# module/server/i18n.py 详解

## 1. 文件概述

`i18n.py` 是国际化模块，负责：
- 管理多语言翻译文件
- 提供翻译加载和保存功能
- 支持中文翻译的读写
- 加载额外的翻译资源

## 2. 导入部分解释


## 3. 类定义解释

### Addition 类（第5-17行）
```python
class Addition:
    @classmethod
    def load_additions(cls) -> dict:
        result = {}
        files: str = ['en-US', 'zh-CN']  # 支持的语言文件
        for file in files:
            file_path = Path.cwd() / 'assets' / 'i18n' / f'{file}.json'  # 语言文件路径
            result[file] = {}
            if not file_path.exists():  # 如果文件不存在
                continue
            with open(str(file_path), 'r', encoding='utf-8') as f:
                result[file] = json.load(f)  # 加载翻译
        return result
```

### I18n 类（第20-44行）
继承自 `Addition`，国际化管理类。

## 4. 每个方法的逐行解释

### I18n.trans_zh_cn 类方法（第23-26行）
```python
@classmethod
def trans_zh_cn(cls, text) -> str:
    cn_zh_data = cls.load_zh_cn()  # 加载中文翻译
    return cn_zh_data[text] if text in cn_zh_data else text  # 返回翻译或原文
```

### I18n.save_zh_cn 类方法（第28-33行）
```python
@classmethod
def save_zh_cn(cls, data) -> None:
    I18n.file_zh_cn.parent.mkdir(parents=True, exist_ok=True)  # 创建目录
    with open(str(I18n.file_zh_cn), 'w', encoding='utf-8') as f:
        s = json.dumps(data, indent=2, ensure_ascii=False, sort_keys=False, default=str)  # 转换为 JSON
        f.write(s)  # 写入文件
```

### I18n.load_zh_cn 类方法（第35-40行）
```python
@classmethod
def load_zh_cn(cls) -> dict:
    if not I18n.file_zh_cn.exists():  # 如果文件不存在
        return {}
    with open(str(I18n.file_zh_cn), 'r', encoding='utf-8') as f:
        return json.load(f)  # 加载翻译
```

## 6. 使用示例

### 加载中文翻译
```python
from module.server.i18n import I18n

# 加载中文翻译
zh_cn = I18n.load_zh_cn()
print(zh_cn)  # {'key1': '翻译1', 'key2': '翻译2', ...}
```

### 翻译文本
```python
from module.server.i18n import I18n

# 翻译文本
translated = I18n.trans_zh_cn('hello')
print(translated)  # '你好' 或 'hello'（如果没有翻译）
```

### 保存中文翻译
```python
from module.server.i18n import I18n

# 保存翻译
data = {
    'hello': '你好',
    'world': '世界'
}
I18n.save_zh_cn(data)
```

### 加载额外翻译
```python
from module.server.i18n import I18n

# 加载额外翻译
additions = I18n.load_additions()
print(additions)  # {'en-US': {...}, 'zh-CN': {...}}
```

## 7. 设计模式总结

1. **继承模式**: `I18n` 继承 `Addition`，扩展功能
2. **类方法模式**: 使用类方法提供静态功能
3. **文件管理模式**: 管理 JSON 翻译文件的读写
4. **延迟加载模式**: 按需加载翻译文件
5. **配置管理模式**: 使用 JSON 文件存储翻译配置
