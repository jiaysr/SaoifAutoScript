# Sougenbi 业原火 任务详解

## 1. 文件概述

**任务功能**: 自动挑战业原火副本，支持选择三种业原火类型（贪/嗔/痴），自动管理加成Buff和票券检测。

- **贪 (GREED)**: 贪念业原火
- **嗔 (ANGER)**: 嗔怒业原火
- **痴 (FOOLERY)**: 愚痴业原火

支持御魂切换、金币/经验Buff自动开关、票券数量OCR检测等功能。

**文件结构**:
- `script_task.py` - 任务主逻辑入口
- `config.py` - 配置参数定义
- `assets.py` - 图像/点击/OCR等资源定义

## 4. 核心代码逐行解释

### ScriptTask 类定义

```python
class ScriptTask(GeneralBattle, GameUi, SwitchSoul, SougenbiAssets):
```

继承组合：通用战斗、游戏UI导航、御魂切换、业原火资源。

### run() - 主入口方法

```python
def run(self):
    con = self.config.sougenbi                              # 获取业原火配置
    s_con: SougenbiConfig = con.sougenbi_config             # 核心配置
    limit_time = con.sougenbi_config.limit_time
    self.limit_time: timedelta = timedelta(                  # 计算时间限制
        hours=limit_time.hour, minutes=limit_time.minute, seconds=limit_time.second)

    # 步骤1: 开启加成Buff
    if s_con.buff_enable:
        self.ui_get_current_page()
        self.ui_goto(page_main)
        self.open_buff()
        if s_con.buff_gold_50_click: self.gold_50(True)     # 按需开启各种Buff
        if s_con.buff_gold_100_click: self.gold_100(True)
        if s_con.buff_exp_50_click: self.exp_50(True)
        if s_con.buff_exp_100_click: self.exp_100(True)
        self.close_buff()

    # 步骤2: 切换御魂
    if con.switch_soul_config.enable:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(con.switch_soul_config.switch_group_team)
    if con.switch_soul_config.enable_switch_by_name:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul_by_name(...)

    # 步骤3: 导航到业原火界面
    self.ui_get_current_page()
    self.ui_goto(page_soul_zones)
    while 1:
        self.screenshot()
        if self.appear(self.I_S_CHECK_SOUGENBI): break      # 已进入业原火界面
        if self.appear_then_click(self.I_S_SOUGENBI, interval=1): continue  # 点击入口
    sleep(0.5)

    # 步骤4: 根据业原火类型选择目标资源
    match con.sougenbi_config.sougenbi_class:
        case SougenbiClass.GREED:
            image_target = self.I_S_FIRE_GREED               # 贪的挑战按钮图像
            click_target = self.C_C_GREED                    # 贪的点击位置
            number_target = self.O_S_GREED                   # 贪的票券OCR
        case SougenbiClass.Anger:
            image_target = self.I_S_FIRE_ANGER
            click_target = self.C_C_ANGER
            number_target = self.O_S_ANGER
        case SougenbiClass.Foolery:
            image_target = self.I_S_FIRE_FOOLERY
            click_target = self.C_C_FOOLERY
            number_target = self.O_S_FOOLERY

    # 步骤5: 锁定阵容
    self.check_lock(con.general_battle_config.lock_team_enable,
                    self.I_S_TEAM_LOCK, self.I_S_TEAM_UNLOCK)

    # 步骤6: 切换到目标业原火类型
    while 1:
        self.screenshot()
        if self.appear(image_target): break                  # 目标类型已选中
        if self.click(click_target, interval=0.5): pass      # 点击切换类型

    # 步骤7: 主战斗循环
    while 1:
        self.screenshot()
        if not self.appear(self.I_S_CHECK_SOUGENBI): continue  # 确认在业原火界面
        if self.current_count >= con.sougenbi_config.limit_count: break  # 次数限制
        if datetime.now() - self.start_time >= self.limit_time: break     # 时间限制

        # OCR检测票券数量
        ticket = number_target.ocr(self.device.image)
        if ticket == 0: break                                # 无票券则退出

        # 点击挑战并执行战斗
        while 1:
            self.screenshot()
            if self.appear_then_click(self.I_S_FIRE, interval=1): pass
            if not self.appear(self.I_S_FIRE):
                self.run_general_battle(config=con.general_battle_config)
                break

    # 步骤8: 返回探索大世界
    while 1:
        self.screenshot()
        if self.appear(self.I_CHECK_EXPLORATION): break
        if self.appear_then_click(self.I_UI_BACK_YELLOW, interval=1): continue

    # 步骤9: 关闭加成Buff
    if s_con.buff_enable:
        self.ui_get_current_page()
        self.ui_goto(page_main)
        self.open_buff()
        if s_con.buff_gold_50_click: self.gold_50(False)
        if s_con.buff_gold_100_click: self.gold_100(False)
        if s_con.buff_exp_50_click: self.exp_50(False)
        if s_con.buff_exp_100_click: self.exp_100(False)
        self.close_buff()

    # 步骤10: 设置下次运行时间并结束
    self.set_next_run("Sougenbi", success=True, finish=True)
    raise TaskEnd
```

## 6. 设计模式总结

### 1. 策略模式 (Strategy Pattern)
- `SougenbiClass` 枚举定义三种业原火类型
- `match` 语句根据类型动态选择对应的图像、点击、OCR资源
- 将资源选择逻辑与战斗逻辑解耦

### 2. 模板方法模式 (Template Method Pattern)
- `run()` 方法定义了完整的任务模板：Buff管理 → 御魂切换 → 导航 → 战斗循环 → 清理
- 与八岐大蛇共享相同的 `GeneralBattle` 基类战斗流程

### 3. 资源动态绑定
- 通过 `match` 语句将 `image_target`, `click_target`, `number_target` 动态绑定到具体的资源
- 后续代码统一使用这些变量，无需关心具体是哪种业原火

### 4. OCR票券检测
- 使用 `number_target.ocr()` 实时检测剩余票券数量
- 票券为0时自动退出，避免无效点击
- 三种业原火使用不同的OCR资源（`O_S_GREED`, `O_S_ANGER`, `O_S_FOOLERY`）

### 5. Buff对称管理
- 开始时开启的Buff在结束时必须关闭
- 使用相同的 `buff_gold_50_click` 等配置项控制开/关
- 确保任务结束后游戏状态恢复

### 6. 组合继承
- `ScriptTask` 通过多重继承组合 `GeneralBattle`（战斗）、`GameUi`（导航）、`SwitchSoul`（御魂切换）、`SougenbiAssets`（资源）的能力
