# GoldYoukai 金币妖怪 任务详解

## 1. 文件概述

**任务功能**: 自动组队挑战金币妖怪副本，包括：
- 切换御魂配置
- 开启金币加成buff
- 创建房间并等待队友
- 执行战斗
- 关闭buff并退出

**入口文件**: `tasks/GoldYoukai/script_task.py`

---

## 2. 配置参数说明

**配置文件**: `tasks/GoldYoukai/config.py`

### GoldYoukaiConfig 参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `buff_gold_50_click` | bool | False | 是否开启50%金币加成 |
| `buff_gold_100_click` | bool | False | 是否开启100%金币加成 |

### GoldYoukai 配置结构

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `scheduler` | Scheduler | 调度器配置 |
| `gold_youkai` | GoldYoukaiConfig | 金币妖怪配置 |
| `switch_soul` | SwitchSoulConfig | 御魂切换配置 |

## 4. 核心代码逐行解释

### ScriptTask.run() - 主入口

```python
def run(self):
    # 切换御魂
    if self.config.gold_youkai.switch_soul.enable:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(self.config.gold_youkai.switch_soul.switch_group_team)

    if self.config.gold_youkai.switch_soul.enable_switch_by_name:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul_by_name(...)

    # 开启加成
    con = self.config.gold_youkai.gold_youkai
    if con.buff_gold_50_click or con.buff_gold_100_click:
        self.ui_get_current_page()
        self.ui_goto(page_main)
        self.open_buff()
        if con.buff_gold_50_click:
            self.gold_50()  # 开启50%金币加成
        if con.buff_gold_100_click:
            self.gold_100()  # 开启100%金币加成
        self.close_buff()

    # 执行两次战斗
    count = 0
    while count < 2:
        self.ui_get_current_page()
        self.ui_goto(page_team)
        self.check_zones('金币妖怪')  # 选择金币妖怪副本

        # 创建房间
        if not self.create_room():
            self.gold_exit(con)
        self.ensure_public()  # 确保公开房间
        self.create_ensure()  # 确认创建

        # 等待队友加入
        wait_timer = Timer(50)
        wait_timer.start()
        while 1:
            self.screenshot()
            if not self.is_in_room():
                continue
            if wait_timer.reached():
                # 超时直接挑战
                logger.warning('Wait for too long and start the challenge')
                self.click_fire()
                count += 1
                self.run_general_battle()
                break
            if not self.appear(self.I_ADD_5_1):
                # 有人进来了，开始挑战
                logger.info('There is someone in the room')
                self.click_fire()
                count += 1
                self.run_general_battle()
                break

    # 退出
    self.gold_exit(con)
```

### battle_wait() - 战斗等待（重写）

```python
def battle_wait(self, random_click_swipt_enable: bool) -> bool:
    self.device.stuck_record_add('BATTLE_STATUS_S')
    self.device.click_record_clear()

    logger.info("Start battle process")
    while 1:
        self.screenshot()
        # 点击准备按钮
        if self.appear_then_click(self.I_PREPARE_HIGHLIGHT, interval=1):
            logger.info('click prepare')
        # 检测胜利
        if self.appear(self.I_DE_WIN):
            logger.info('Win battle')
            self.ui_click_until_disappear(self.I_DE_WIN)
            return True
        if self.appear(self.I_GOLD_WIN):
            logger.info('Win battle')
            self.ui_click_until_disappear(self.I_GOLD_WIN)
            return True
        # 检测失败
        if self.appear(self.I_FALSE):
            logger.warning('False battle')
            self.ui_click_until_disappear(self.I_FALSE)
            return False
```

### gold_exit() - 退出清理

```python
def gold_exit(self, con):
    self.ui_get_current_page()
    self.ui_goto(page_main)

    # 关闭buff
    if con.buff_gold_50_click or con.buff_gold_100_click:
        self.open_buff()
        if con.buff_gold_50_click:
            self.gold_50(False)  # 关闭50%加成
        if con.buff_gold_100_click:
            self.gold_100(False)  # 关闭100%加成
        self.close_buff()

    self.set_next_run(task='GoldYoukai', success=True, finish=False)
    raise TaskEnd('GoldYoukai')
```

## 6. 设计模式总结

### 1. 组合模式
- 继承多个组件：`GameUi`, `GeneralBattle`, `GeneralRoom`, `GeneralInvite`, `SwitchSoul`
- 各组件提供独立功能，组合完成复杂任务

### 2. 模板方法模式
- `battle_wait()` 重写父类方法
- 自定义胜利/失败检测逻辑

### 3. 超时控制
- `Timer(50)` 控制等待队友时间
- 超时后自动开始挑战

### 4. 资源管理模式
- 开启buff → 执行任务 → 关闭buff
- 确保资源正确释放

### 5. 状态机模式
- `is_in_room()` 检测房间状态
- `I_ADD_5_1` 检测是否有空位
- `I_GOLD_WIN` 检测战斗胜利
