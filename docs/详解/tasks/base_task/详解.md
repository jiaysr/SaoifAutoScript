# BaseTask 基础任务类 逐行代码详解

## 1. 文件概述

`base_task.py` 是整个自动化脚本框架的**核心基类**，定义了所有任务的公共行为。它提供了：

- 截图与异常检测机制（突发协作邀请处理）
- 图像匹配与点击操作（appear/appear_then_click）
- OCR 文字识别操作
- 列表查找与滑动操作
- 多尺度图片识别
- 等待机制（等待出现/消失/稳定）
- 任务调度（设置下次运行时间）
- UI 奖励领取与通用 UI 操作

所有具体任务类（如 Restart、GameUi 等）都继承自 `BaseTask`。

## 2. 配置参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `config` | `Config` | 全局配置对象，包含所有任务的配置 |
| `device` | `Device` | 设备对象，负责截图和输入操作 |
| `folder` | `str` | 任务文件夹名 |
| `name` | `str` | 任务名称 |
| `stage` | `str` | 任务阶段 |
| `limit_time` | `timedelta` | 任务软时间限制 |
| `limit_count` | `int` | 任务运行次数限制 |
| `current_count` | `int` | 当前已运行次数 |

## 3. 资源定义说明

`BaseTask` 通过继承 `GlobalGameAssets` 获得全局游戏资源（如协作邀请按钮、网络异常图标等），通过继承 `CostumeBase` 获得皮肤相关资源。

### 4.4 图像匹配 `appear()`（第157-184行）

```python
    def appear(self, target, interval=None, threshold=None):
        if interval:
            if target.name in self.interval_timer:
                if self.interval_timer[target.name].limit != interval:
                    self.interval_timer[target.name] = Timer(interval)
            else:
                self.interval_timer[target.name] = Timer(interval)
            if not self.interval_timer[target.name].reached():
                return False
```

- **第157-175行**：核心图像匹配方法。`interval` 参数控制匹配频率——在指定时间间隔内重复调用会直接返回 `False`，避免频繁匹配浪费性能。

### 4.5 匹配并点击 `appear_then_click()`（第186-216行）

```python
    def appear_then_click(self, target, action=None, interval=None, threshold=None, duration=None):
        appear = self.appear(target, interval=interval, threshold=threshold)
        if appear and not action:
            x, y = target.coord()
            self.device.click(x, y, control_name=target.name)
        elif appear and action:
            x, y = action.coord()
            if isinstance(action, RuleLongClick):
                self.device.long_click(x, y, duration=action.duration / 1000, control_name=target.name)
            elif isinstance(action, RuleClick):
                self.device.click(x, y, control_name=target.name)
        return appear
```

- **第186-216行**：出现即点击。支持三种模式：
  1. 无 `action`：点击目标图像本身的坐标
  2. `action` 为 `RuleClick`：点击指定位置
  3. `action` 为 `RuleLongClick`：长按指定位置（`duration` 单位为毫秒，转换为秒传入设备）

## 5. 任务执行流程图

```
BaseTask 初始化
│
├── 注入 Config 和 Device
├── 初始化 interval_timer（频率控制）
├── 记录启动时间
├── 检查皮肤配置
└── 初始化计数器
│
├── screenshot() ──────────────────────────┐
│   ├── device.screenshot()                │
│   └── _burst() ── 检测协作邀请           │
│       ├── 根据策略决定接受/拒绝/忽略      │
│       └── 循环处理直到邀请消失            │
│                                          │
├── appear(target) ────────────────────────┤
│   ├── 检查 interval 频率限制             │
│   ├── OCR 或图像匹配                     │
│   └── 返回匹配结果                       │
│                                          │
├── appear_then_click(target, action) ─────┤
│   ├── appear(target)                     │
│   ├── 无 action → 点击目标坐标           │
│   └── 有 action → 点击 action 坐标       │
│                                          │
├── wait_until_appear(target) ─────────────┤
│   └── 循环截图直到目标出现或超时          │
│                                          │
└── set_next_run(task) ────────────────────┘
    └── 设置任务下次运行时间
```

## 6. 设计模式总结

| 设计模式 | 应用位置 | 说明 |
|----------|----------|------|
| **模板方法模式** | `screenshot()` | 在截图后自动插入突发事件检测，子类无需关心 |
| **策略模式** | `_burst()` 中的 match-case | 根据配置选择不同的协作邀请处理策略 |
| **频率控制模式** | `interval_timer` 字典 | 通过 Timer 对象控制操作执行频率，避免重复操作 |
| **组合模式** | `appear_then_click()` | 将匹配和点击组合为原子操作 |
| **多重继承** | `BaseTask(GlobalGameAssets, CostumeBase)` | 通过继承获得全局资源和皮肤处理能力 |
| **防御性编程** | `maybe_screenshot()` | 在需要时才截图，优化性能 |
