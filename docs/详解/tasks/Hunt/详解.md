# 狩猎战 (Hunt) 任务代码详解

## 1. 文件概述

狩猎战任务包含三个核心文件：

| 文件 | 行数 | 职责 |
|------|------|------|
| `config.py` | 32行 | 定义配置参数模型（Pydantic） |
| `assets.py` | 42行 | 定义UI资源定位规则（图片、点击） |
| `script_task.py` | 197行 | 实现任务执行逻辑 |

**任务说明**：狩猎战分为「麒麟」和「阴界之门」两种模式：
- **麒麟**：周一至周四开放，可挑战时间 6:00-23:00
- **阴界之门**：周五至周日开放，可挑战时间 17:00-23:00

### 4.3 check_datetime() - 时间检查

```python
def check_datetime(self) -> bool:
    now = datetime.now()
    day_of_week = now.weekday()  # 0=周一, 6=周周日
    
    # 判断今日是麒麟日还是阴界日
    if 0 <= day_of_week <= 3:      # 周一到周四
        self.kirin_day = True
    elif 4 <= day_of_week <= 6:    # 周五到周日
        self.kirin_day = False
    
    # 判断明日类型（用于安排次日任务）
    if 3 <= day_of_week <= 5:      # 周四到周六
        self.tomorrow_kirin_day = False
    else:
        self.tomorrow_kirin_day = True
```

**第58-68行**：根据星期几判断今日和明日的挑战类型。

```python
    now = datetime.now()
    
    if self.kirin_day:
        logger.info('Today is the Kirin day')
        # 麒麟日：6:00前设定为今日自定义时间
        if now.time() < time(6, 0):
            self.custom_next_run(task='Hunt', custom_time=self.con_time.kirin_time, time_delta=0)
            raise TaskEnd('Hunt')
        # 23:00后安排明日任务
        elif now.time() > time(23, 0):
            self.plan_tomorrow_hunt()
            raise TaskEnd('Hunt')
        else:
            return True  # 在可执行时间段内
    else:
        logger.info('Today is the Netherworld day')
        # 阴界日：17:00前设定为今日自定义时间
        if now.time() < time(17, 0):
            self.custom_next_run(task='Hunt', custom_time=self.con_time.netherworld_time, time_delta=0)
            raise TaskEnd('Hunt')
        # 23:00后安排明日任务
        elif now.time() > time(23, 0):
            self.plan_tomorrow_hunt()
            raise TaskEnd('Hunt')
        else:
            return True  # 在可执行时间段内
```

**第70-94行**：根据当前时间决定是否执行、等待或安排明日任务。

### 4.5 kirin() - 麒麟挑战

```python
def kirin(self):
    logger.hr('kirin', 2)  # 打印分隔线
    
    while 1:
        self.screenshot()  # 截图
        
        # 检测到准备按钮，说明进入战斗准备界面
        if self.appear(self.I_PREPARE_HIGHLIGHT):
            break
        
        # 点击确认按钮（处理弹窗）
        if self.appear_then_click(self.I_UI_CONFIRM, interval=0.9):
            continue
        
        # 点击挑战按钮
        if self.appear_then_click(self.I_KIRIN_CHALLAGE, interval=1.5):
            continue
        
        # 检测到已挑战标记，今日已完成
        if self.appear(self.I_KIRIN_END):
            logger.warning('Today have already challenged the Kirin')
            self.ui_click_until_disappear(self.I_UI_BACK_YELLOW)
            return
    
    logger.info('Start battle')
    # 执行战斗
    self.run_general_battle(self.config.hunt.kirin_battle_config)
```

**第105-121行**：麒麟挑战流程——循环检测界面状态，进入准备界面后开始战斗。

### 4.6 netherworld() - 阴界之门挑战

```python
def netherworld(self):
    logger.hr('netherworld', 2)
    
    while 1:
        self.screenshot()
        
        # 检测是否在房间内
        if self.is_in_room(False):
            self.screenshot()
            # 检测火按钮（开始按钮）
            if not self.appear(self.I_FIRE):
                continue
            self.click_fire()  # 点击开始
            break
        
        # 点击阴界之门入口
        if self.appear_then_click(self.I_NW, interval=0.9):
            continue
        
        # 点击确认按钮
        if self.appear_then_click(self.I_UI_CONFIRM, interval=0.9):
            continue
        
        # 点击挑战按钮
        if self.appear_then_click(self.I_NW_CHALLAGE, interval=1.5):
            continue
        
        # 检测到已完成标记
        if self.appear(self.I_NW_DONE):
            logger.warning('Today have already challenged the Netherworld')
            self.ui_click_until_disappear(self.I_UI_BACK_RED)
            return
    
    logger.info('Start battle')
    # 执行战斗
    self.run_general_battle(self.config.hunt.netherworld_battle_config)
```

### 4.7 battle_wait() - 战斗等待（重写）

```python
def battle_wait(self, random_click_swipt_enable: bool) -> bool:
    """
    重写父类方法
    阴界之门：胜利后回到狩猎战主界面
    麒麟：胜利后回到麒麟主界面
    """
    # 初始化卡顿检测
    self.device.stuck_record_add('BATTLE_STATUS_S')
    self.device.click_record_clear()
    
    logger.info("Start battle process")
    stuck_timer = Timer(180)  # 3分钟超时计时器
    stuck_timer.start()
    
    while 1:
        self.screenshot()
        
        # 检测胜利
        if self.appear(self.I_WIN):
            logger.info('Battle win')
            self.ui_click_until_disappear(self.I_WIN)
            return True
        
        # 检测失败
        if self.appear(self.I_FALSE, threshold=0.8):
            logger.info("Battle result is false")
            self.ui_click_until_disappear(self.I_FALSE)
            return False
        
        # 阴界之门：失败后可能回到准备界面
        if self.appear_then_click(self.I_PREPARE_HIGHLIGHT, interval=1.5):
            logger.info('Netherworld click prepare after maybe failed')
            self.device.stuck_record_add('BATTLE_STATUS_S')
            continue
        
        # 超时处理：3分钟后延长5分钟
        if stuck_timer and stuck_timer.reached():
            stuck_timer = None
            self.device.stuck_record_clear()
            self.device.stuck_record_add('BATTLE_STATUS_S')
```

**第148-186行**：重写战斗等待逻辑，处理阴界之门的特殊返回界面。

## 6. 设计模式总结

### 6.1 多重继承组合模式

```python
class ScriptTask(GameUi, GeneralBattle, GeneralInvite, SwitchSoul, HuntAssets):
```

通过多重继承组合不同功能模块，实现代码复用：
- **GameUi**：界面导航基类
- **GeneralBattle**：通用战斗逻辑
- **GeneralInvite**：组队功能
- **SwitchSoul**：御魂切换
- **HuntAssets**：资源定义

### 6.2 模板方法模式

`battle_wait()` 方法重写父类实现，适配狩猎战的特殊流程：
- 父类：战斗结束返回主界面
- 子类：阴界之门失败后返回准备界面

### 6.3 状态机模式

挑战流程通过循环检测UI状态实现状态机：
```
截图 → 检测状态 → 执行动作 → 循环
```

### 6.4 资源与逻辑分离

- `assets.py`：定义UI资源（图片、点击区域）
- `script_task.py`：实现业务逻辑
- `config.py`：管理配置参数

### 6.5 异常控制流

使用 `TaskEnd` 异常控制任务结束，避免深层嵌套：
```python
if not self.check_datetime():
    raise TaskEnd('Hunt')
```

### 6.6 定时调度

通过 `custom_next_run()` 实现定时调度：
- `time_delta=0`：今日指定时间
- `time_delta=1`：明日指定时间
