# Script 脚本设置 逐行代码详解

## 1. 文件概述

`Script` 模块定义了脚本运行的**全局配置**，包含三个子模块：

- **config_device.py**：设备配置（模拟器类型、截图方式、控制方式等）
- **config_error.py**：错误处理配置（错误保存、通知等）
- **config_optimization.py**：性能优化配置（截图间隔、调度规则等）
- **config.py**：聚合配置入口
- **assets.py**：资源定义（空，纯配置模块）

## 2. 配置参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `serial` | `str` | `"auto"` | 设备序列号（ADB serial） |
| `handle` | `str` | `""` | 窗口句柄 |
| `package_name` | `PackageName` | `AUTO` | 游戏包名 |
| `screenshot_method` | `ScreenshotMethod` | `AUTO` | 截图方式 |
| `control_method` | `ControlMethod` | `MINITOUCH` | 控制方式 |
| `adb_restart` | `bool` | `False` | 是否重启 ADB |
| `emulatorinfo_type` | `EmulatorInfoType` | `AUTO` | 模拟器类型 |
| `emulatorinfo_name` | `str` | `""` | 模拟器名称 |
| `emulatorinfo_path` | `str` | `""` | 模拟器路径 |
| `emulator_window_minimize` | `bool` | `False` | 模拟器启动时最小化 |
| `run_background_only` | `bool` | `False` | 模拟器无UI后台运行 |

### Optimization 优化配置（config_optimization.py）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `screenshot_interval` | `float` | `0.3` | 普通截图间隔（秒） |
| `combat_screenshot_interval` | `float` | `1.0` | 战斗中截图间隔（秒） |
| `task_hoarding_duration` | `float` | `0` | 任务囤积时长（秒） |
| `when_task_queue_empty` | `WhenTaskQueueEmpty` | `GOTO_MAIN` | 任务队列为空时的行为 |
| `close_game_wait_duration` | `Time` | `00:00:00` | 关闭游戏后等待时长 |
| `close_emulator_wait_duration` | `Time` | `00:00:00` | 关闭模拟器后等待时长 |
| `emulator_startup_lead_time` | `Time` | `00:02:00` | 模拟器启动提前量 |
| `schedule_rule` | `ScheduleRule` | `FILTER` | 调度规则 |

### WhenTaskQueueEmpty 枚举

| 值 | 说明 |
|----|------|
| `GOTO_MAIN` | 返回主页等待 |
| `CLOSE_GAME` | 关闭游戏等待 |

### ScheduleRule 枚举

| 值 | 说明 |
|----|------|
| `FILTER` | 基于过滤器的调度（开发者设定规则） |
| `FIFO` | 先来后到 |
| `PRIORITY` | 基于优先级 |

## 4. 核心代码逐行解释

### 4.1 PackageName 枚举（config_device.py 第10-16行）

```python
class PackageName(str, Enum):
    AUTO = 'auto'
    NETEASE_ONMYOJI = 'com.netease.onmyoji.wyzymnqsd_cps'
    NETEASE_MI = 'com.netease.onmyoji.mi'
    NETEASE = 'com.netease.onmyoji'
    NETEASE_HUAWEI = 'com.netease.onmyoji.huawei'
    NETEASE_BILIBILI = 'com.netease.onmyoji.bili'
```

- **第10-16行**：游戏包名枚举。支持多个渠道的阴阳师客户端，`AUTO` 模式自动检测已安装的包。

### 4.2 ScreenshotMethod 枚举（config_device.py 第18-27行）

```python
class ScreenshotMethod(str, Enum):
    AUTO = 'auto'
    ADB = 'ADB'
    ADB_NC = 'ADB_nc'
    UIAUTOMATOR2 = 'uiautomator2'
    DROIDCAST = 'DroidCast'
    DROIDCAST_RAW = 'DroidCast_raw'
    SCRCPY = 'scrcpy'
    WINDOW_BACKGROUND = 'window_background'
    NEMU_IPC = 'nemu_ipc'
```

- **第18-27行**：截图方式枚举。不同方式在速度和兼容性上有差异：
  - `ADB`：通用但较慢
  - `DroidCast`：通过应用内截图，速度快
  - `NEMU_IPC`：MuMu 模拟器专用，最快
  - `WINDOW_BACKGROUND`：窗口后台截图，支持最小化

### 4.3 Device 配置类（config_device.py 第52-78行）

```python
class Device(BaseModel):
    serial: str = Field(default="auto", description='serial_help')
    handle: str = Field(default='', description='handle_help')
    package_name: PackageName = Field(default=PackageName.AUTO)
    screenshot_method: ScreenshotMethod = Field(default=ScreenshotMethod.AUTO)
    control_method: ControlMethod = Field(default=ControlMethod.MINITOUCH)
    adb_restart: bool = Field(default=False)
    emulatorinfo_type: Union[EmulatorInfoType, str] = Field(default=EmulatorInfoType.AUTO)
    emulatorinfo_name: str = Field(default='')
    emulatorinfo_path: str = Field(default='')
    emulator_window_minimize: bool = Field(default=False)
    run_background_only: bool = Field(default=False)
```

- **第52-78行**：设备配置。`serial` 设为 `"auto"` 时自动检测连接的设备。`emulatorinfo_type` 支持枚举和字符串两种类型，方便扩展。

### 4.4 Error 配置类（config_error.py 第10-24行）

```python
class Error(BaseModel):
    handle_error: bool = Field(default=True)
    error_repeated: bool = Field(default=False)
    save_error: bool = Field(default=True)
    screenshot_length: int = Field(default=1, ge=1)
    notify_enable: bool = Field(default=False)
    notify_config: MultiLine = Field(default='provider: null')
```

- **第10-24行**：错误处理配置。`notify_config` 使用 YAML 格式配置通知提供商。

### 4.5 Optimization 配置类（config_optimization.py 第19-34行）

```python
class Optimization(BaseModel):
    screenshot_interval: float = Field(default=0.3)
    combat_screenshot_interval: float = Field(default=1.0)
    task_hoarding_duration: float = Field(default=0)
    when_task_queue_empty: WhenTaskQueueEmpty = Field(default=WhenTaskQueueEmpty.GOTO_MAIN)
    close_game_wait_duration: Time = Field(default=Time(minute=0))
    close_emulator_wait_duration: Time = Field(default=Time(minute=0))
    emulator_startup_lead_time: Time = Field(default=Time(minute=2))
    schedule_rule: ScheduleRule = Field(default=ScheduleRule.FILTER)
```

- **第19-34行**：性能优化配置。关键参数：
  - `screenshot_interval`：控制截图频率，0.3 秒约 3 FPS
  - `combat_screenshot_interval`：战斗中降低截图频率到 1 秒
  - `task_hoarding_duration`：任务囤积时长，0 表示立即执行
  - `when_task_queue_empty`：空闲时行为（返回主页或关闭游戏）

### 4.6 Script 聚合配置（config.py 第11-13行）

```python
class Script(BaseModel):
    device: Device = Field(default_factory=Device)
    error: Error = Field(default_factory=Error)
    optimization: Optimization = Field(default_factory=Optimization)
```

- **第11-13行**：Script 配置聚合了设备、错误处理和优化三个子配置。

## 5. 任务执行流程图

```
Script 配置加载
│
├── Device 设备配置
│   ├── serial: 设备序列号
│   ├── package_name: 游戏包名
│   ├── screenshot_method: 截图方式
│   ├── control_method: 控制方式
│   └── emulatorinfo: 模拟器信息
│
├── Error 错误配置
│   ├── handle_error: 自动处理错误
│   ├── save_error: 保存错误截图
│   └── notify: 错误通知
│
└── Optimization 优化配置
    ├── screenshot_interval: 截图频率
    ├── combat_screenshot_interval: 战斗截图频率
    ├── schedule_rule: 调度规则
    └── when_task_queue_empty: 空闲行为
```

## 6. 设计模式总结

| 设计模式 | 应用位置 | 说明 |
|----------|----------|------|
| **枚举约束** | PackageName/ScreenshotMethod 等 | 通过枚举限制可选值，防止配置错误 |
| **聚合模式** | Script 类 | 将相关配置聚合到统一入口 |
| **默认值策略** | 所有 Field | 提供合理默认值，开箱即用 |
| **Union 类型** | `emulatorinfo_type` | 支持枚举和字符串，兼顾严格性和灵活性 |
| **关注点分离** | Device/Error/Optimization 分文件 | 按职责分离配置，便于维护 |
