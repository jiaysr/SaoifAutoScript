# Orochi 八岐大蛇 任务详解

## 1. 文件概述

**任务功能**: 自动挑战八岐大蛇御魂副本，支持多种游戏身份模式：
- **队长模式 (LEADER)**: 创建队伍、邀请队友、循环挑战
- **队员模式 (MEMBER)**: 接受邀请、等待队长开始战斗
- **单人模式 (ALONE)**: 独自挑战副本
- **野队模式 (WILD)**: 创建公开房间、自动匹配野人队友

支持按层数自动切换御魂配置、自动开启/关闭御魂加成Buff、猫咪奖励领取等功能。

**文件结构**:
- `script_task.py` - 任务主逻辑入口
- `config.py` - 配置参数定义
- `assets.py` - 图像/点击/OCR等资源定义

## 2. 配置参数说明

### Orochi 总配置结构

| `switch_soul` | SwitchSoulConfig | 御魂切换配置 |

### OrochiConfig 核心配置

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `user_status` | UserStatus | LEADER | 用户身份（队长/队员/单人/野队） |
| `layer` | Layer | ELEVEN(悲鸣) | 挑战层数 |
| `limit_time` | Time | 30分钟 | 限制运行时间 |
| `limit_count` | int | 30 | 限制挑战次数 |
| `soul_buff_enable` | bool | False | 是否开启御魂加成Buff |

### UserStatus 枚举

| 值 | 说明 |
|----|------|
| `LEADER` | 队长模式，负责创建房间和邀请 |
| `MEMBER` | 队员模式，等待被邀请 |
| `ALONE` | 单人模式，独自挑战 |
| `WILD` | 野队模式，公开匹配 |

### Layer 枚举（层数）

| 值 | 说明 |
|----|------|
| `ONE` ~ `NINE` | 壹层到玖层 |
| `TEN` | 拾层 |
| `ELEVEN` | 悲鸣 |
| `TWELVE` | 神罚 |
| `THIRTEEN` | 虚无 |

### SwitchSoulConfig 御魂切换配置

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable` | bool | False | 启用按组/队切换御魂 |
| `switch_group_team` | str | '-1,-1' | 组号,队号 |
| `enable_switch_by_name` | bool | False | 启用按名称切换御魂 |
| `group_name` | str | '' | 御魂组名称 |
| `team_name` | str | '' | 御魂队伍名称 |
| `auto_switch_soul` | bool | False | 启用根据选层自动切换御魂 |
| `ten_switch` | str | '-1,-1' | 拾层御魂配置 |
| `eleven_switch` | str | '-1,-1' | 悲鸣御魂配置 |
| `twelve_switch` | str | '-1,-1' | 神罚御魂配置 |

## 4. 核心代码逐行解释

### ScriptTask 类定义

```python
class ScriptTask(GeneralBattle, GeneralInvite, GeneralBuff, GeneralRoom, GameUi, SwitchSoul, OrochiAssets):
```

通过多重继承组合了以下能力：
- `GeneralBattle` - 通用战斗逻辑
- `GeneralInvite` - 邀请队友逻辑
- `GeneralBuff` - Buff管理逻辑
- `GeneralRoom` - 房间管理逻辑
- `GameUi` - 游戏界面导航
- `SwitchSoul` - 御魂切换
- `OrochiAssets` - 八岐大蛇的图像资源

### run() - 主入口方法

```python
def run(self) -> bool:
    # 御魂切换方式一：按组号/队号切换
    if self.config.orochi.switch_soul.enable:
        self.ui_get_current_page()          # 获取当前页面状态
        self.ui_goto(page_shikigami_records) # 导航到式神录
        self.run_switch_soul(self.config.orochi.switch_soul.switch_group_team)

    # 御魂切换方式二：按名称切换
    if self.config.orochi.switch_soul.enable_switch_by_name:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul_by_name(...)

    # 根据选层切换御魂（方式三）
    self.orochi_switch_soul()

    # 初始化限制条件
    limit_count = self.config.orochi.orochi_config.limit_count
    limit_time = self.config.orochi.orochi_config.limit_time
    self.current_count = 0
    self.limit_count: int = limit_count
    self.limit_time: timedelta = timedelta(hours=..., minutes=..., seconds=...)

    # 如果不在战斗中，导航到主页并开启Buff
    if not self.is_in_battle(True):
        self.ui_get_current_page()
        self.ui_goto(page_main)
        if config.orochi_config.soul_buff_enable:
            self.open_buff()
            self.soul(is_open=True)     # 开启御魂加成
            self.close_buff()

    # 根据用户身份选择执行模式
    match config.orochi_config.user_status:
        case UserStatus.LEADER: success = self.run_leader()
        case UserStatus.MEMBER: success = self.run_member()
        case UserStatus.ALONE:  self.run_alone()
        case UserStatus.WILD:   success = self.run_wild()

    # 关闭御魂加成Buff
    if config.orochi_config.soul_buff_enable:
        self.open_buff()
        self.soul(is_open=False)
        self.close_buff()

    # 设置下一次运行时间
    if success:
        self.set_next_run('Orochi', finish=True, success=True)
    else:
        self.set_next_run('Orochi', finish=False, success=False)

    raise TaskEnd  # 结束任务
```

def check_lock(self, lock: bool = True) -> bool:
    if lock:
        while 1:
            self.screenshot()
            if self.appear(self.I_OROCHI_LOCK):     # 已锁定则返回
                return True
            if self.appear_then_click(self.I_OROCHI_UNLOCK, interval=1):  # 未锁定则点击锁定
                continue
    else:
        while 1:
            self.screenshot()
            if self.appear(self.I_OROCHI_UNLOCK):   # 已解锁则返回
                return True
            if self.appear_then_click(self.I_OROCHI_LOCK, interval=1):   # 已锁定则点击解锁
                continue

### run_leader() - 队长模式

```python
def run_leader(self):
    # 1. 导航到八岐大蛇界面
    self.ui_get_current_page()
    self.ui_goto(page_soul_zones)
    self.orochi_enter()

    # 2. 选择层数和锁定阵容
    layer = self.config.orochi.orochi_config.layer
    self.check_layer(layer)
    self.config.orochi.general_battle_config.lock_team_enable = True
    self.check_lock(...)

    # 3. 创建队伍和房间
    while 1:
        self.screenshot()
        if self.appear(self.I_CHECK_TEAM): break
        if self.appear_then_click(self.I_FORM_TEAM, interval=1): continue
    self.create_room()
    self.ensure_private()    # 设为私人房间
    self.create_ensure()

    # 4. 主循环：邀请队友并战斗
    is_first = True
    while 1:
        self.screenshot()
        # 处理战斗结束后的邀请弹窗
        if self.check_and_invite(self.config.orochi.invite_config.default_invite):
            continue
        # 检查猫咪奖励
        if self.appear_then_click(self.I_PET_PRESENT, action=self.C_WIN_3, interval=1):
            continue
        # 检查限制条件
        if self.current_count >= self.limit_count: break
        if datetime.now() - self.start_time >= self.limit_time: break
        # 检查房间是否存活
        if not self.is_in_room():
            if self.is_room_dead(): success = False; break
            continue
        # 首次邀请队友，之后直接战斗
        if is_first:
            if not self.run_invite(config=..., is_first=True):
                success = False; break
            is_first = False
            self.run_general_battle(config=...)
        else:
            if self.run_invite(config=...):
                self.run_general_battle(config=...)
            else:
                success = False; break

    # 5. 退出房间和队伍
    self.exit_room()
    self.exit_team()
    self.ui_get_current_page()
    self.ui_goto(page_main)
    return success
```

### run_alone() - 单人模式

```python
def run_alone(self):
    # 导航到八岐大蛇界面
    self.ui_get_current_page()
    self.ui_goto(page_soul_zones)
    self.orochi_enter()
    self.check_layer(layer)
    self.check_lock(...)

    # 定义局部函数检测是否在大蛇界面
    def is_in_orochi(screenshot=False) -> bool:
        if screenshot: self.screenshot()
        return self.appear(self.I_OROCHI_FIRE)

    # 主循环
    while 1:
        self.screenshot()
        if not is_in_orochi(): continue
        # 检查限制条件
        if self.current_count >= self.limit_count: break
        if datetime.now() - self.start_time >= self.limit_time: break
        # 点击挑战并执行战斗
        while 1:
            self.screenshot()
            if self.appear_then_click(self.I_OROCHI_FIRE, interval=1): pass
            if not self.appear(self.I_OROCHI_FIRE):
                self.run_general_battle(config=...)
                break

    # 退出返回主页
    while 1:
        if not self.appear(self.I_FORM_TEAM): break
        if self.appear_then_click(self.I_UI_BACK_YELLOW, interval=1): continue
    self.ui_current = page_soul_zones
    self.ui_goto(page_main)
```

### battle_wait() - 重写战斗等待

```python
def battle_wait(self, random_click_swipt_enable: bool) -> bool:
    self.device.stuck_record_add('BATTLE_STATUS_S')
    self.device.click_record_clear()
    # 将三个奖励点击位置命名为同一个名称以随机点击
    self.C_REWARD_1.name = 'C_REWARD'
    self.C_REWARD_2.name = 'C_REWARD'
    self.C_REWARD_3.name = 'C_REWARD'

    while 1:
        self.screenshot()
        # 点击胜利鼓（随机选择点击位置防封）
        action_click = random.choice([self.C_WIN_1, self.C_WIN_2, self.C_WIN_3])
        if self.appear_then_click(self.I_WIN, action=action_click, interval=0.8):
            continue
        # 检测贪吃鬼（特殊奖励界面）
        if self.appear(self.I_GREED_GHOST):
            self.wait_until_appear(self.I_REWARD, wait_time=1.5)
            while 1:
                if not self.appear(self.I_GREED_GHOST): break
                if self.click(random.choice([...]), interval=1.5): continue
            return True
        # 检测普通奖励界面
        if self.appear(self.I_REWARD):
            while 1:
                if self.appear_then_click(self.I_REWARD, action=random.choice([...]), interval=1.5):
                    continue
                if not self.appear(self.I_REWARD): break
            return True
        # 检测失败
        if self.appear(self.I_FALSE):
            self.ui_click_until_disappear(self.I_FALSE)
            return False
        # 随机滑动防封
        if random_click_swipt_enable:
            self.random_click_swipt()
```

### orochi_switch_soul() - 根据选层切换御魂

```python
def orochi_switch_soul(self) -> None:
    orochi_switch_soul = self.config.orochi.switch_soul
    if not orochi_switch_soul.auto_switch_soul: return

    # 根据选择的层数确定御魂配置
    layer = self.config.orochi.orochi_config.layer
    match layer:
        case Layer.TEN:      group_team = orochi_switch_soul.ten_switch
        case Layer.ELEVEN:   group_team = orochi_switch_soul.eleven_switch
        case Layer.TWELVE:   group_team = orochi_switch_soul.twelve_switch
        case Layer.THIRTEEN: group_team = orochi_switch_soul.thirteen_switch

    # 执行御魂切换
    if orochi_switch_soul.auto_switch_soul:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(group_team)
```

def is_room_dead(self) -> bool:
    sleep(0.5)
    # 如果出现匹配中或探索界面，等待0.5秒后再次确认
    if self.appear(self.I_MATCHING) or self.appear(self.I_CHECK_EXPLORATION):
        sleep(0.5)
        if self.appear(self.I_MATCHING) or self.appear(self.I_CHECK_EXPLORATION):
            return True
    return False

## 6. 设计模式总结

### 1. 策略模式 (Strategy Pattern)
- `UserStatus` 枚举决定执行哪种运行模式（Leader/Member/Alone/Wild）
- `match` 语句根据配置分发到不同的执行方法
- 每种模式封装了独立的战斗策略

### 2. 模板方法模式 (Template Method Pattern)
- `run()` 方法定义了完整的任务执行模板：切换御魂 → 初始化 → 执行战斗 → 清理
- 子方法 `run_leader()`, `run_member()` 等实现具体的战斗流程
- `battle_wait()` 重写父类方法以适配八岐大蛇的特殊奖励界面（贪吃鬼）

### 3. 组合模式 (Composition via Mixin)
- 通过多重继承组合不同能力：战斗、邀请、Buff、房间管理、UI导航
- 每个 Mixin 提供独立的功能模块，`ScriptTask` 将它们组合在一起

### 4. 状态机模式
- 界面状态通过图像识别（`appear()`）来判断
- `is_in_room()`, `is_room_dead()`, `is_in_battle()` 等方法实现状态检测
- 根据当前状态决定下一步操作

### 5. 防封机制
- 战斗过程中随机选择点击位置（`random.choice`）
- `random_click_swipt()` 随机滑动
- `stuck_record_add/clear` 卡死检测机制

### 6. 资源与逻辑分离
- 所有图像/点击/OCR资源定义在 `assets.py` 中
- 业务逻辑在 `script_task.py` 中
- 配置参数在 `config.py` 中
- 三层分离便于维护和扩展
