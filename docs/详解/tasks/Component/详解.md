# Component 通用组件 逐行代码详解

## 1. 文件概述

`Component` 目录是整个自动化框架的**通用组件库**，提供：

- **config_base.py**：基础配置类和自定义类型定义（TimeDelta、DateTime、Time 等）
- **config_scheduler.py**：任务调度器配置（启用、优先级、运行间隔等）
- **子目录**：各功能组件（战斗、邀请、房间、御魂切换等）

这些组件被所有任务模块共享和复用。

## 2. 配置参数说明

### config_base.py 自定义类型

| 类型 | 基础类型 | 说明 | 序列化格式 |
|------|----------|------|------------|
| `TimeDelta` | `timedelta` | 时间间隔 | `"DD HH:MM:SS"` |
| `DateTime` | `datetime` | 日期时间 | `"YYYY-MM-DD HH:MM:SS"` |
| `Time` | `time` | 时间 | `"HH:MM:SS"` |
| `MultiLine` | `str` | 多行文本 | JSON schema `multi_line` |

### config_scheduler.py Scheduler 配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enable` | `bool` | `False` | 是否启用该任务 |
| `next_run` | `DateTime` | `2023-01-01 00:00:00` | 下次运行时间 |
| `priority` | `int` | `5` | 任务优先级（数字越小优先级越高） |
| `success_interval` | `TimeDelta` | `1天` | 成功后的运行间隔 |
| `failure_interval` | `TimeDelta` | `1天` | 失败后的运行间隔 |
| `server_update` | `Time` | `09:00:00` | 服务器更新时间 |
| `delay_date` | `int` | `1` | 延迟天数（1-31） |
| `float_time` | `Time` | `00:00:00` | 浮动时间 |

## 3. 资源定义说明

Component 目录本身不包含 assets.py，但其子目录（如 GeneralBattle、GeneralInvite 等）各自定义了专用资源。这些资源通过继承关系被具体任务使用。

## 4. 核心代码逐行解释

### 4.1 TimeDelta 类型定义（config_base.py 第17-59行）

```python
def format_timedelta(tdelta: timedelta):
    days = tdelta.days
    hours, rem = divmod(tdelta.seconds, 3600)
    minutes, seconds = divmod(rem, 60)
    return f"{days:02d} {hours:02d}:{minutes:02d}:{seconds:02d}"
```

- **第17-21行**：将 `timedelta` 格式化为 `"DD HH:MM:SS"` 字符串格式。

```python
def datadelta_validator(v: Any) -> timedelta:
    if isinstance(v, str):
        try:
            pattern = r'(\d{1,2})\s+(\d{1,2}):(\d{1,2}):(\d{1,2})'
            match = re.match(pattern, v)
            if match:
                days = int(match.group(1))
                hours = int(match.group(2))
                minutes = int(match.group(3))
                seconds = int(match.group(4))
                return TimeDelta(days=days, hours=hours, minutes=minutes, seconds=seconds)
            return TimeDelta(days=1, hours=0, minutes=0, seconds=0)
        except ValueError:
            raise ValueError('Invalid interval value')
    return v
```

- **第23-37行**：`TimeDelta` 的验证器。将字符串格式的时间间隔解析为 `timedelta` 对象。格式：`"DD HH:MM:SS"`，解析失败默认为 1 天。

```python
TimeDelta = Annotated[timedelta,
                      BeforeValidator(datadelta_validator),
                      PlainSerializer(format_timedelta, return_type=str),
                      WithJsonSchema({'type': 'time_delta'}),]
```

- **第56-59行**：使用 Pydantic 的 `Annotated` 定义 `TimeDelta` 类型：
  - `BeforeValidator`：反序列化时先执行验证器
  - `PlainSerializer`：序列化时格式化为字符串
  - `WithJsonSchema`：自定义 JSON Schema 类型标识

### 4.2 DateTime 类型定义（config_base.py 第40-64行）

```python
def datetime_validator(v: Any) -> datetime:
    if isinstance(v, str):
        return datetime.fromisoformat(v)
    return v
```

- **第40-43行**：DateTime 验证器，将 ISO 格式字符串解析为 `datetime` 对象。

```python
DateTime = Annotated[datetime,
                     BeforeValidator(datetime_validator),
                     PlainSerializer(lambda v: v.strftime('%Y-%m-%d %H:%M:%S'), return_type=str),
                     WithJsonSchema({'type': 'date_time'}),]
```

- **第61-64行**：DateTime 类型，序列化格式为 `"YYYY-MM-DD HH:MM:SS"`。

### 4.3 ConfigBase 基类（config_base.py 第84-113行）

```python
class ConfigBase(BaseModel):
    def __init__(self, *args, **kwargs):
        try:
            super().__init__(*args, **kwargs)
        except ValidationError as exc:
            exc_info = exc.errors()[0]
            val_error_type = exc_info.get('type', None)
            val_error_key = exc_info.get('loc', None)[0]
            if val_error_type not in ['greater_than_equal', 'greater_than',
                                      'less_than', 'less_than_equal']:
                raise exc
            try:
                default_value = self.model_fields[val_error_key].default
                kwargs[val_error_key] = self.model_fields[val_error_key].default
                super().__init__(*args, **kwargs)
            except Exception as e:
                raise
```

- **第84-113行**：配置基类，继承 Pydantic 的 `BaseModel`。核心逻辑：
  1. 初始化时捕获 `ValidationError`
  2. 如果是数值范围错误（大于/小于限制），自动回退到默认值
  3. 其他类型的验证错误正常抛出
  4. 这种设计避免了用户输入略微超范围时导致整个配置加载失败

### 4.4 Scheduler 调度器配置（config_scheduler.py 第8-17行）

```python
class Scheduler(ConfigBase):
    enable: bool = Field(default=False, description='enable_help')
    next_run: DateTime = Field(default=DateTime.fromisoformat("2023-01-01 00:00:00"))
    priority: int = Field(default=5, description='priority_help')
    success_interval: TimeDelta = Field(default=TimeDelta(days=1))
    failure_interval: TimeDelta = Field(default=TimeDelta(days=1))
    server_update: Time = Field(default=Time(hour=9, minute=0, second=0))
    delay_date: int = Field(default=1, ge=1, le=31)
    float_time: Time = Field(default=Time(hour=0, minute=0, second=0))
```

- **第8-17行**：任务调度器标准配置。每个任务都有一个 Scheduler，控制：
  - 是否启用
  - 下次运行时间
  - 优先级
  - 成功/失败后的重试间隔
  - 服务器更新时间（用于避免在维护期间运行）

## 5. 任务执行流程图

```
组件配置加载流程
│
├── ConfigBase.__init__()
│   ├── Pydantic 数据验证
│   ├── 范围错误 → 回退默认值
│   └── 其他错误 → 正常抛出
│
├── 自定义类型解析
│   ├── TimeDelta: "DD HH:MM:SS" → timedelta
│   ├── DateTime: "YYYY-MM-DD HH:MM:SS" → datetime
│   └── Time: "HH:MM:SS" → time
│
└── Scheduler 调度配置
    ├── enable: 是否启用
    ├── next_run: 下次运行时间
    ├── priority: 优先级
    ├── success_interval: 成功间隔
    └── failure_interval: 失败间隔
```

## 6. 设计模式总结

| 设计模式 | 应用位置 | 说明 |
|----------|----------|------|
| **类型注解模式** | `Annotated` 类型定义 | 通过 Pydantic Annotated 实现自定义序列化/反序列化 |
| **防御性初始化** | `ConfigBase.__init__()` | 范围错误自动回退默认值，提高配置容错性 |
| **组件化架构** | Component 子目录 | 将通用功能封装为独立组件，供各任务复用 |
| **工厂模式** | `Field(default_factory=...)` | Pydantic 的默认值工厂，避免可变默认值问题 |
| **模板方法模式** | `Scheduler` | 所有任务共享相同的调度配置结构 |
