# 染色试炼任务详解

## 1. 文件概述

染色试炼（DyeTrials）是《阴阳师》游戏中的限时活动玩法（灵染试炼）。玩家通过反复挑战活动副本来获取活动奖励。该自动化脚本实现了以下功能：

- 自动切换御魂套装
- 从庭院导航进入灵染试炼活动界面
- 自动循环挑战活动副本（最多50次）
- 自动处理战斗奖励弹窗
- 战斗次数OCR监控

### 文件清单

| 文件 | 说明 |
|------|------|
| `script_task.py` | 任务主逻辑，包含活动进入和战斗循环 |
| `config.py` | 配置定义，包含御魂切换配置 |
| `assets.py` | 资源定义，包含活动入口和战斗相关图片模板 |

## 4. 核心代码逐行解释

### `ScriptTask` 类

```python
class ScriptTask(GeneralBattle, GameUi, SwitchSoul, DyeTrialsAssets):
```

继承：
- `GeneralBattle`：通用战斗能力
- `GameUi`：页面导航能力
- `SwitchSoul`：御魂切换能力
- `DyeTrialsAssets`：活动资源定义

### `run()` 方法 — 主入口

```python
def run(self):
    cfg = self.config.dye_trials

    # 自动换御魂
    if cfg.switch_soul_config.enable:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(cfg.switch_soul_config.switch_group_team)
    if cfg.switch_soul_config.enable_switch_by_name:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul_by_name(cfg.switch_soul_config.group_name, cfg.switch_soul_config.team_name)

    self.ui_get_current_page()
    self.ui_goto(page_main)

    self.get_all()

    self.ui_get_current_page()
    self.ui_goto(page_main)

    self.set_next_run(task='DyeTrials', success=True, finish=True)
    raise TaskEnd('DyeTrials')
```

**执行流程**：
1. 可选：切换御魂套装
2. 导航到主页
3. 执行 `get_all()` 进入活动并循环战斗
4. 返回主页
5. 设置下次运行时间

### `get_all()` — 活动进入与战斗循环

#### 4.1 进入活动界面

```python
def get_all(self):
    while 1:
        self.screenshot()
        if self.appear(self.I_FP_CHALLENGE):
            break
        if self.appear_then_click(self.I_FP_ACCESS, interval=0.8):
            continue
        if self.appear_then_click(self.I_FP_ACCESS_1, interval=1.5):
            continue
        if self.appear_then_click(self.I_TOGGLE_BUTTON, interval=3):
            continue
    logger.info('Enter DyeTrials')
```

**进入逻辑**：
1. 先在庭院中找到活动入口（`I_FP_ACCESS`）
2. 点击进入活动页面
3. 如果需要切换活动页面，点击切换按钮（`I_TOGGLE_BUTTON`）
4. 点击进入战斗界面（`I_FP_ACCESS_1`）
5. 直到出现"挑战"按钮（`I_FP_CHALLENGE`）表示进入成功

4. 点击"挑战"按钮开始战斗

## 6. 设计模式总结

### 6.1 活动任务通用模式

染色试炼代表了一类"限时活动"任务的通用模式：
1. 从庭院进入活动入口
2. 循环挑战活动副本
3. 处理奖励弹窗
4. 达到次数上限或超时后退出

这种模式可以复用于其他类似活动。

### 6.2 OCR次数监控

通过OCR识别战斗次数（`O_BATTLE_NUM`），实现精确的次数控制。`DigitCounter` 模式自动解析"当前/总数"格式。

### 6.3 多层超时机制

- **单次操作超时**：`interval` 参数控制每次点击的最小间隔
- **全局超时**：`boss_timer`（60秒）控制整个战斗循环的最大时间
- **卡死检测**：`stuck_record` 机制检测脚本是否卡在某个状态

### 6.4 资源复用

复用 `RestartAssets.I_HARVEST_CHAT_CLOSE`（来自Restart模块）来处理聊天关闭按钮，避免重复定义相同的资源。

### 6.5 计时器重置模式

每次成功执行操作（领取奖励、点击挑战）都重置全局超时计时器。只有连续60秒无任何有效操作才触发超时退出。
