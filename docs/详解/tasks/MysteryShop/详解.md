# 神秘商店（MysteryShop）任务详解

## 1. 文件概述

神秘商店任务是《阴阳师》手游中"神秘商店"功能的自动化脚本模块。神秘商店每周三和周六开放，玩家可以访问好友的神秘商店购买物品，并通过分享给好友获得额外奖励。

**核心功能：**
- 自动判断开放时间（周三/周六）
- 在自己的商店和好友商店之间切换购买
- 支持购买：蓝票（神秘符咒）、黑蛋碎片、太鼓 3/4 级
- 自动分享给最多 5 个好友（支持同服/跨服搜索）
- 根据购买次数领取里程碑奖励（3/5/10 次）
- 智能计算下次开放时间

**文件组成：**
| 文件 | 作用 |
|------|------|
| `script_task.py` | 任务主逻辑，含商店购买、好友切换、分享、奖励领取 |
| `config.py` | 配置模型定义（调度器、购买选项、分享好友） |
| `assets.py` | 图像/OCR 资源定义（自动生成） |

## 2. 配置参数说明

### 2.1 ShopConfig（商店配置）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `time_of_mystery` | `Time` | `00:00:00` | 神秘商店的执行时间（0 表示立即执行） |
| `mystery_amulet` | `bool` | `False` | 是否购买蓝票（神秘符咒，85 勾玉） |
| `black_daruma_scrap` | `bool` | `False` | 是否购买黑蛋碎片（60 勾玉） |
| `shop_kaiko_3` | `bool` | `False` | 是否购买太鼓 3 级（45 勾玉） |
| `shop_kaiko_4` | `bool` | `False` | 是否购买太鼓 4 级（80 勾玉） |

### 2.2 ShareConfig（分享配置）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enable` | `bool` | `False` | 是否启用分享功能 |
| `share_friend_1` ~ `share_friend_5` | `str` | `''` | 要分享的好友名称（最多 5 个） |

### 2.3 Scheduler（调度器）

继承默认调度器，无额外参数。

## 4. 核心代码逐行解释

### 4.5 `share()` 分享方法

```python
def share(self, share_config: ShareConfig = None):
    if not share_config.enable:
        return
    if share_config.share_friend_1 == '':
        return
    self.ui_click(self.I_MS_SHARE, self.I_INVITE_ENSURE)
    if not self.invite_friend(share_config.share_friend_1):
        logger.warning(f'Share friend 1 {share_config.share_friend_1} is not exist')
```
- 依次分享给配置的好友（最多 5 个）
- 每次分享：点击分享按钮 → 搜索好友 → 邀请

### 4.6 `invite_friend()` 好友搜索（重写）

```python
def invite_friend(self, name: str = None, find_mode: FindMode = FindMode.AUTO_FIND) -> bool:
    def select(name: str) -> bool:
        selected = False
        sleep(1)
        if not selected:
            if self.detect_select(name):
                selected = True
        sleep(1)
        if not selected:
            if self.detect_select(name):
                selected = True
        return selected

    selected = False
    self.ui_click_until_disappear(self.I_FLAG_1_OFF)
    selected = select(name)
    if not selected:
        self.ui_click_until_disappear(self.I_FLAG_2_OFF)
        selected = select(name)
    self.ui_click_until_disappear(self.I_INVITE_ENSURE)
```
- 先在同服好友中搜索，找不到再切换到跨服好友搜索
- 每次搜索带两次重试（`detect_select` 调用两次）

### 4.7 `shop_reward()` 里程碑奖励

```python
def shop_reward(self):
    number = self.O_MS_RECORDS.ocr(self.device.image)
    if not isinstance(number, int):
        return
    if number >= 3:
        self.ui_get_reward(self.I_MS_REWARD_3)
    if number >= 5:
        self.ui_get_reward(self.I_MS_REWARD_5)
    if number >= 10:
        self.ui_get_reward(self.I_MS_REWARD_10)
```
- OCR 识别购买次数，根据次数领取对应里程碑奖励

### 4.8 `next_time()` 调度计算

```python
def next_time(self, success: bool = True):
    target_time: time = self.config.mystery_shop.shop_config.time_of_mystery
    target_time: timedelta = timedelta(hours=target_time.hour, ...)
    if target_time == time(hour=0, minute=0, second=0):
        self.set_next_run(task='MysteryShop', success=success, finish=True)
        raise TaskEnd('MysteryShop')
    now = datetime.now()
    day_of_week = now.weekday()
    if 2 <= day_of_week <= 4:
        next_time = now_datetime + timedelta(days=5 - day_of_week) + target_time
    elif 5 <= day_of_week <= 6 or 0 <= day_of_week <= 1:
        next_time = now_datetime + timedelta(days=6 - day_of_week + 3) + target_time
```
- 如果 `time_of_mystery` 为 00:00:00，使用默认调度
- 否则根据当前星期计算下一个开放日（周三/周六）+ 目标时间

## 6. 设计模式总结

### 6.1 模板方法 + 策略模式
- `buy_mall_one()` 是模板方法，定义了购买的通用流程
- 不同商品通过传入不同的按钮/确认弹窗/OCR/价格参数实现策略差异
- `while` 循环确保每次购买都成功执行

### 6.2 状态检测模式
- 通过 OCR 识别好友名字变化来确认页面切换
- 通过分享按钮的存在与否判断当前是自己的商店还是好友的商店

### 6.3 好友搜索降级策略
- 先搜索同服好友（`I_FLAG_1_OFF`）
- 找不到再搜索跨服好友（`I_FLAG_2_OFF`）
- 每级搜索带两次重试，提高成功率

### 6.4 里程碑奖励模式
- 基于累计购买次数的阶梯式奖励
- OCR 读取次数后按阈值（3/5/10）依次领取
- 使用 `>=` 判断确保不会遗漏

### 6.5 智能调度计算
- 根据当前星期和目标时间计算精确的下次执行时间
- 支持跨周计算（周六 → 下周三）
- `time_of_mystery` 为 0 时回退到默认调度
