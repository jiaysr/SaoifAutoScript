# Restart 重启任务 逐行代码详解

## 1. 文件概述

`Restart` 模块负责游戏的**启动、登录和奖励收取**，是整个自动化流程的入口任务。它包含：

- **script_task.py**：任务入口，控制应用重启流程和定时体力领取
- **login.py**：登录处理器，处理各种登录弹窗和界面交互
- **config.py**：配置定义（收获配置、任务重置、角色选择）
- **config_scheduler.py**：调度器配置（最高优先级）
- **assets.py**：资源定义（登录界面、收获界面的图像/OCR/点击规则）

## 4. 核心代码逐行解释

### 4.1 ScriptTask 主任务（script_task.py 第16-73行）

```python
class ScriptTask(LoginHandler):
    def run(self) -> None:
        if not self.delay_pending_tasks():
            self.app_restart()
        raise TaskEnd('ScriptTask end')
```

- **第18-25行**：任务入口。先检查是否需要延迟任务（周三维护），否则执行应用重启。完成后抛出 `TaskEnd` 表示任务结束。

- **第37-44行**：应用重启流程：停止应用 → 启动应用 → 处理登录 → 设置下次运行时间。


- **第46-56行**：定时领体力逻辑。游戏每天 12-14、20-22 时各赠送 20 体力：
  - 00:00-12:00 → 设置今日 12:00 运行
  - 12:00-20:00 → 设置今日 20:00 运行
  - 20:00-23:59 → 设置次日 12:00 运行

### 4.2 周三维护延迟（script_task.py 第58-73行）

```python
    def delay_pending_tasks(self) -> bool:
        datetime_now = datetime.now()
        if not (datetime_now.weekday() == 2 and 6 <= datetime_now.hour <= 8):
            return False
        logger.info("The game server is updating, delay the pending tasks to 9:00")
        for task in self.config.pending_task:
            self.set_next_run(task=task.command, target=datetime_now.replace(hour=9, minute=0, second=0))
        self.set_next_run(task='Restart', success=True, finish=True, server=True)
        return True
```

- **第58-73行**：检测周三（weekday==2）6-8 点的服务器维护时间，将所有待处理任务延迟到 9:00。

### 4.4 登录重试机制（login.py 第150-167行）

```python
    def app_handle_login(self) -> bool:
        for _ in range(2):
            self.device.stuck_record_clear()
            self.device.click_record_clear()
            try:
                self._app_handle_login()
                if self.config.restart.harvest_config.enable:
                    self.harvest()
                return True
            except (GameTooManyClickError, GameStuckError) as e:
                logger.warning(e)
                self.device.app_stop()
                self.device.app_start()
                continue
        logger.critical('Login failed more than 3')
        raise RequestHumanTakeover
```

- **第150-167行**：登录重试机制。最多重试 2 次（共 3 次），失败后请求人工接管。登录成功后自动执行收获流程。

```python
    def harvest_mail(self) -> bool:
        if not self.appear_multi_scale(self.I_HARVEST_MAIL, scale_range=(0.8, 1.1)) and \
                not self.appear(self.I_HARVEST_MAIL_COPY):
            if not self.appear(self.I_READ_ALL_MAIL):

        # 进入邮件页面
        while 1:

            if self.appear(self.I_READ_ALL_MAIL):
                break
            if self.appear_then_click_multi_scale(self.I_HARVEST_MAIL, interval=1.5, scale_range=(0.8, 1.1)):
                continue

            if self.appear_then_click(self.I_READ_ALL_MAIL, interval=1.5):
                continue
            if self.appear_then_click(self.I_HARVEST_MAIL_ALL, interval=1.5):
                continue

        return True
```

```python
    def harvest_courtyard_affairs(self) -> bool:
        if not self.ui_click_multi_scale(self.I_NOTE, self.I_PAGE, timeout=3, scale_range=(0.8, 1.2)):
            return False
        count_success = 0
        while 1:
            self.screenshot()
```

## 6. 设计模式总结

| 设计模式 | 应用位置 | 说明 |
|----------|----------|------|
| **重试模式** | `app_handle_login()` | 登录失败自动重试，最多 3 次 |
| **超时退出** | `harvest()` 中的 `timer_harvest` | 5 秒无收获自动退出 |
| **优先级队列** | 收获循环中的处理顺序 | 按重要性依次处理各类奖励 |
| **多尺度匹配** | `appear_multi_scale()` | 适应不同分辨率的图像识别 |
| **状态机** | `_app_handle_login()` | 登录过程中的各种状态转换 |
| **防御性编程** | `delay_pending_tasks()` | 自动处理服务器维护时间 |
