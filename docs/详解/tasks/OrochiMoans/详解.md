# OrochiMoans 大蛇悲鸣 任务详解

## 1. 文件概述

**任务功能**: 大蛇悲鸣副本任务的占位/配置模块。

该模块目前是一个最小化的任务框架，仅包含配置和资源定义的骨架。大蛇悲鸣的实际战斗逻辑复用了八岐大蛇 (`Orochi`) 的代码，因为悲鸣是八岐大蛇副本的第十一层（`Layer.ELEVEN = '悲鸣'`）。

本模块可能是为未来独立化悲鸣副本逻辑而预留的接口。

**文件结构**:
- `config.py` - 配置参数定义（仅调度器）
- `assets.py` - 资源定义（空类）
- 无 `script_task.py` - 无独立任务逻辑

**注意**: 该目录下没有 `script_task.py`，说明大蛇悲鸣任务的实际执行依赖于其他模块（主要是 `Orochi` 模块中 `Layer.ELEVEN` 层的处理）。

## 2. 配置参数说明

**配置文件**: `tasks/OrochiMoans/config.py`

### OrochiMoans 配置结构

```python
class OrochiMoans(ConfigBase):
    scheduler: Scheduler = Field(default_factory=Scheduler)
```

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `scheduler` | Scheduler | 调度器配置（执行时间、间隔等） |

**说明**: 当前配置仅包含调度器，没有战斗参数、层数选择等配置。这是因为：
1. 悲鸣作为八岐大蛇的子层，战斗配置复用 `Orochi` 的 `GeneralBattleConfig`
2. 实际的悲鸣挑战在 `Orochi.run()` 中通过 `Layer.ELEVEN` 触发
3. 本模块可能仅用于在调度系统中注册"大蛇悲鸣"这个任务名称

## 6. 设计模式总结

### 1. 占位符模式 (Placeholder Pattern)
- 该模块仅提供最小化的类定义作为占位符
- 实际功能由其他模块（Orochi）提供
- 用于在任务注册系统中保留任务名称

### 2. 模块复用模式
- 悲鸣作为八岐大蛇的第十一层，完全复用 `Orochi` 的代码
- 通过枚举值 `Layer.ELEVEN = '悲鸣'` 将悲鸣映射到八岐大蛇的处理逻辑
- 避免代码重复，维护集中在一处

### 3. 预留扩展点
- 独立的 `config.py` 和 `assets.py` 为未来独立化预留了接口
- 如果未来悲鸣副本的机制与普通八岐大蛇不同，可以在此模块中添加独立逻辑
- 只需添加 `script_task.py` 并实现 `ScriptTask.run()` 即可
