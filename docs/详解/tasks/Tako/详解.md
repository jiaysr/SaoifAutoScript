# 石距任务详解

## 1. 文件概述

石距（Tako）是《阴阳师》游戏中的组队副本玩法。玩家创建房间后等待其他玩家加入，共同击败石距BOSS获取奖励。周末会变为"愤怒的石距"（奖励更丰厚）。该自动化脚本实现了以下功能：

- 自动切换御魂套装
- 自动开启/关闭金币和经验加成Buff
- 自动创建房间并等待队友加入
- 区分工作日（石距）和周末（愤怒的石距）
- 战斗结束后自动关闭Buff并设置下次运行时间

### 文件清单

| 文件 | 说明 |
|------|------|
| `script_task.py` | 任务主逻辑，包含Buff管理、房间创建、战斗执行 |
| `config.py` | 配置定义，包含Buff开关和御魂切换配置 |
| `assets.py` | 资源定义（当前为空，使用通用组件资源） |

| `buff_exp_50_click` | `bool` | `False` | 是否开启50%经验加成 |

## 4. 核心代码逐行解释

### `ScriptTask` 类

```python
class ScriptTask(GameUi, GeneralBattle, GeneralRoom, GeneralInvite, SwitchSoul):
```

继承5个通用组件基类，石距任务完全依赖通用组件，无需专属资源。

### `run()` 方法 — 主入口

#### 4.1 御魂切换

```python
conf = self.config.tako
if conf.switch_soul.enable:
    self.ui_get_current_page()
    self.ui_goto(page_shikigami_records)
    self.run_switch_soul(conf.switch_soul.switch_group_team)
if conf.switch_soul.enable_switch_by_name:
    self.ui_get_current_page()
    self.ui_goto(page_shikigami_records)
    self.run_switch_soul_by_name(conf.switch_soul.group_name, conf.switch_soul.team_name)
```

支持两种御魂切换方式：
- 按组号+队伍号切换
- 按组名+队伍名切换

#### 4.2 开启Buff

```python
conf_buff = conf.tako_config
if conf_buff.enable:
    self.ui_get_current_page()
    self.ui_goto(page_main)
    self.open_buff()
    if conf_buff.buff_gold_50_click:
        self.gold_50()
    if conf_buff.buff_gold_100_click:
        self.gold_100()
    if conf_buff.buff_exp_50_click:
        self.exp_50()
    if conf_buff.buff_exp_100_click:
        self.exp_100()
    self.close_buff()
```

导航到主页，打开Buff面板，根据配置开启对应的加成Buff。

#### 4.3 创建房间

```python
self.ui_get_current_page()
self.ui_goto(page_team)
if 5 <= self.start_time.weekday() <= 6:
    self.check_zones('喷怒的石距')
else:
    self.check_zones('石距')
if not self.create_room():
    self.exit_task()
self.ensure_public()
self.create_ensure()
```

**日期判断**：
- `weekday()` 返回 0-6（周一到周日）
- 5=周六，6=周日 → 选择"愤怒的石距"
- 其他日期 → 选择"石距"

创建房间后确保为公开房间并确认创建。

#### 4.4 等待队友并战斗

```python
wait_timer = Timer(60)
wait_timer.start()
while 1:
    self.screenshot()
    if not self.is_in_room():
        continue
    if wait_timer.reached():
        logger.warning('Wait for too long, exit')
        self.exit_room()
        break
    if not self.appear(self.I_ADD_1):
        logger.info('There is someone in the room and start the challenge')
        self.click_fire()
        self.run_general_battle()
        break
self.exit_task()
```

**等待逻辑**：
- 最多等待60秒
- 检测"添加"按钮（`I_ADD_1`）是否消失（消失表示有人加入）
- 有人加入后点击挑战按钮开始战斗
- 超时则退出房间

### `exit_task()` — 退出任务

```python
def exit_task(self):
    conf_buff = self.config.tako.tako_config
    self.ui_get_current_page()
    self.ui_goto(page_main)
    if conf_buff.enable:
        self.ui_get_current_page()
        self.ui_goto(page_main)
        self.open_buff()
        if conf_buff.buff_gold_50_click:
            self.gold_50(False)
        if conf_buff.buff_gold_100_click:
            self.gold_100(False)
        if conf_buff.buff_exp_50_click:
            self.exp_50(False)
        if conf_buff.buff_exp_100_click:
            self.exp_100(False)
        self.close_buff()
    self.set_next_run(task='Tako', success=True, finish=False)
    raise TaskEnd('Tako')
```

退出前关闭所有已开启的Buff，避免浪费加成时间。

### `battle_wait()` — 战斗等待（重写）

```python
def battle_wait(self, random_click_swipt_enable: bool) -> bool:
    self.device.stuck_record_add('BATTLE_STATUS_S')
    self.device.click_record_clear()
    logger.info("Start battle process")
    while 1:
        self.screenshot()
        if self.appear(self.I_WIN) or self.appear(self.I_REWARD):
            logger.info('Win battle')
            self.ui_click_until_disappear(self.I_WIN)
            while 1:
                self.screenshot()
                if self.appear(self.I_CHECK_MAIN) or self.appear(self.I_CHECK_TEAM):
                    break
                if self.click(self.C_REWARD_2, interval=2):
                    continue
            return True
        if self.appear(self.I_FALSE):
            logger.warning('False battle')
            self.ui_click_until_disappear(self.I_FALSE)
            return False
```

重写了通用战斗等待方法：
- 检测胜利标志（`I_WIN`或`I_REWARD`）
- 胜利后点击奖励并等待返回主界面/组队界面
- 检测失败标志（`I_FALSE`）

## 6. 设计模式总结

### 6.1 组件复用模式

石距任务是典型的"纯组件组合"任务，没有专属资源文件（`assets.py` 为空）。所有功能都通过复用通用组件（`GeneralBattle`、`GeneralRoom`等）实现。

### 6.2 条件日期分支

使用 `weekday()` 判断当前日期，选择不同的副本类型。这种简单的条件分支模式适用于周期性变化的游戏内容。

### 6.3 对称的开启/关闭模式

Buff管理采用对称模式：
- 进入时开启Buff
- 退出时关闭对应的Buff
- 使用相同的配置开关控制开启和关闭

### 6.4 方法重写

`battle_wait()` 方法重写了父类的战斗等待逻辑，适化石距战斗的特殊奖励领取流程（需要点击 `C_REWARD_2`）。

### 6.5 超时退出机制

房间等待使用60秒硬超时，避免脚本在无人匹配时无限等待。超时后直接退出房间并设置下次运行时间。
