# 契灵之境任务 (BondlingFairyland) 逐行代码详解

## 1. 文件概述

契灵之境任务用于自动刷契灵副本，捕获契灵（类似宠物系统）。该任务支持多种运行模式和契灵类型：

### 功能特性

- **探查模式**：自动刷探查副本获取契灵球
- **结契模式**：使用盘子捕获契灵（低/中/高级盘子）
- **组队支持**：队长/队员/单人/交接模式
- **自动购买**：使用鸣契石购买契灵
- **御魂切换**：针对不同契灵自动切换御魂配置

### 契灵类型

| 契灵 | 说明 |
|------|------|
| 镇墓兽 (TOMB_GUARD) | 第一批契灵 |
| 火灵 (AZURE_BASAN) | 第一批契灵 |
| 茨球 (SNOWBALL) | 第一批契灵 |
| 小黑 (LITTLE_KURO) | 第一批契灵 |
| 针女 (BONDLING_2_1) | 第二批契灵 |
| 薙魂 (BONDLING_2_2) | 第二批契灵 |
| 月魔兔 (BONDLING_2_3) | 第二批契灵 |
| 狐火 (BONDLING_2_4) | 第二批契灵 |

### 文件结构

| 文件 | 说明 |
|------|------|
| `script_task.py` | 任务入口，包含主流程和各模式实现 |
| `config.py` | 配置定义，包含模式、契灵类型、御魂切换等 |
| `assets.py` | 资源定义，包含图像、点击、OCR等规则 |
| `config_battle.py` | 战斗配置，继承自通用战斗配置 |
| `battle.py` | 战斗逻辑，处理结契战斗和捕获判定 |
| `general_invite.py` | 邀请系统，处理组队邀请逻辑 |

```python
    search_switch: str = Field(default='')                 # 探查御魂配置
    tomb_guard_switch: str = Field(default='')             # 镇墓兽御魂配置
    snowball_switch: str = Field(default='')               # 茨球御魂配置
    little_kuro_switch: str = Field(default='')            # 小黑御魂配置
    azure_basan_switch: str = Field(default='')            # 火灵御魂配置
    # ... 更多契灵御魂配置

    def get_switch_by_enum(self, bondling_enum: BondlingClass) -> tuple:
        """根据契灵类型获取对应的御魂配置"""
        return self.get_switch_by_name(f"{bondling_enum.name.lower()}_switch")

    def get_switch_by_name(self, switch_name: str) -> tuple:
        """解析御魂配置字符串（支持数字和名称两种格式）"""
        group_team = getattr(self, switch_name, None)
        if group_team is None or ',' not in group_team:
            return None, (None, None)
        group, team = group_team.split(',')
        if group.isdigit() and team.isdigit():
            return 'int', (int(group), int(team))  # 按编号切换
        return 'str', (group, team)                # 按名称切换
```

```python
def run(self):
    cong = self.config.bondling_fairyland

    # 第一步：检查契忆数量
    if cong.bondling_config.check_enable:
        self.ui_goto(page_mall, confirm_wait=2.5)
        self.ui_click(self.I_MALL_SCCALES, self.I_MALL_SCCALES_CHECK)
        self.ui_click(self.I_MALL_BONDLINGS_SURE, self.I_MALL_BONDLINGS_ON)
        cu, re, total = self.O_BL_CHECK_MONEY.ocr(self.device.image)
        if cu >= cong.bondling_config.limit_num:
            # 契忆已满，结束任务
            self.set_next_run(task='BondlingFairyland', finish=True, success=True)
            raise TaskEnd

    # 第二步：切换御魂
    self.switch_soul()

    # 第三步：前往契灵主界面
    self.ui_goto_page(page_bondling_fairyland)

    # 第四步：根据模式执行
    self.goto_ball_area(BondlingClass.get_index(cong.bondling_config.bondling_stone_class))

    if cong.bondling_config.bondling_mode == BondlingMode.MODE1:
        # 模式1：只刷探查
        self.run_search(cong.bondling_config)
        self.set_next_run(task='BondlingFairyland', finish=True, success=True)
        raise TaskEnd

    # 模式2/3/4：根据身份选择
    match cong.bondling_config.user_status:
        case UserStatus.handoff1:
            self.limit_count //= 2
            self.switch_ball()
        case UserStatus.handoff2:
            self.limit_count //= 2
            self.run_member()
            self.current_count = 0
            self.ui_goto(page_bondling_fairyland)
            self.switch_ball()
        case UserStatus.LEADER | UserStatus.ALONE:
            self.switch_ball()
        case UserStatus.MEMBER:
            self.run_member()
```

#### switch_ball() - 切换契灵球
```python
def switch_ball(self):
    cong = self.config.bondling_fairyland
    bondling_config = cong.bondling_config
    
    idx = BondlingClass.get_index(bondling_config.bondling_stone_class)
    current_ball_index = idx if idx is not None else 1
    capture_setting_checked = False

    while 1:
        # 确保在探查界面
        if not self.in_search_ui(screenshot=True):
            self.ui_goto(page_bondling_fairyland)
            continue

        if bondling_config.bondling_mode != BondlingMode.MODE1:
            # 点击球进入结契界面
            if self.ball_click(current_ball_index):
                pass
            else:
                # 没有球了，尝试购买或探查
                if self.run_stone(bondling_config.bondling_stone_enable):
                    continue  # 购买成功
                elif bondling_config.bondling_search_enable and \
                     bondling_config.user_status == UserStatus.ALONE:
                    if self.run_search(bondling_config, limit_cnt=random.randint(5, 20)):
                        continue  # 探查成功
                    else:
                        break  # 时间/次数到了
                else:
                    break  # 无法继续

            # 检查结契设置（仅第一次）
            if not capture_setting_checked:
                self.capture_setting(bondling_config.bondling_mode)
                capture_setting_checked = True

            # 执行捕捉
            if self.run_catch(bondling_config, battle_config):
                pass  # 捕捉成功
            else:
                break  # 盘子没了/时间到了/次数到了

    # 退出时回到探查界面
    while 1:
        if self.in_search_ui(): break
        if self.in_catch_ui():
            self.appear_then_click(self.I_BACK_Y, interval=1)
```

#### run_search() - 运行探查
```python
def run_search(self, bondling_config: BondlingConfig, limit_cnt: int = None):
    """
    返回值：
    - False: 超出次数/时间限制
    - True: 打满五只球或达到limit_cnt次
    """
    self.lock_team()
    while 1:
        if not self.in_search_ui(screenshot=True): continue
        
        # 检查是否达到limit_cnt
        if limit_cnt is not None and limit_cnt <= 0:
            return True
        
        # 检查次数限制
        if self.current_count >= bondling_config.limit_count:
            return False
        
        # 检查时间限制
        if datetime.now() - self.start_time >= self.limit_time:
            return False
        
        # 点击探查
        if self.click_search():
            self.run_general_battle(self.general_battle_config)
            if limit_cnt is not None:
                limit_cnt -= 1
        else:
            return True  # 五只球满了
```

#### run_catch() - 执行捕捉
```python
def run_catch(self, bondling_config: BondlingConfig, battle_config: BattleConfig):
    """
    返回值：
    - False: 盘子没了/时间到了/次数到了
    - True: 捕获成功
    """
    self.lock_team()

    # 检查盘子数量
    def check_plate_number():
        match bondling_config.bondling_mode:
            case BondlingMode.MODE2: target_plate = self.O_B_LOW_NUMBER
            case BondlingMode.MODE3: target_plate = self.O_B_MEDIUM_NUMBER
            case BondlingMode.MODE4: target_plate = self.O_B_HIGH_NUMBER
        cu, res, total = target_plate.ocr(self.device.image)
        if cu == 0 and cu + res == total:
            return False  # 没有盘子了
        return True

    # 检查契灵球数量
    def check_ball_number():
        cu, res, total = self.O_B_BALL_NUMBER.ocr(self.device.image)
        if cu == 0 and cu + res == total and total == 99:
            return False  # 没有球了
        return True

    if not check_plate_number(): return False
    if not check_ball_number(): return False

    # 开始战斗循环
    while 1:
        if self.appear(self.I_BALL_AREA):
            return True  # 捕获成功，回到探查界面
        
        if not self.in_catch_ui(): continue
        
        if not check_plate_number(): return False
        if self.current_count >= bondling_config.limit_count: return False
        if datetime.now() - self.start_time >= self.limit_time: return False

        # 根据身份选择战斗方式
        cong = self.config.bondling_fairyland
        match cong.bondling_config.user_status:
            case UserStatus.ALONE:
                self.run_alone()
                self.run_battle(battle_config, limit_count=self.limit_count)
            case _:
                if self.run_leader():
                    return True
```

```python
def capture_setting(self, mode: BondlingMode) -> None:
    if mode == BondlingMode.MODE1:
        return  # 探查模式不需要设置

    # 打开结契设置
    self.ui_click(self.I_CLICK_CAPTION, self.I_CAPTION_ENSURE, interval=1)
    
    # 启用自动结契
    self.ui_click(self.I_C_AUTO_FALSE, self.I_C_AUTO_TRUE, interval=1)
    
    # 启用极简模式
    self.ui_click(self.I_C_MINIMAL_MODE_DISABLE, self.I_C_MINIMAL_MODE_ENABLE, interval=0.8)

    # 根据模式设置盘子类型
    if mode == BondlingMode.MODE3:
        self.ui_click(self.I_C_MIDUM_FALSE, self.I_C_MIDUM_TRUE, interval=1)
        self.ui_click_until_disappear(self.I_C_FIRST_ENABLE, interval=1)      # 羁绊式神
        self.ui_click_until_disappear(self.I_C_CONTINUOUS_ENABLE, interval=1) # 连续结契
    elif mode == BondlingMode.MODE2:
        self.ui_click(self.I_C_LOW_FALSE, self.I_C_LOW_TRUE, interval=1)
        self.ui_click_until_disappear(self.I_C_FIRST_DISABLE, interval=1)
        self.ui_click_until_disappear(self.I_C_CONTINUOUS_DISABLE, interval=1)
    elif mode == BondlingMode.MODE4:
        self.ui_click(self.I_C_HIGH_FALSE, self.I_C_HIGH_TRUE, interval=1)

    self.ui_click_until_disappear(self.I_CAPTION_ENSURE, interval=1)
```

```python
def ball_click(self, index: int) -> bool:
    """点击球进入结契战斗界面"""
    def get_click_target(ind: int):
        match = {
            1: self.C_STONE_1, 2: self.C_STONE_2, 3: self.C_STONE_3,
            4: self.C_STONE_4, 5: self.C_STONE_5,
        }
        return match[(ind - 1) % 4 + 1]  # 循环映射1-4

    click_target = get_click_target(index)
    click_count = 0
    while 1:
        if self.appear(self.I_BALL_HELP):
            return True  # 成功进入结契界面
        if click_count >= 3:
            return False  # 点击3次仍无法进入
        if self.click(click_target, interval=1):
            click_count += 1
```

```python
def run_battle(self, battle_config: BattleConfig, limit_count: int = None) -> bool:
    self.current_count += 1
    logger.info(f'Current count: {self.current_count} / {limit_count}')
```

#### catch_battle_wait() - 战斗等待（重写）
```python
def catch_battle_wait(self, random_click_swipt_enable: bool) -> bool:
    """
    重写战斗等待逻辑，处理结契特有的捕获判定
    返回：捕获成功返回True，否则返回False
    """
    win: bool = False
    bondling_mode = self.config.bondling_fairyland.bondling_config.bondling_mode
    cap_again = bondling_mode in [BondlingMode.MODE3, BondlingMode.MODE4]  # 中/高级盘子支持连续结契
    cap_cnt, max_cap = 0, 10  # 最多连续结契10次

    while 1:
        if cap_cnt >= max_cap:
            cap_again = False  # 超过最大次数，不再连续

        # 捕获成功
        if self.appear_then_click(self.I_CAP_SUCCESS, action=self.C_CAP_SUCCESS, interval=1):
            win = True
        
        # 连续结契捕获失败
        if self.appear_then_click(self.I_CAP_FAILURE, action=self.C_CAP_SUCCESS, interval=1):
            win = False
        
        # 非连续结契且单次抓捕失败
        if not cap_again and self.appear_then_click(self.I_BATTLE_FAIL_ABANDON, interval=1):
            win = False
        
        # 连续结契则继续
        if cap_again and self.appear_then_click(self.I_CAP_AGAIN, interval=1):
            cap_cnt += 1
            continue
        
        # 领取奖励
        if self.appear(self.I_REWARD, threshold=0.6):
            break
        if self.appear_then_click(self.I_WIN, threshold=0.6): continue
        if self.appear_then_click(self.I_BATTLE_SUCCESS, threshold=0.6, interval=1): continue
        if self.appear_then_click(self.I_BATTLE_FAIL, threshold=0.6, interval=1): continue

        # 随机点击防封
        if random_click_swipt_enable:
            self.random_click_swipt()

    # 领取奖励
    while 1:
        action_click = random.choice([self.C_REWARD_1, self.C_REWARD_2, self.C_REWARD_3])
        if self.appear_then_click(self.I_REWARD, action=action_click, interval=1.5): continue
        if not self.appear(self.I_REWARD): break

    return win
```

#### run_invite() - 邀请入口
```python
def run_invite(self, config: InviteConfig, is_first: bool = False, is_over: bool = True) -> bool:
    """
    队长在组队界面邀请好友
    返回：成功时进入战斗，失败时退出房间
    """
    if not self.ensure_enter(): return False

    if is_first:
        # 第一次：设置房间类型、邀请好友
        self.timer_invite = Timer(20)
        self.timer_invite.start()
        self.ensure_room_type(config.invite_number)
        self.invite_friends(config)
    else:
        self.timer_invite = Timer(30)
        self.timer_invite.start()

    # 等待循环
    wait_second = config.wait_time.second + config.wait_time.minute * 60
    self.timer_wait = Timer(wait_second)
    self.timer_wait.start()

    while 1:
        if self.timer_wait.reached(): return False  # 等待超时
        if self.appear(self.I_MATCHING): return False  # 房间已不存在

        if not self.is_in_room(): continue

        # 判断是否可以开始挑战
        fire = False
        if self.room_type == RoomType.NORMAL_2 and not self.appear(self.I_ADD_1):
            fire = True  # 两人房间且已有队友

        if fire:
            if is_over:
                self.click_fire()
                return True
            else:
                return True

        # 定时重新邀请
        if self.timer_invite and self.timer_invite.reached():
            self.timer_invite.reset()
            self.invite_friends(config)
```

#### check_room_type() - 检查房间类型
```python
def check_room_type(self, image=None, pre_type=None) -> RoomType:
    """通过图像匹配判断房间类型"""
    def check_2(img):
        return self.I_ADD_1.match(img) and not self.I_ADD_2.match(img)
    
    def check_3(img):
        return self.I_ADD_1.match(img) and self.I_ADD_2.match(img)
    
    def check_5(img):
        return self.I_ADD_5_1.match(img) and self.I_ADD_5_2.match(img) and \
               self.I_ADD_5_3.match(img) and self.I_ADD_5_4.match(img)
    
    def check_eternity_sea(img):
        return self.I_LOCK_SEA.match(img) or self.I_UNLOCK_SEA.match(img)

    # 按优先级检查
    if check_2(image): return RoomType.NORMAL_2
    if check_3(image): return RoomType.NORMAL_3
    if check_5(image): return RoomType.NORMAL_5
    if check_eternity_sea(image): return RoomType.ETERNITY_SEA
    return None
```

## 6. 设计模式总结

### 6.1 状态机模式
- `in_search_ui()` / `in_catch_ui()` / `is_in_room()` 检测当前状态
- 主循环根据状态决定下一步操作

### 6.2 策略模式
- `BondlingMode` 定义不同运行策略
- `UserStatus` 定义不同身份的处理逻辑
- `capture_setting()` 根据模式配置不同的结契参数

### 6.3 组合模式
- 多重继承组合功能：
  - `GameUi` - UI导航
  - `GeneralInvite` - 邀请系统
  - `GeneralRoom` - 房间管理
  - `BondlingBattle` - 战斗逻辑
  - `SwitchSoul` - 御魂切换
  - `BondlingFairylandAssets` - 资源定义

### 6.4 模板方法模式
- `run_battle()` 定义战斗骨架
- `catch_battle_wait()` 重写等待逻辑以处理结契特有判定

### 6.5 资源驱动模式
- 所有UI元素在 `assets.py` 中声明
- 配置在 `config.py` 中定义
- 代码逻辑与具体资源解耦

### 6.6 容错机制
- **超时检测**：防止无限等待
- **次数限制**：防止过度消耗资源
- **数量检查**：盘子/契灵球/契忆数量检查
- **状态回退**：退出时确保回到正确的界面

### 6.7 交接模式
- `handoff1`：队长完成一半后切换为队员
- `handoff2`：队员完成一半后切换为队长
- 实现了灵活的角色切换机制
