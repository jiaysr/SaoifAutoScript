# 百鬼夜行 (Hyakkiyakou) 任务详解

## 1. 文件概述

百鬼夜行是《阴阳师》中的一个限时活动玩法，玩家通过向式神投掷豆子来捕获它们。本任务实现了**全自动百鬼夜行**功能，核心特点：

- **AI目标检测**：使用 `oashya` 库（基于ONNX Runtime）实时检测屏幕上出现的式神
- **智能决策**：`Agent` 根据式神稀有度权重和优先级策略决定是否投掷豆子
- **自动选王**：在鬼王选择界面，自动识别三个候选的稀有度并选择最高稀有度
- **好友邀请**：可选自动邀请好友参与
- **调试支持**：支持实时画面展示、持续学习（保存训练图片）、结果截图

### 文件清单

| 文件 | 用途 |
|------|------|
| `script_task.py` | 任务主入口，包含战斗循环和决策执行 |
| `config.py` | 配置参数定义（Pydantic模型） |
| `assets.py` | UI资源定义（图片、点击、滑动、OCR规则） |
| `debugger.py` | 调试工具，支持实时画面展示和持续学习 |

### 2.1 HyakkiyakouConfig — 百鬼夜行核心配置

```python
class HyakkiyakouConfig(ConfigBase):
    hya_limit_time: Time = Field(default=Time(minute=20))      # 运行时长限制，默认20分钟
    hya_limit_count: int = Field(default=10)                    # 运行次数限制，默认10次

    hya_priorities: str = Field(default='')                     # 自定义优先级（逗号分隔的式神名）
    hya_sp: float = Field(default=1.0)                          # SP式神投掷权重（0~1）
    hya_ssr: float = Field(default=1.0)                         # SSR式神投掷权重
    hya_sr: float = Field(default=0.7)                          # SR式神投掷权重
    hya_r: float = Field(default=0.3)                           # R式神投掷权重
    hya_n: float = Field(default=0.0)                           # N式神投掷权重
    hya_g: float = Field(default=0.0)                           # 呱太投掷权重
```

**权重机制**：权重值范围 0~1，代表对该稀有度式神的投掷概率。SP/SSR默认满权重，SR为0.7，R为0.3，N和呱太为0（不投）。

#### 4.1.4 `tracker` 属性 (第55-77行)

```python
@cached_property
def tracker(self) -> Tracker:
    # 从配置读取模型参数
    hyakkiyakou_models = self._config.hyakkiyakou_models
    conf = hyakkiyakou_models.conf_threshold    # 置信度阈值
    nms = hyakkiyakou_models.iou_threshold      # NMS阈值
    # 参数校验：范围必须在 [0.2, 1]
    if conf < 0.2 or conf > 1:
        raise RequestHumanTakeover('conf_threshold should be in [0.2, 1]')
    if nms < 0.2 or nms > 1:
        raise RequestHumanTakeover('iou_threshold should be in [0.2, 1]')
    # 解析推理引擎和精度
    inf_en = 'onnxruntime' if ... == InferenceEngine.ONNXRUNTIME else 'tensorrt'
    precision = 'fp32' if ... == ModelPrecision.FP32 else 'int8'
    # 目前仅支持 onnxruntime + FP32
    if inf_en == 'tensorrt' or precision == 'int8':
        raise RequestHumanTakeover('Only support onnxruntime and FP32 now')
    # 构造参数字典并创建 Tracker 实例
    args = {
        'conf_threshold': conf,
        'iou_threshold': nms,
        'precision': precision,
        'inference_engine': inf_en,
        'debug': debug_info,
    }
    return Tracker(args=args)
```

**关键点**：`@cached_property` 确保 Tracker 只创建一次，后续访问直接返回缓存实例。Tracker 是 `oashya` 库提供的目标跟踪器，内部封装了 YOLO 检测模型和目标跟踪算法。

```python
@cached_property
def agent(self) -> Agent:
    hya_config = self._config.hyakkiyakou_config
    # 读取各稀有度权重
    sp = hya_config.hya_sp
    ssr = hya_config.hya_ssr
    sr = hya_config.hya_sr
    r = hya_config.hya_r
    n = hya_config.hya_n
    g = hya_config.hya_g
    weights: list = [sp, ssr, sr, r, n, g]  # 权重列表：[SP, SSR, SR, R, N, G]
    # 解析自定义优先级字符串
    str_priorities: str = hya_config.hya_priorities
    if str_priorities == '':
        priorities = []
    else:
        str_priorities = str_priorities.replace(' ', '').replace('，', ',')  # 兼容中文逗号
        try:
            priorities = [label2id(s) for s in str_priorities.split(',')]  # 将名称转为类别ID
        except Exception as e:
            logger.error(f'Priority error: {str_priorities}')
            raise RequestHumanTakeover
    # 构造策略字典
    strategy: dict = {
        'weights': weights,              # 稀有度权重
        'priorities': priorities,        # 自定义优先级（特定式神优先）
        'invite_friend': hya_config.hya_invite_friend,  # 是否邀请好友
        'auto_bean': hya_config.hya_auto_bean            # 是否自动调整豆子
    }
    return Agent(strategy=strategy)
```

**Agent** 是决策核心，根据检测到的式神和策略决定是否投掷、投向谁。

```python
def run(self):
    hya_count: int = 0
    self.limit_count: int = self._config.hyakkiyakou_config.hya_limit_count  # 次数限制
    limit_time = self._config.hyakkiyakou_config.hya_limit_time
    self.limit_time: timedelta = timedelta(hours=limit_time.hour, ...)       # 时间限制

    # 导航到百鬼夜行页面
    self.ui_goto_page(page_onmyodo)                           # 先切换到阴阳术页面
    self.switch_onmyoji(self._config...hya_onmyoji)           # 切换指定阴阳师
    self.ui_goto_page(page_hyakkiyakou)                       # 进入百鬼夜行页面

    # 主循环：执行百鬼夜行
    while 1:
        if hya_count >= self.limit_count:                     # 次数达到上限
            break
        if datetime.now() - self.start_time >= self.limit_time:  # 时间达到上限
            break
        self.one()                                            # 执行一局百鬼夜行
        hya_count += 1
        logger.info(f'count: {hya_count}/{self.limit_count}')

    # 等待并关闭结算界面
    while 1:
        self.screenshot()
        if not self.appear(self.I_HACCESS):                   # 等待出现进入按钮
            continue
        if self.appear(self.I_HCLOSE_RED):                    # 等待出现关闭按钮
            break
    self.ui_click_until_disappear(self.I_HCLOSE_RED)          # 点击关闭
    self.set_next_run(task='Hyakkiyakou', success=True, finish=False)  # 设置下次运行时间
    raise TaskEnd                                             # 抛出任务结束异常
```

#### 4.1.8 `_rarity_score()` 稀有度评分 (第155-180行)

```python
def _rarity_score(self, class_id: int) -> int:
    """
    返回稀有度分数：SP=5 > SSR=4 > SR=3 > R=2 > N=1 > G=0
    其他（buff/未收录）返回 -1
    """
    if CI.MIN_G <= class_id <= CI.MAX_G:     return 0   # 呱太
    if CI.MIN_N <= class_id <= CI.MAX_N:     return 1   # N卡
    if (CI.MIN_R <= class_id <= CI.MAX_R) and class_id not in (CI.R_007, CI.R_008):
        return 2   # R卡（排除童男/童女，它们是特殊buff）
    if CI.MIN_SR <= class_id <= CI.MAX_SR:   return 3   # SR
    if CI.MIN_SSR <= class_id <= CI.MAX_SSR: return 4   # SSR
    if CI.MIN_SP <= class_id <= CI.MAX_SP:   return 5   # SP
    return -1  # 其他（buff等）
```

**设计意图**：通过 `CLASSINDEX`（CI）常量定义的ID范围来判断式神稀有度，用于鬼王选择。

#### 4.1.9 `_detect_current_rarity()` 当前截图稀有度检测 (第182-206行)

```python
def _detect_current_rarity(self) -> tuple[int, int]:
    self.screenshot()                                          # 截取当前画面
    tracks = self.tracker(image=self.device.image, response=[0, 0, False, 10])  # 运行检测
    best_score = -1
    best_class = -1
    for _id, _class, _conf, _cx, _cy, _w, _h, _v in tracks:  # 遍历所有检测结果
        score = self._rarity_score(_class)                     # 获取稀有度分数
        if score > best_score:
            best_score = score
            best_class = _class
    return best_score, best_class                              # 返回最高稀有度
```

#### 4.1.10 `_select_best_boss()` 自动选王 (第208-237行)

```python
def _select_best_boss(self):
    """在鬼王选择界面，依次点击三个候选，检测稀有度，最终选择最高的"""
    candidates = [self.C_HSELECT_1, self.C_HSELECT_2, self.C_HSELECT_3]
    best_idx = 0
    best_score = -1
    scores = []

    for idx, btn in enumerate(candidates):
        self.click(btn, interval=0.1)        # 点击第idx个候选
        time.sleep(1)                         # 等待界面刷新
        score, cls = self._detect_current_rarity()  # 检测当前显示的式神稀有度
        scores.append(score)
        if score > best_score:
            best_score = score
            best_idx = idx

    logger.info(f'Hyakki select scores: {scores}, choose index {best_idx + 1}')
    self._best_boss_button = candidates[best_idx]  # 记录最佳按钮
    self.click(self._best_boss_button, interval=0.1)  # 再次点击确保选中
    time.sleep(0.5)
```

**注意**：如果三个候选都识别失败（score全为-1），默认选择第一个。

#### 4.1.11 `one()` 单局百鬼夜行 (第239-311行)

```python
def one(self):
    self.reset_state()                                           # 重置状态
    if not self.appear(self.I_HACCESS):                         # 检查页面
        logger.warning('Page Error')
    if self._config.hyakkiyakou_config.hya_invite_friend:
        self.invite_friend()                                     # 邀请好友

    # 进入鬼王选择界面
    self.ui_click(self.I_HACCESS, self.I_HSTART, interval=2)   # 点击"进入"直到出现"开始"
    self.wait_until_appear(self.I_HTITLE)                       # 等待标题出现

    # 自动选择最佳鬼王
    self._best_boss_button = None
    self._select_best_boss()

    # 确认开始战斗
    while 1:
        self.screenshot()
        if not self.appear(self.I_HTITLE):                      # 标题消失 = 进入战斗
            break
        if self.appear_then_click(self.I_HSTART, interval=2):   # 点击开始
            continue
        if not self.appear(self.I_HSELECTED) and self._best_boss_button is not None:
            self.click(self._best_boss_button, interval=2)      # 保险：重新点击选中
            continue

    self.device.stuck_record_add('BATTLE_STATUS_S')             # 添加卡死检测记录
    logger.hr('Start Hyakkiyakou')

    # 战斗主循环
    init_bean_flag: bool = False
    last_action = [0, 0, False, 10]                             # 初始动作：[x, y, throw, bean]
    self.hya_fs_check_timer.reset()

    while 1:
        self.fast_screenshot(screenshot=...)                     # 快速截图
        if self.appear(self.I_HEND):                            # 检测到结束
            break
        if not self.appear(self.I_CHECK_RUN):                   # 不在砸豆子状态
            continue
        if not init_bean_flag:                                  # 首次进入，调整豆子数量
            init_bean_flag = True
            self.bean_05to10()                                  # 将豆子从0.5调到10
            time.sleep(0.5)

        # 核心决策循环
        if not self.appear(self.I_HFREEZE):                     # 非冰冻状态
            freeze = self.appear(self.I_HFREEZE)
            self.slave_state = self.update_state()              # 更新状态（豆子数等）
            tracks = self.tracker(image=self.device.image, response=last_action)  # AI检测
            last_action = self.agent.decision(tracks=tracks, state=self.slave_state, freeze=freeze)  # 决策
            self.do_action(last_action, state=self.slave_state) # 执行动作
        else:
            tracks = []                                         # 冰冻状态暂不处理

        # 调试：实时展示
        if self._config.debug_config.hya_show:
            draw_image = draw_tracks(self.device.image, tracks=tracks)
            self.debugger.show_sync(image=draw_image)
        # 调试：持续学习
        if self._config.debug_config.continuous_learning:
            self.debugger.deal_learning(image=self.device.image, tracks=tracks)
        # 调试：信息输出
        if self._config.debug_config.hya_info:
            self.debugger.show_info(tracker=self.tracker, f=self.agent.focus)

    # 战斗结束处理
    logger.info('Hyakkiyakou End')
    if self._config.debug_config.hya_show:
        self.debugger.show_stop()
    if self._config.debug_config.hya_save_result:
        time.sleep(2)
        self.debugger.save_result(self.device.image)
    self.ui_click(self.I_HEND, self.I_HACCESS)                  # 点击结束回到入口
    self.debugger.save_images()                                  # 保存持续学习图片
    del self.debugger
    self.tracker.clear_tracks()                                  # 清除跟踪状态
```

#### 4.1.12 `do_action()` 执行投掷 (第313-319行)

```python
def do_action(self, action: list, state):
    x, y, throw, bean = action       # 解包动作：坐标、是否投掷、豆子数
    if not throw:                     # 不需要投掷
        return
    if state[0] <= 0:                # 豆子数为0
        return
    self.fast_click(x=x, y=y, control_method=self._config.debug_config.hya_control_method)
```

## 6. 设计模式总结

### 6.1 多重继承组合模式

`ScriptTask` 通过多重继承组合了 `GameUi`（UI操作）、`HyaSlave`（战斗操作）、`SwitchOnmyoji`（阴阳师切换）三个能力模块，遵循**组合优于继承**的思想（虽然语法上是继承，但本质是功能组合）。

### 6.2 缓存属性模式 (Cached Property)

`tracker`、`agent`、`debugger` 均使用 `@cached_property`，确保：
- 延迟初始化：只在首次访问时创建
- 单例效果：整个任务生命周期内只创建一次
- 避免重复计算：模型加载等重操作只执行一次

### 6.3 感知-决策-执行 (Perception-Decision-Action) 循环

战斗核心采用经典的 PDA 架构：
1. **感知 (Perception)**：`tracker(image)` 运行YOLO检测，获取式神位置和类别
2. **决策 (Decision)**：`agent.decision(tracks, state, freeze)` 根据策略决定动作
3. **执行 (Action)**：`do_action(action)` 在指定坐标点击投掷

### 6.4 状态机模式

整个任务流程是一个隐式状态机：
- 页面导航状态：主界面 → 阴阳术 → 百鬼夜行 → 鬼王选择 → 战斗 → 结算
- 通过图片匹配 (`appear`) 检测当前状态并转换

### 6.5 策略模式 (Strategy Pattern)

`Agent` 的行为由 `strategy` 字典驱动，不同权重和优先级配置产生不同的决策行为，无需修改 `Agent` 内部逻辑。

### 6.6 调试器分离模式

`Debugger` 类独立于主逻辑，通过配置开关控制是否启用。支持：
- 实时画面展示（独立线程 + `cv2.imshow`）
- 持续学习数据收集
- 结果截图保存
- 信息表格输出（Rich库）

### 6.7 异常驱动的流程控制

使用 `TaskEnd` 异常作为任务结束信号，`RequestHumanTakeover` 作为需要人工干预的信号，这是一种**异常驱动设计**，简化了深层调用栈中的流程控制。
