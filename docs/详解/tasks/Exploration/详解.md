# 探索任务 (Exploration) 逐行代码详解

## 1. 文件概述

探索任务是阴阳师自动化脚本中的核心肝帝任务，用于自动刷探索副本（如困难28章）以获取经验、金币和达摩等资源。该任务支持三种运行模式：

- **单人模式 (ALONE)**：独自刷探索，自动寻怪、战斗、拾取奖励
- **队长模式 (LEADER)**：创建队伍并邀请好友，组队刷探索
- **队员模式 (MEMBER)**：接受队长邀请，跟随队长进行探索

### 文件结构

| 文件 | 说明 |
|------|------|
| `script_task.py` | 任务入口，继承自 `SoloScriptTask` |
| `config.py` | 配置定义，包含探索等级、战斗次数、加成等参数 |
| `assets.py` | 资源定义，包含图像匹配、点击坐标、OCR等规则 |
| `base.py` | 基础探索逻辑，场景识别、候补式神管理、UP怪搜索 |
| `solo.py` | 三种运行模式的核心实现（solo/leader/member） |
| `version.py` | 高亮检测相关，用于识别探索中的特殊标记 |

#### 场景识别 (`get_current_scene`)
```python
def get_current_scene(self, reuse_screenshot: bool = True) -> Scene:
    if not reuse_screenshot:
        self.screenshot()  # 重新截图

    if self.appear(self.I_CHECK_EXPLORATION) and not self.appear(self.I_E_SETTINGS_BUTTON):
        return Scene.WORLD          # 探索大世界
    elif self.appear(self.I_E_EXPLORATION_CLICK):
        return Scene.ENTRANCE       # 入口弹窗
    elif self.appear(self.I_E_SETTINGS_BUTTON) or self.appear(self.I_E_AUTO_ROTATE_ON) or \
         self.appear(self.I_E_AUTO_ROTATE_OFF):
        return Scene.MAIN           # 探索内部
    elif self.is_in_prepare():
        return Scene.BATTLE_PREPARE # 战斗准备
    elif self.is_in_battle():
        return Scene.BATTLE_FIGHTING # 战斗中
    elif self.is_in_room() or self.appear(self.I_CREATE_ENSURE):
        return Scene.TEAM           # 组队界面
    
    return Scene.UNKNOWN
```
- **逻辑**：通过图像匹配判断当前处于哪个界面
- **优先级**：从最具体的场景开始判断，最后才是未知

#### 打开指定章节 (`open_expect_level`)
```python
def open_expect_level(self):
    swipeCount = 0
    while 1:
        self.screenshot()
        # OCR识别当前显示的章节
        results = self.O_E_EXPLORATION_LEVEL_NUMBER.detect_and_ocr(self.device.image)
        text1 = [result.ocr_text for result in results]
        # 修复OCR误识别（"名"→"第", "书"→"第"）
        text1 = [text.replace("名", "第").replace("书", "第") for text in text1]
        # 检查是否包含目标章节
        result = set(text1).intersection({explorationConfig.exploration_config.exploration_level})
        
        if self.appear(self.I_E_EXPLORATION_CLICK) or result and len(result) > 0:
            break  # 找到目标章节
        
        # 向上滑动查找
        self.swipe(self.S_SWIPE_LEVEL_UP)
        swipeCount += 1
        if swipeCount >= 15:
            raise GameStuckError("滑动次数过多，可能卡住")
        time.sleep(1)

    # 选中对应章节
    while 1:
        self.O_E_EXPLORATION_LEVEL_NUMBER.keyword = explorationConfig.exploration_config.exploration_level
        if self.ocr_appear_click(self.O_E_EXPLORATION_LEVEL_NUMBER):
            self.wait_until_appear(self.I_E_EXPLORATION_CLICK, wait_time=3)
        if self.appear(self.I_E_EXPLORATION_CLICK):
            break
```
- **算法**：OCR识别 + 滑动查找 + 点击选中
- **容错**：处理OCR误识别、滑动超时

```python
def add_shiki(self, screenshot=True):
```

#### 搜索UP怪 (`search_up_fight`)
```python
def search_up_fight(self, up_type: UpType = None):
    if up_type is None:
        up_type = self._config.exploration_config.up_type
    
    # 1. 如果选择了特定UP类型
    if up_type != UpType.ALL:
        match up_type:
            case UpType.EXP: find_flag = self.I_UP_EXP
            case UpType.COIN: find_flag = self.I_UP_COIN
            case UpType.DARUMAA: find_flag = self.I_UP_DARUMA
        
        if self.appear(find_flag):
            x, y, w, h = find_flag.roi_front
            x_center, y_center = find_flag.front_center()
            
            # 2. 缩小搜索范围（在UP图标上方找战斗按钮）
            roi_back_y = max(0, y - 300)
            roi_back_h = y - 20 - roi_back_y
            roi_back_x = max(0, x - 60)
            roi_back_w = min(1280, x + w + 60) - roi_back_x
            
            # 3. 匹配所有战斗按钮
            matches = self.I_NORMAL_BATTLE_BUTTON.match_all(
                image=self.device.image, threshold=0.9,
                roi=[roi_back_x, roi_back_y, roi_back_w, roi_back_h]
            )
            
            if matches:
                # 4. 计算加权距离，找最近的
                distances = []
                for match in matches:
                    x_match = match[1] + match[3] / 2
                    y_match = match[2] + match[4] / 2
                    x_diff = abs(x_center - x_match)
                    y_diff = abs(y_center - y_match)
                    weighted_distance = (x_diff * 3) + y_diff  # X方向权重更高
                    distances.append((weighted_distance, match))
                
                distances.sort(key=lambda x: x[0], reverse=False)
                match = distances[0][1]
                roi_front = list(match[1:])
                self.I_NORMAL_BATTLE_BUTTON.roi_front = roi_front
                return self.I_NORMAL_BATTLE_BUTTON
        else:
            return None  # 没找到UP图标

    # 5. 默认情况：有怪就打
    if self.appear(self.I_NORMAL_BATTLE_BUTTON):
        return self.I_NORMAL_BATTLE_BUTTON
    return None
```
- **算法**：UP图标定位 → 缩小ROI → 多目标匹配 → 加权距离排序
- **优化**：X方向权重3倍，确保找到正上方的怪

#### 退出检测 (`check_exit`)
```python
def check_exit(self) -> bool:
    # 1. 战斗次数达到限制
    if self.minions_cnt >= self._config.exploration_config.minions_cnt:
        return True
    # 2. 时间达到限制
    if datetime.now() - self.start_time >= self.limit_time:
        return True
    # 3. 突破票检测（可能触发任务切换）
    self.activate_realm_raid(self._config.scrolls, self._config.exploration_config)
    return False
```

```python
class ScriptTask(SoloExploration):
    def run(self):
        logger.hr('exploration')
        # 1. 未知场景处理（随机点击尝试恢复）
        random_click_cnt = 0
        while 1:
            self.screenshot()
            scene = self.get_current_scene()
            if random_click_cnt >= 2:
                break
            if scene == Scene.UNKNOWN:
                if self.click(self.C_SAFE_RANDOM, interval=1.5):
                    random_click_cnt += 1
                continue
            else:
                break

        # 2. 如果仍是未知场景，执行前置处理
        if scene == Scene.UNKNOWN:
            self.pre_process()

        # 3. 根据用户身份选择运行模式
        match self._config.exploration_config.user_status:
            case UserStatus.ALONE: self.run_solo()
            case UserStatus.LEADER: self.run_leader()
            case UserStatus.MEMBER: self.run_member()
            case _: self.run_solo()

        # 4. 后置处理
        self.post_process()
```

```python
def run_solo(self):
    explore_init = False
    search_fail_cnt = 0

    while 1:
        self.screenshot()
        scene = self.get_current_scene()
        
        if scene == Scene.WORLD:
            # 大世界：稳定检测 → 宝箱拾取 → 退出检测 → 打开章节
            if not self.wait_world_stable(): continue
            if self.appear(self.I_TREASURE_BOX_CLICK):
                self.ui_click_until_disappear(self.I_TREASURE_BOX_CLICK)
            if self.check_exit(): break
            self.open_expect_level()
            explore_init = False

        elif scene == Scene.ENTRANCE:
            # 入口：点击探索按钮进入
            if self.check_exit(): break
            self.ui_click(self.I_E_EXPLORATION_CLICK, stop=self.I_E_SETTINGS_BUTTON)

        elif scene == Scene.MAIN:
            # 探索内部：初始化 → 拾取奖励 → 打Boss → 打小怪 → 滑动寻怪
            if not explore_init:
                self.ui_click(self.I_E_AUTO_ROTATE_OFF, stop=self.I_E_AUTO_ROTATE_ON)
                if self._config.exploration_config.auto_rotate == AutoRotate.yes:
                    self.enter_settings_and_do_operations()
                explore_init = True
                continue
            
            if self.appear(self.I_BATTLE_REWARD):  # 小纸人奖励
                if self.ui_get_reward(self.I_BATTLE_REWARD): continue
            
            if self.appear(self.I_BOSS_BATTLE_BUTTON):  # Boss
                if self.fire(self.I_BOSS_BATTLE_BUTTON): continue
            
            fight_button = self.search_up_fight()  # 小怪
            if fight_button is not None:
                if self.fire(fight_button): continue
            
            if search_fail_cnt >= 4:  # 滑动寻怪
                search_fail_cnt = 0
                if self._match_end.stable(self.device.image):
                    self.quit_explore()  # 到达地图尽头
                    continue
                if self.swipe(self.S_SWIPE_BACKGROUND_RIGHT, interval=3): continue
            else:
                search_fail_cnt += 1

        elif scene == Scene.BATTLE_PREPARE or scene == Scene.BATTLE_FIGHTING:
            self.check_take_over_battle(is_screenshot=False, ...)
```

```python
def highlight(image):
    # 1. 转换到YUV色彩空间，提取U通道
    yuv = cv2.cvtColor(image, cv2.COLOR_RGB2YUV)
    _, u, _ = cv2.split(yuv)
    cv2.subtract(128, u, dst=u)
    cv2.multiply(u, 8, dst=u)  # 增强U通道对比度

    # 2. 计算与白色的相似度
    color = color_similarity_2d(image, color=(255,255,255))

    # 3. 转换到HSV，提取V通道（亮度）
    hsv = cv2.cvtColor(image, cv2.COLOR_RGB2HSV)
    _, _, v = cv2.split(hsv)

    # 4. 应用多重掩码
    image = apply_mask(image, u)
    image = apply_mask(image, color)
    image = apply_mask(image, v)

    # 5. 增强对比度并反转
    cv2.convertScaleAbs(image, alpha=3, dst=image)
    cv2.subtract((255, 255, 255, 0), image, dst=image)

    return image
```
- **目的**：提取探索地图上怪物的高亮标记
- **算法**：YUV色彩空间分析 + 白色相似度 + HSV亮度掩码

## 6. 设计模式总结

### 6.1 状态机模式
- 使用 `Scene` 枚举定义有限状态
- `get_current_scene()` 作为状态检测器
- 主循环根据状态分发处理逻辑

### 6.2 模板方法模式
- `BaseExploration` 定义了探索的骨架流程
- `SoloExploration` 和 `ScriptTask` 实现具体变体
- `pre_process()` 和 `post_process()` 提供扩展点

### 6.3 策略模式
- `run_solo()` / `run_leader()` / `run_member()` 封装不同策略
- 通过 `user_status` 配置动态选择策略

### 6.4 组合模式
- 通过多重继承组合功能模块：
  - `GameUi` - UI导航
  - `GeneralBattle` - 通用战斗
  - `GeneralRoom` - 房间管理
  - `GeneralInvite` - 邀请系统
  - `SwitchSoul` - 御魂切换
  - `ExplorationAssets` - 资源定义

### 6.5 资源驱动模式
- 所有UI元素（图像、点击区域、OCR区域）在 `assets.py` 中声明式定义
- 代码通过资源引用进行操作，与具体坐标解耦

### 6.6 容错与恢复机制
- **随机点击**：未知场景时尝试恢复
- **超时检测**：防止无限循环
- **滑动计数**：防止滑动卡死
- **场景回退**：退出时确保回到主界面

### 6.7 防封策略
- 战斗过程中随机点击和滑动
- 操作间隔随机化
- 模拟人类操作行为
