# GlobalGame 全局游戏设置 逐行代码详解

## 1. 文件概述

`GlobalGame` 模块定义了**全局游戏配置和资源**，是所有任务共享的基础设施：

- **config.py**：全局配置（协作邀请策略、网络异常处理、皮肤配置、组队通信）
- **config_emergency.py**：紧急事件配置（协作邀请、网络异常）
- **assets.py**：全局 UI 资源（协作邀请按钮、网络异常图标、通用弹窗按钮）
- **gg/**：协作邀请相关图片资源
- **ui/**：通用 UI 元素图片资源

## 2. 配置参数说明

### GlobalGame 主配置（config.py）

| 参数 | 类型 | 说明 |
|------|------|------|
| `emergency` | `Emergency` | 紧急事件处理配置 |
| `costume_config` | `CostumeConfig` | 皮肤配置 |
| `team_flow` | `TeamFlow` | 组队通信配置 |

### Emergency 紧急事件配置（config_emergency.py）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `friend_invitation` | `FriendInvitation` | `ACCEPT` | 协作邀请处理策略 |
| `when_network_abnormal` | `WhenNetworkAbnormal` | `WAIT_10S` | 网络异常处理方式 |
| `when_network_error` | `WhenNetworkError` | `RESTART` | 网络错误处理方式 |
| `home_client_clear` | `bool` | `True` | 是否清理客户端缓存 |

### FriendInvitation 枚举

| 值 | 说明 |
|----|------|
| `ACCEPT` | 接受所有邀请 |
| `REJECT` | 拒绝所有邀请 |
| `ONLY_JADE` | 仅接受勾玉协作 |
| `JADE_AND_FOOD` | 接受勾玉和粮食协作 |
| `IGNORE` | 忽略所有邀请 |

### TeamFlow 组队通信配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enable` | `bool` | `False` | 是否启用组队通信 |
| `broker` | `str` | `""` | MQTT 代理地址 |
| `port` | `int` | `8883` | 端口号 |
| `transport` | `Transport` | `TCP` | 传输协议（TCP/SSL/TLS） |
| `ca` | `str` | `""` | CA 证书路径 |
| `username` | `str` | `""` | 用户名 |
| `password` | `str` | `""` | 密码 |

## 4. 核心代码逐行解释

### 4.1 FriendInvitation 枚举（config_emergency.py 第8-16行）

```python
class FriendInvitation(str, Enum):
    ACCEPT = 'accept'
    REJECT = 'reject'
    ONLY_JADE = 'only_jade'
    JADE_AND_FOOD = 'jade_and_food'
    IGNORE = 'ignore'
```

- **第8-16行**：协作邀请处理策略枚举。游戏中的协作邀请包括勾玉协作、粮食协作等，用户可选择不同的自动处理策略。

### 4.2 Emergency 配置类（config_emergency.py 第26-31行）

```python
class Emergency(BaseModel):
    friend_invitation: FriendInvitation = Field(default=FriendInvitation.ACCEPT)
    when_network_abnormal: WhenNetworkAbnormal = Field(default=WhenNetworkAbnormal.WAIT_10S)
    when_network_error: WhenNetworkError = Field(default=WhenNetworkError.RESTART)
    home_client_clear: bool = Field(default=True)
```

- **第26-31行**：紧急事件配置。网络异常时默认等待 10 秒重试，网络错误时默认重启游戏。

### 4.3 TeamFlow 组队通信（config.py 第11-23行）

```python
class Transport(str, Enum):
    TCP = 'TCP'
    SSL_TLS = 'SSL/TLS'

class TeamFlow(BaseModel):
    enable: bool = Field(default=False)
    broker: str = Field(default='')
    port: int = Field(default=8883)
    transport: Transport = Field(default=Transport.TCP)
    ca: str = Field(default='')
    username: str = Field(default='')
    password: str = Field(default='')
```

- **第11-23行**：组队通信配置，使用 MQTT 协议实现多设备间的组队协调。默认禁用。

### 4.4 GlobalGame 聚合配置（config.py 第26-29行）

```python
class GlobalGame(BaseModel):
    emergency: Emergency = Field(default_factory=Emergency)
    costume_config: CostumeConfig = Field(default_factory=CostumeConfig)
    team_flow: TeamFlow = Field(default_factory=TeamFlow)
```

- **第26-29行**：全局游戏配置聚合了三个子配置。

## 5. 任务执行流程图

```
GlobalGame 配置体系
│
├── Emergency 紧急事件
│   ├── FriendInvitation 协作邀请
│   │   ├── ACCEPT → 接受
│   │   ├── REJECT → 拒绝
│   │   ├── ONLY_JADE → 仅勾玉
│   │   ├── JADE_AND_FOOD → 勾玉+粮食
│   │   └── IGNORE → 忽略
│   │
│   ├── WhenNetworkAbnormal 网络异常
│   │   ├── RESTART → 重启游戏
│   │   └── WAIT_10S → 等待10秒
│   │
│   └── WhenNetworkError 网络错误
│       └── RESTART → 重启游戏
│
├── CostumeConfig 皮肤配置
│   └── (皮肤切换相关)
│
└── TeamFlow 组队通信
    └── MQTT 协议多设备协调
```

## 6. 设计模式总结

| 设计模式 | 应用位置 | 说明 |
|----------|----------|------|
| **策略模式** | `FriendInvitation` 枚举 | 用户可选择不同的协作邀请处理策略 |
| **全局资源池** | `GlobalGameAssets` | 所有任务共享的 UI 资源定义 |
| **聚合配置** | `GlobalGame` 类 | 将相关配置聚合到统一入口 |
| **模板匹配** | 所有 `RuleImage` | 通过图像模板匹配检测 UI 元素 |
| **事件驱动** | Emergency 配置 | 针对突发事件的响应策略配置 |
