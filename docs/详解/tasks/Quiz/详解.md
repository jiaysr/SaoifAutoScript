# 对弈竞猜（Quiz）详解

## 1. 文件概述

对弈竞猜是阴阳师中的限时答题活动，玩家需要在限定时间内回答问题。该任务自动完成：进入竞猜页面、OCR识别题目和选项、查询答案数据库、自动选择正确答案、处理答错/答对结果、未知题目记录和通知推送等功能。

**涉及文件：**
- `script_task.py` — 任务主逻辑，包含题目识别、答案查询、自动答题等
- `config.py` — 配置定义，包含答题轮数、每轮题数
- `assets.py` — 资源定义，包含OCR识别区域、点击区域
- `debug.py` — 调试工具，包含未知题目记录、符号清除

### 4.2 `run`方法 — 主运行流程

```python
    def run(self):
        self.ui_get_current_page()
        self.ui_goto(page_main)                          # 导航到庭院
        _config = self.config.model.quiz.quiz_config
        self.enter()                                     # 进入竞猜页面

        quiz_cnt = 0
        while 1:
            if quiz_cnt >= _config.quiz_cnt:
                break                                    # 达到配置的轮数
            try:
                self.once()                              # 执行一轮竞猜
                quiz_cnt += 1
            except NoTicket:
                break                                    # 没有门票了

        self.ui_click(self.I_UI_BACK_YELLOW, self.I_CHECK_MAIN, interval=2)
        self.set_next_run(task='Quiz', success=True, finish=True)
        raise TaskEnd('Quiz')
```
主循环：进入竞猜 → 循环执行指定轮数 → 没票退出 → 返回庭院。

### 4.3 `enter`方法 — 进入竞猜

```python
    def enter(self):
        while 1:
            self.screenshot()
            if self.appear(self.I_START):
                break                                    # 已到达竞猜页面
            if self.appear_then_click(self.I_SHI, interval=1):
                continue                                 # 点击活动入口
            if self.appear_then_click(self.I_ENTRY, interval=1):
                continue                                 # 点击竞猜入口
        logger.info('Quiz start')
```
从庭院导航到竞猜页面。

### 4.4 `once`方法 — 单轮竞猜

```python
    def once(self) -> bool:
        logger.hr('Quiz', 3)
        start_cnt = 0
        self.answer_cnt = 0                              # 重置答题计数
        self.last_countdown = None                       # 重置倒计时状态

        while 1:
            self.screenshot()
            if self.appear(self.I_MESSAGE):
                break                                    # 检测到竞猜标志，已进入
            if start_cnt >= 4:
                logger.error('No ticket')
                raise NoTicket('No ticket')              # 4次点击后仍未进入，没票了
            if self.appear_then_click(self.I_START, interval=1.5):
                start_cnt += 1
                continue                                 # 点击开始按钮
```
等待进入竞猜，最多尝试4次点击开始按钮。

```python
        self.last_select_1, self.last_select_2, self.last_select_3, self.last_select_4 = '', '', '', ''
        quiz_timer = Timer(1.4)                          # 1.4秒检测间隔
        quiz_timer.start()

        while 1:
            self.screenshot()
            if self.ui_reward_appear_click():
                continue                                 # 处理奖励弹窗
            if self.appear(self.I_FAIL_QUIT):
                logger.info('Quiz Fail and exit')
                self.ui_click(self.I_FAIL_QUIT, self.I_START)
                break                                    # 答错了，退出
            if self.appear(self.I_SHARE):
                logger.info('Quiz Victory and exit')
                self.ui_click(self.I_UI_BACK_RED, self.I_START)
                break                                    # 答完了，退出
            if quiz_timer.reached():
                quiz_timer.reset()
                self._deal_quiz()                        # 处理当前题目
                continue
        self.close_fn()                                  # 关闭调试文件
```
答题主循环：每1.4秒检测一次，处理题目直到答错或答完。

### 4.6 `detect_new`方法 — 检测新题目

```python
    def detect_new(self, select_1, select_2, select_3, select_4) -> bool:
        diff_count = 0
        if self.last_select_1 != select_1:
            diff_count += 1
        if self.last_select_2 != select_2:
            diff_count += 1
        if self.last_select_3 != select_3:
            diff_count += 1
        if self.last_select_4 != select_4:
            diff_count += 1

        new = diff_count >= 3                             # 至少3个选项不同才算新题

        self.last_select_1, self.last_select_2, self.last_select_3, self.last_select_4 = \
            select_1, select_2, select_3, select_4
        return new
```
通过比较当前选项与上次选项，判断是否为新题目。使用3/4阈值避免OCR波动导致的误判。

### 4.8 `debug.py` — 调试工具

```python
def remove_symbols(text):
    return re.sub(r'[^\w\s]', '', text)                  # 移除所有标点符号，保留文字和空格
```
清除文本中的标点符号，提高答案匹配准确率。

```python
class Debugger:
    def _log_file(self) -> Path:
        file: Path = Path(f'./log/quiz/supplement.txt')  # 未知题目记录文件
        # ... 确保目录和文件存在
```
日志文件路径：`./log/quiz/supplement.txt`。

```python
    def append_one(self, question: str, options: list[str]):
        question = remove_symbols(question)
        options = [remove_symbols(option) for option in options]
        file = self._log_file()
        lock = FileLock(f"{file}.lock")                  # 文件锁，防止并发写入
        line = f'{question},{options[0]},{options[1]},{options[2]},{options[3]}\n'
        with lock:
            with open(file, 'a', encoding='utf-8') as f:
                f.write(line)
                f.flush()
```
将未知题目追加到日志文件，使用文件锁确保线程安全。格式：`题目,选项1,选项2,选项3,选项4`。

## 6. 设计模式总结

### 6.1 外部知识库模式
答案来自`DemonEncounter.data.answer.Answer`模块，这是一个预先构建的答案数据库。通过`answer_one()`方法查询，实现了知识与逻辑的分离。

### 6.2 增量学习模式
当遇到未知题目时，`append_one()`将其记录到`supplement.txt`文件中。这些记录可以后续补充到答案数据库中，实现了系统的增量学习能力。

### 6.3 阈值去抖动
`detect_new()`使用3/4阈值判断是否为新题目，避免因OCR识别波动导致的重复答题。这是一种去抖动（debounce）策略。

### 6.4 时间窗口策略
只在倒计时2-5秒范围内处理题目，既保证题目完整性，又确保有足够时间选择答案。

### 6.5 文件锁并发控制
`debug.py`使用`FileLock`实现文件级锁，防止多进程同时写入日志文件导致数据损坏。

### 6.6 通知推送集成
遇到未知题目时通过`notifier.push()`推送通知，让用户及时了解系统遇到的新问题。

### 6.7 符号归一化
`remove_symbols()`清除所有标点符号，使OCR结果与答案库的匹配更加鲁棒。
