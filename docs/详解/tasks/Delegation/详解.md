# 委托任务详解

## 1. 文件概述

委托任务（Delegation）是《阴阳师》游戏中的委派玩法。玩家可以将式神委派出去执行任务，完成后获得奖励。该自动化脚本实现了以下功能：

- 自动导航至委派页面
- 自动领取已完成的委派奖励
- 根据配置自动执行指定的委派任务（弥助的画、鸟之羽、寻找耳环、猫老大、接送弥助、奇怪的痕迹）
- 自动选择式神并出发

### 文件清单

| 文件 | 说明 |
|------|------|
| `script_task.py` | 任务主逻辑，包含奖励领取和委派执行 |
| `config.py` | 配置定义，包含6个委派任务的启用开关 |
| `assets.py` | 资源定义，包含委派界面的图片模板和OCR规则 |

## 4. 核心代码逐行解释

### `ScriptTask` 类

```python
class ScriptTask(GameUi, DelegationAssets):
```

继承 `GameUi`（页面导航）和 `DelegationAssets`（资源定义）。

### `run()` 方法 — 主入口

```python
def run(self):
    self.ui_get_current_page()
    self.ui_goto(page_delegation)
    self.check_reward()
    con: DelegationConfig = self.config.delegation.delegation_config
    if con.miyoshino_painting:
        self.delegate_one('画')
    if con.bird_feather:
        self.delegate_one('鸟羽')
    # ... 其他委派任务
    self.set_next_run(task='Delegation', success=True, finish=True)
    raise TaskEnd
```

**执行流程**：
1. 导航到委派页面
2. 先领取所有已完成的奖励
3. 根据配置依次执行每个委派任务
4. 设置下次运行时间

### `delegate_one()` — 执行单个委派任务

```python
def delegate_one(self, name: str) -> bool:
    def ui_click(click, stop):
        while 1:
            self.screenshot()
            if self.appear(stop):
                break
            if self.click(click, interval=1.5):
                continue
```

内部辅助函数 `ui_click`：持续点击 `click` 目标直到 `stop` 目标出现。

### `check_reward()` — 领取奖励

```python
def check_reward(self):
    check_timer = Timer(3)
    check_timer.start()
    while 1:
        self.screenshot()
        if self.appear_then_click(self.I_REWARDS_GET, interval=1):
            check_timer.reset()
            continue
        if self.appear_then_click(self.I_REWARDS_CHAT, interval=1):
            check_timer.reset()
            continue
        if self.appear_then_click(self.I_CHAT_1, interval=1):
            check_timer.reset()
            continue
        if self.appear_then_click(self.I_CHAT_2, interval=1):
            check_timer.reset()
            continue
        if self.appear_then_click(self.I_REWARDS_DONE, interval=1):
            check_timer.reset()
            continue
        if self.appear_then_click(self.I_REWARDS_FALSE, interval=1):
            check_timer.reset()
            continue
        if not self.appear(self.I_REWARDS_MIN):
            continue
        if check_timer.reached():
            break
        if self.ocr_appear_click(self.O_D_DONE, interval=1):
            check_timer.reset()
            continue
```

**奖励领取循环**：
1. 依次检测并点击各种奖励弹窗（完美达成、对话、完成、差强人意）
2. 每次成功点击都重置3秒计时器
3. 当3秒内无任何奖励可领取时，判定奖励领取完毕
4. 如果委派列表最小化标记（`I_REWARDS_MIN`）未出现，继续循环
5. 通过OCR识别"完成"文字来点击已完成的委派

## 6. 设计模式总结

### 6.1 配置驱动的任务执行

每个委派任务对应一个布尔开关，`run()` 方法通过读取配置决定执行哪些委派。新增委派任务只需在 `config.py` 中添加字段并在 `run()` 中添加调用。

### 6.2 动态OCR关键词

```python
self.O_D_NAME.keyword = name
```

通过运行时修改OCR资源的 `keyword` 属性，复用同一个OCR规则来识别不同的委派名称。这是一种轻量级的参数化资源复用模式。

### 6.3 内部函数封装重复模式

`delegate_one` 中定义了内部函数 `ui_click(click, stop)`，封装了"持续点击直到目标出现"的重复模式，简化了式神选择的代码。

### 6.4 计时器防抖模式

`check_reward` 使用3秒计时器实现防抖：每次检测到奖励都重置计时器，只有连续3秒无奖励才退出。这确保了在多层奖励弹窗时能全部领取。

### 6.5 状态检测的多种信号

委派任务的状态判断使用多种信号：
- 图片匹配：`I_D_START`（出发）、`I_D_BACK`（返回/委派中）
- OCR识别：`O_D_NAME`（任务名称）、`O_D_DONE`（完成）
- 弹窗检测：各种奖励弹窗
