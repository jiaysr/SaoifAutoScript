# 蛙老板（FrogBoss）详解

## 1. 文件概述

蛙老板是阴阳师中的限时竞猜活动，玩家需要在两只青蛙之间选择一方下注。该任务自动完成：进入活动页面、识别双方投注人数、根据策略选择下注方、处理下注结果（成功/失败）、自动计算下次活动时间等功能。支持多种投注策略，包括多数策略、少数策略、大神策略等。

**涉及文件：**
- `script_task.py` — 任务主逻辑，包含竞猜流程、策略选择、大神数据抓取等
- `config.py` — 配置定义，包含投注策略枚举、时间配置
- `assets.py` — 资源定义，包含图片匹配、OCR识别区域

## 2. 配置参数说明

### 2.1 `Strategy`（投注策略枚举）

| 枚举值 | 说明 |
|--------|------|
| `Majority` | 多数策略 — 投注人数多的一方 |
| `Minority` | 少数策略 — 投注人数少的一方（博高赔率） |
| `Bilibili` | B站策略 — 跟随B站博主推荐（暂未实现） |
| `Dashen` | 大神策略 — 抓取网易大神APP多个博主的推荐，投票决定 |
| `AlwaysRed` | 总是选红方（左侧） |
| `AlwaysBlue` | 总是选蓝方（右侧） |

### 2.2 `FrogBossConfig`（蛙老板配置）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `before_end_frog` | Time | 0:15:00 | 距离活动结束前多久执行（时:分:秒） |
| `strategy_frog` | Strategy | Majority | 投注策略 |

### 2.3 `FrogBoss`（主配置）

| 参数 | 类型 | 说明 |
|------|------|------|
| `scheduler` | Scheduler | 调度器配置 |
| `frog_boss_config` | FrogBossConfig | 蛙老板功能配置 |

### 4.2 `next_run`方法 — 计算下次执行时间

```python
    def next_run(self):
        time = self.config.model.frog_boss.frog_boss_config.before_end_frog
        time_delta = TimeDelta(hours=time.hour, minutes=time.minute, seconds=time.second)
```
获取配置中的"提前多久执行"时间。

```python
        time_now = datetime.now()
        time_set = time_now.replace(minute=0, second=0, microsecond=0)
```
获取当前时间，归零分秒。

```python
        if 10 <= time_now.hour < 12:
            time_set = time_set.replace(hour=14)         # 10-12点 → 下次14点
        elif 12 <= time_now.hour < 14:
            time_set = time_set.replace(hour=16)         # 12-14点 → 下次16点
        elif 14 <= time_now.hour < 16:
            time_set = time_set.replace(hour=18)         # 14-16点 → 下次18点
        elif 16 <= time_now.hour < 18:
            time_set = time_set.replace(hour=20)         # 16-18点 → 下次20点
        elif 18 <= time_now.hour < 20:
            time_set = time_set.replace(hour=22)         # 18-20点 → 下次22点
        elif 20 <= time_now.hour < 22:
            time_set = time_set.replace(hour=0) + TimeDelta(days=1)  # 20-22点 → 次日0点
        elif 22 <= time_now.hour < 24:
            time_set = time_set.replace(hour=12) + TimeDelta(days=1) # 22-24点 → 次日12点
        else:
            time_set = time_set.replace(hour=12)         # 0-10点 → 当天12点
```
蛙老板活动每2小时一轮（10-12, 12-14, ..., 22-24），根据当前时间计算下一轮开始时间。

```python
        self.set_next_run(task='FrogBoss', target=time_set - time_delta)
```
设置下次执行时间为下一轮开始时间减去提前量。

- **Dashen**: 调用大神策略抓取

```python
            red_span = 9999
            blue_span = 9999
            if red_regex.search(body_text):
                red_span = red_regex.search(body_text).start()  # 红方关键词位置
            if blue_regex.search(body_text):
                blue_span = blue_regex.search(body_text).start()  # 蓝方关键词位置
            if red_span < blue_span:
                return 'LEFT'                            # 红方关键词出现更早

                return 'RIGHT'                           # 蓝方关键词出现更早
            return 'Unknown'
```
通过关键词在文本中的位置判断博主推荐哪方。位置越靠前，优先级越高。

## 6. 设计模式总结

### 6.1 策略模式（Strategy Pattern）
通过`Strategy`枚举和`match-case`语句实现了多种投注策略的切换。每种策略封装了独立的决策逻辑，用户可通过配置自由选择。

### 6.2 外部数据聚合
`get_dashen`方法通过HTTP API抓取网易大神APP上27个博主的最新动态，解析文本内容提取投注建议，实现了基于社区智慧的决策。这是一种典型的数据聚合模式。

### 6.3 正则表达式匹配
使用正则表达式匹配各种中文表述方式（"押红"、"压左"、"红方"等），并通过关键词在文本中的位置判断优先级，处理了自然语言的多样性。

### 6.4 时间窗口计算
`next_run`方法根据蛙老板活动的固定时间段（每2小时一轮）自动计算下次执行时间，实现了精确的调度控制。

### 6.5 容错设计
- 博主数据抓取失败时静默跳过
- 无法判断胜负时默认选择左方
- 五五开时选择少数方（博高赔率）
- 多个弹窗确认的循环处理
