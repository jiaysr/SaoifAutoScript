# GotoMain 返回主页 逐行代码详解

## 1. 文件概述

`GotoMain` 模块是一个**简单的导航任务**，功能单一明确：

- **script_task.py**：任务入口，将游戏导航回主页
- **assets.py**：资源定义（空，依赖 GameUi 的资源）

该模块通常在任务队列为空时被调度器调用，确保游戏回到主页状态。

## 2. 配置参数说明

GotoMain 没有独立的配置文件，其调度行为由通用的 `Scheduler` 控制。

## 3. 资源定义说明

`assets.py` 定义了空的 `GotoMainAssets` 类。实际使用的资源来自 `GameUi` 模块（通过继承 `GameUi` 类获得）。

```python
class GotoMainAssets:
    pass
```

## 4. 核心代码逐行解释

### 4.1 ScriptTask 类定义（script_task.py 全文）

```python
from tasks.GameUi.game_ui import GameUi
from tasks.GameUi.page import page_main
from module.exception import TaskEnd

class ScriptTask(GameUi):
    def run(self) -> None:
        self.ui_get_current_page()
        self.ui_goto(page_main)
        raise TaskEnd('Goto main end')
```

- **第1-3行**：导入 `GameUi` 类（页面导航引擎）和 `page_main`（主页页面对象）以及 `TaskEnd` 异常。

- **第6行**：继承 `GameUi`，获得完整的页面导航能力（BFS 最短路径、页面检测等）。

- **第8-10行**：`run()` 方法，任务执行流程：
  1. `ui_get_current_page()`：检测当前所在页面
  2. `ui_goto(page_main)`：使用 BFS 最短路径导航到主页
  3. `raise TaskEnd('Goto main end')`：抛出任务结束异常，通知调度器

### 4.2 执行流程详解

```python
self.ui_get_current_page()
```

- **第9行**：调用 `GameUi.ui_get_current_page()` 方法。该方法会：
  1. 遍历所有已注册页面（通过 `PageRegistry`）
  2. 对每个页面执行图像匹配（`ui_page_appear()`）
  3. 找到匹配的页面后设置 `self.ui_current`
  4. 未找到则尝试关闭弹窗或随机点击

```python
self.ui_goto(page_main)
```

- **第10行**：调用 `GameUi.ui_goto()` 方法导航到主页。该方法会：
  1. 调用 `build_reverse_path_dict(page_main)` 构建从所有页面到主页的最短路径
  2. 根据 `self.ui_current` 查找对应路径
  3. 沿路径逐页跳转（`_execute_path()`）
  4. 每页执行附加操作（关闭弹窗等）
  5. 到达主页后等待确认

```python
raise TaskEnd('Goto main end')
```

- **第11行**：抛出 `TaskEnd` 异常。这是框架的任务结束机制，调度器捕获此异常后会：
  1. 记录任务完成
  2. 更新下次运行时间
  3. 切换到下一个待执行任务

## 5. 任务执行流程图

```
GotoMain.run()
│
├── ui_get_current_page()
│   ├── 遍历所有已注册页面
│   ├── 对每个页面执行图像匹配
│   ├── 找到匹配 → 设置 ui_current
│   └── 未找到 → 关闭弹窗/随机点击
│
├── ui_goto(page_main)
│   ├── build_reverse_path_dict(page_main)
│   │   └── BFS 构建最短路径
│   ├── 获取当前页面路径
│   └── _execute_path(path)
│       ├── 遍历路径节点
│       ├── run_additional() 关闭弹窗
│       ├── appear_then_operate() 点击跳转
│       └── ui_wait_until_appear() 等待页面
│
└── raise TaskEnd('Goto main end')
    └── 通知调度器任务完成
```

## 6. 设计模式总结

| 设计模式 | 应用位置 | 说明 |
|----------|----------|------|
| **门面模式** | `ScriptTask` | 封装了复杂的页面导航逻辑为简单的 `run()` 方法 |
| **继承复用** | 继承 `GameUi` | 复用全部页面导航能力，无需重复实现 |
| **异常控制流** | `raise TaskEnd` | 使用异常而非返回值控制任务生命周期 |
| **单一职责** | 整个模块 | 只做一件事——回到主页 |
