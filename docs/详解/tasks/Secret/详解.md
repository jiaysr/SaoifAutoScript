# 秘闻竞速（Secret）任务详解

## 1. 文件概述

秘闻竞速任务是《阴阳师》手游中"秘闻副本"的自动化脚本模块。秘闻副本每周重置，玩家需要逐层挑战（共 10 层），每层通关后可获得勾玉奖励。该脚本自动寻找未通关层、智能判断挑战策略，并支持金币加成管理。

**核心功能：**
- 自动识别未通关层数（通过 OCR 识别"未通关"文字和勾玉数量）
- 智能滑动列表寻找可挑战的层
- 支持金币 50%/100% 加成的开启与关闭
- 可选挑战第 9 层和第 10 层
- 周一早上 8 点前自动跳过（服务器维护时间）
- 自定义战斗胜利/失败界面识别

**文件组成：**
| 文件 | 作用 |
|------|------|
| `script_task.py` | 任务主逻辑，含层数寻找、战斗策略、加成管理 |
| `config.py` | 配置模型定义（调度器、加成、层数选择） |
| `assets.py` | 图像/点击/OCR/滑动资源定义（自动生成） |

## 2. 配置参数说明

### 2.1 Scheduler（调度器）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `success_interval` | `TimeDelta` | `7天` | 成功后的下次调度间隔 |
| `failure_interval` | `TimeDelta` | `7天` | 失败后的下次调度间隔 |

### 2.2 SecretConfig（秘闻配置）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `secret_gold_50` | `bool` | `False` | 是否开启 50% 金币加成（前 5 层开启，第 6 层关闭） |
| `secret_gold_100` | `bool` | `False` | 是否开启 100% 金币加成（前 5 层开启，第 6 层关闭） |
| `layer_10` | `bool` | `False` | 是否挑战第 10 层 |
| `layer_9` | `bool` | `False` | 是否挑战第 9 层 |

### 2.3 GeneralBattleConfig（通用战斗配置）

继承自通用战斗组件，`lock_team_enable` 被强制设为 `False`（秘闻不允许锁定阵容）。

### 2.4 SwitchSoulConfig（御魂切换配置）

继承自通用御魂切换组件，支持按组队和按名称两种切换方式。

## 3. 资源定义说明

### 3.1 点击区域（RuleClick）

| 变量名 | ROI 区域 | 说明 |
|--------|----------|------|
| `C_SE_CLICK_LAYER` | (434,155,100,100) | 动态点击区域，ROI 会根据 OCR 结果动态调整 |

### 3.2 图像模板（RuleImage）

| 变量名 | 说明 | 阈值 |
|--------|------|------|
| `I_SE_ENTER` | 进入秘闻副本按钮 | 0.8 |
| `I_SE_FIRE` | 秘闻挑战按钮 | 0.7 |
| `I_SE_PLACEMENT` | 排行榜标识（判断是否成功进入） | 0.8 |
| `I_SE_JADE` | 勾玉图标（用于定位层数） | 0.8 |
| `I_SE_JADE_LAST` | 最后一个位置的勾玉图标 | 0.8 |
| `I_SE_BATTLE_WIN` | 秘闻战斗胜利界面 | 0.8 |
| `I_SE_FINISHED_1` | 已完成标识（可退出） | 0.8 |

### 3.3 OCR 识别（RuleOcr）

| 变量名 | 模式 | 关键词 | 说明 |
|--------|------|--------|------|
| `O_SE_NO_PASS` | `Full` | `未通关` | 主列表区域的"未通关"文字识别 |
| `O_SE_NO_PASS_LAST` | `Full` | `未通关` | 列表底部区域的"未通关"文字识别 |
| `O_SE_LAYER_1` | `Single` | - | 第一个位置的层数文字 |
| `O_SE_LAYER_8` | `Single` | `捌` | 第 8 层 |
| `O_SE_LAYER_9` | `Single` | `玖` | 第 9 层 |
| `O_SE_LAYER_10` | `Single` | `拾` | 第 10 层 |
| `O_SE_JADE` | `Digit` | - | 勾玉数量（用于推算层数：层数 = 勾玉数 / 7） |
| `O_SE_GOLD` | `Digit` | - | 金币数量（辅助判断第 1 层） |
| `O_SE_TOTAL_TIME` | `Single` | - | 总耗时（判断是否已打过） |

### 3.4 滑动操作（RuleSwipe）

| 变量名 | 说明 |
|--------|------|
| `S_SE_DOWN_SEIPE` | 向下滑动列表，寻找更多未通关层 |

## 4. 核心代码逐行解释

### 4.1 类定义

```python
class ScriptTask(GameUi, GeneralBattle, SwitchSoul, SecretAssets):
    lay_list = ['壹', '贰', '叁', '肆', '伍', '陆', '柒', '捌', '玖', '拾']
```

- 多重继承：`GameUi`（页面导航）、`GeneralBattle`（通用战斗）、`SwitchSoul`（御魂切换）、`SecretAssets`（资源定义）
- `lay_list`：中文数字列表，用于 OCR 识别层数

### 4.2 `match_layer` 缓存属性

```python
@cached_property
def match_layer(self) -> dict:
    return {'壹': 1, '贰': 2, ..., '拾': 10}
```
- 中文数字到阿拉伯数字的映射表
- 使用 `@cached_property` 只初始化一次

### 4.3 `battle_config` 缓存属性

```python
@cached_property
def battle_config(self) -> GeneralBattleConfig:
    conf = self.config.model.secret.general_battle
    conf.lock_team_enable = False
    return conf
```
- 获取战斗配置并强制关闭阵容锁定（秘闻副本不支持锁定）

### 4.4 `run()` 主方法

**阶段一：时间检查与御魂切换**
```python
    self.check_time()
    secret: Secret = self.config.secret
    con = secret.secret_config
    if secret.switch_soul.enable:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(secret.switch_soul.switch_group_team)
```
- `check_time()` 检查是否为周一早上（服务器维护时间）
- 执行御魂切换

**阶段二：进入秘闻副本**
```python
    self.ui_goto(page_secret_zones)
    self.ui_click(self.I_SE_ENTER, self.I_SE_FIRE)
    time.sleep(1)
    self.screenshot()
    if not self.appear(self.I_SE_PLACEMENT):
        logger.warning('Unsuccessful entry.')
        success = False
```
- 导航到秘闻副本页面
- 点击进入按钮，等待挑战按钮出现
- 通过排行榜标识判断是否成功进入（已进入过的无法再次进入）

**阶段三：自动挑战循环**
```python
    first_battle = True
    while 1:
        self.screenshot()
        if not success:
            break
        if not self.appear(self.I_SE_FIRE):
            continue
        if self.appear(self.I_SE_FINISHED_1):
            break
        layer = self.find_battle()
```
- 主循环：寻找可挑战的层并战斗
- `find_battle()` 返回找到的层数，找不到返回 `None`

**阶段四：战斗策略**
```python
        if first_battle and layer <= 5:
            first_battle = False
            buff = []
            if con.secret_gold_50:
                buff.append(BuffClass.GOLD_50)
            if con.secret_gold_100:
                buff.append(BuffClass.GOLD_100)
            self.click_battle()
            success = self.run_general_battle(self.battle_config, buff=buff)
```
- 第一次战斗且在前 5 层：开启金币加成

```python
        if not first_battle and layer == 6:
            buff = []
            if con.secret_gold_50:
                buff.append(BuffClass.GOLD_50_CLOSE)
            if con.secret_gold_100:
                buff.append(BuffClass.GOLD_100_CLOSE)
            self.click_battle()
            success = self.run_general_battle(self.battle_config, buff=buff)
```
- 第 6 层：关闭金币加成（节省加成时间）

```python
        elif not first_battle and layer == 9 and con.layer_9:
            self.click_battle()
            success = self.run_general_battle(self.battle_config)
        elif not first_battle and layer == 10 and con.layer_10:
            self.click_battle()
            success = self.run_general_battle(self.battle_config)
            break
```
- 第 9/10 层：根据配置决定是否挑战

**阶段五：收尾**
```python
    self.ui_click(self.I_UI_BACK_BLUE, self.I_UI_BACK_YELLOW)
    self.ui_click(self.I_UI_BACK_YELLOW, self.I_CHECK_MAIN)
    if con.secret_gold_50 or con.secret_gold_100:
        self.open_buff()
        if con.secret_gold_50:
            self.gold_50(False)
        if con.secret_gold_100:
            self.gold_100(False)
        self.close_buff()
    self.set_next_run(task='Secret', success=True, finish=True)
    raise TaskEnd('Secret')
```
- 退出秘闻副本
- 确保关闭所有金币加成（防止在其他任务中浪费加成时间）
- 设置下次运行时间

### 4.5 `find_battle()` 层数寻找方法

```python
def find_battle(self, screenshot: bool = False) -> int or None:
```

这是最复杂的方法，包含三个内部函数：

**`set_layer_roi()` - 动态调整 OCR 区域**
```python
    def set_layer_roi(ocr_target, roi):
        ocr_target.roi[0] = int(roi[0]) - 225
        ocr_target.roi[1] = int(roi[1]) - 40
```
- 根据"未通关"文字的位置，偏移计算层数 OCR 的 ROI

**`check_layer()` - 检查层数文字**
```python
    def check_layer(ocr_target, roi=None) -> int or None:
        level = ocr_target.ocr(self.device.image)
        level = level.replace('·', '').replace(' ', '').replace('。', '').replace('武', '贰')
        if level not in self.lay_list and roi:
            set_layer_roi(ocr_target, roi)
            self.screenshot()
            level = ocr_target.ocr(self.device.image)
```
- OCR 识别层数文字，进行容错替换（`·` → 空，`武` → `贰`）
- 若第一次识别失败，调整 ROI 重试

**`confirm_layer()` - 通过勾玉数量确认层数**
```python
    def confirm_layer(ocr_target, roi=None) -> int or None:
        ocr_target.roi[0] = int(roi[0]) - 118
        ocr_target.roi[1] = int(roi[1]) + 37
        jade_num = ocr_target.ocr(self.device.image)
        if jade_num < 7:
            gold_number = self.O_SE_GOLD.ocr(self.device.image)
            if isinstance(gold_number, int) and (gold_number == 10000 or gold_number == 18000):
                return 1
            return None
        lr = jade_num // 7
        return lr
```
- 通过勾玉数量推算层数：`层数 = 勾玉数 / 7`（每层 7 勾玉）
- 特殊处理第 1 层（勾玉不足 7，通过金币数量 10000/18000 判断）

**主逻辑：**
```python
    text_pos = self.O_SE_NO_PASS.ocr(self.device.image)
    if text_pos != (0, 0, 0, 0):
        layer = confirm_layer(self.O_SE_JADE, text_pos)
        if layer:
            self.C_SE_CLICK_LAYER.roi_front = text_pos
            self.click(self.C_SE_CLICK_LAYER, interval=1)
            return layer
    else:
        last_text_pos = self.O_SE_NO_PASS_LAST.ocr(self.device.image)
        if last_text_pos != (0, 0, 0, 0):
            layer = confirm_layer(self.O_SE_JADE, last_text_pos)
            if not layer and last_text_pos[1] > 520:
                layer = 10
            if layer:
                self.C_SE_CLICK_LAYER.roi_front = last_text_pos
                self.click(self.C_SE_CLICK_LAYER, interval=1)
                return layer
        else:
            self.swipe(self.S_SE_DOWN_SEIPE, interval=3)
            time.sleep(2)
```
- 先在主列表区域找"未通关"
- 找不到则在底部区域找
- 都找不到则向下滑动继续找
- 第 10 层的特殊处理（位置超过 520 像素）

### 4.6 `battle_wait()` 战斗等待（重写）

```python
def battle_wait(self, random_click_swipt_enable: bool) -> bool:
    self.device.stuck_record_add('BATTLE_STATUS_S')
    self.device.click_record_clear()
    while 1:
        self.screenshot()
        if self.appear(self.I_SE_BATTLE_WIN):
            self.ui_click_until_disappear(self.I_SE_BATTLE_WIN, interval=2)
            return True
        if self.appear_then_click(self.I_WIN, interval=1):
            continue
        if self.appear(self.I_REWARD):
            self.ui_click_until_disappear(self.I_REWARD)
            return True
        if self.appear(self.I_FALSE):
            self.ui_click_until_disappear(self.I_FALSE)
            return False
```
- 重写父类的战斗等待方法
- 增加了秘闻特有的胜利界面识别 `I_SE_BATTLE_WIN`

### 4.7 `check_time()` 时间检查

```python
def check_time(self) -> None:
    time_now = datetime.now()
    if time_now.weekday() == 0 and time_now.hour < 8:
        self.set_next_run(task='Secret', finish=True,
                          target=time_now.replace(hour=9, minute=0, second=0, microsecond=0))
        raise TaskEnd('Secret')
```
- 周一早上 8 点前不执行（服务器维护时间）
- 设置为当天 9 点重新调度

## 6. 设计模式总结

### 6.1 多重继承组合模式
- `ScriptTask` 通过多重继承组合 4 个基类的功能
- `GameUi`：页面导航能力
- `GeneralBattle`：通用战斗能力
- `SwitchSoul`：御魂切换能力
- `SecretAssets`：资源定义

### 6.2 策略模式
- 战斗策略根据层数动态切换：
  - 前 5 层：开启加成
  - 第 6 层：关闭加成
  - 第 9/10 层：根据配置决定
- 通过 `first_battle` 标志和 `layer` 值组合判断

### 6.3 动态 ROI 调整
- OCR 的识别区域根据上一次识别结果动态调整
- `set_layer_roi()` 和 `confirm_layer()` 根据"未通关"文字位置偏移计算新的 ROI
- 这种设计适应了列表滚动后元素位置变化的场景

### 6.4 容错 OCR 识别
- 多重容错：文字替换（`武` → `贰`）、ROI 调整重试、勾玉数量推算
- 第 10 层的特殊像素位置判断兜底
- 金币数量辅助判断第 1 层

### 6.5 加成生命周期管理
- 加成的开启和关闭在不同层执行，形成完整的生命周期
- 任务结束后强制关闭加成，防止影响其他任务
- 使用 `BuffClass.GOLD_50_CLOSE` / `GOLD_100_CLOSE` 枚举显式关闭
