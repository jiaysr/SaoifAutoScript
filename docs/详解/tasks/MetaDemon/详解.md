# 超鬼王（MetaDemon）详解

## 1. 文件概述

超鬼王是阴阳师限时活动中的高难度Boss挑战玩法。该任务自动完成：进入活动页面、召唤鬼王、识别Boss星级、根据星级选择不同阵容、自动战斗、疲劳值管理、一星卡片合成、以及高星鬼王通知推送等功能。

**涉及文件：**
- `script_task.py` — 任务主逻辑，包含Boss战斗、策略选择、疲劳管理等
- `config.py` — 配置定义，包含调度器、御魂切换、策略匹配、自定义阵容等
- `assets.py` — 资源定义，包含图片匹配、OCR识别区域

```python
    @classmethod
    def strategy2group_team(cls, strategies, detect_name) -> list[int] | None:
        for i in range(2):                               # 0: 完全匹配, 1: 1个字符不同
            for key_name in strategies:
                if len(key_name) != len(detect_name):
                    continue                             # 长度不同跳过
                diff_count = sum(1 for c1, c2 in zip(key_name, detect_name) if c1 != c2)
                if diff_count <= i < len(detect_name):
                    return strategies[key_name]          # 找到匹配的策略
        return None
```
模糊匹配策略：先尝试完全匹配，再允许1个字符差异。用于OCR识别可能有误差的情况。

### 4.3 `crafting`方法 — 卡片合成

```python
    def crafting(self):
        logger.info('Star crafting 1 star to 2 star')
        self.ui_click(self.I_CRAFTING_1, self.I_CRAFTING_START, interval=1.5)  # 进入合成界面
        timer = Timer(3).start()
        count = 0
        while 1:
            self.screenshot()
            if self.ui_reward_appear_click():
                timer.reset()
                continue                                 # 处理奖励弹窗
            if timer.reached() or count > 3:
                break                                    # 超时或合成3次后退出
            if not self.ocr_appear(self.O_CRAFTING_CARD_1):
                break                                    # 没有一星卡了
            if self.appear(self.I_CRAFTING_EMPTY) or self.appear(self.I_CRAFTING_EMPTY_NEW):
                if self.appear_then_click(self.I_CRAFTING_CARD_STAR_1, interval=1):
                    continue                             # 选择一星卡放入合成槽
            else:
                self.appear_then_click(self.I_CRAFTING_START, interval=3)  # 点击开始合成
                count += 1
                timer.reset()
                continue
        self.ui_click_until_disappear(self.I_UI_BACK_RED, interval=1)  # 退出合成界面
```
自动将一星卡片合成为二星，最多合成3次。

### 4.5 `battle_boss`方法 — Boss战斗

```python
    def battle_boss(self, group: int = None, team: int = None) -> bool:
        self.ui_click_until_disappear(self.I_BATTLE_DEMON, interval=1.8)  # 点击战斗按钮
        battle_config = GeneralBattleConfig()
        battle_config.lock_team_enable = False
        if group is None and team is None:
            battle_config.preset_enable = False          # 不使用预设
            success = self.run_general_battle(battle_config)
        else:
            battle_config.preset_enable = True           # 使用预设阵容
            battle_config.preset_group = group
            battle_config.preset_team = team
            tmp_battle_count = self.current_count
            self.current_count = 0                       # 重置计数（预设阵容不计入）
            success = self.run_general_battle(battle_config)
            self.current_count = tmp_battle_count + 1    # 恢复并增加计数
        return True if success else False
```
执行Boss战斗，支持普通模式和预设阵容模式。

## 6. 设计模式总结

### 6.1 策略模式（Strategy Pattern）
`Strategy`类实现了按式神名匹配阵容的策略机制。通过`parse_all()`将策略配置解析为字典，`strategy2group_team()`实现模糊匹配（允许1-2个字符差异），支持针对不同Boss使用不同阵容。

### 6.2 缓存属性模式
大量使用`@cached_property`装饰器（`cached_strategies`、`cached_default_group_team`），确保配置解析只执行一次，提高性能。

### 6.3 状态检测模式
通过图像匹配组合判断Boss状态：
- `I_BOSS_EMPTY` + `I_BOSS_CONVENE` → 有Boss可挑战
- `I_STAR56_POS_1` → 判断是否为5/6星
- `I_STAR56_HP_THRESHOLD_T/F` → 判断血量阈值

### 6.4 动态阵容选择
根据Boss星级和血量动态选择阵容的4元组：`[高血量组, 高血量队, 低血量组, 低血量队]`，实现了灵活的战斗策略配置。

### 6.5 通知推送集成
当召唤到高星鬼王时，通过`self.config.notifier.push()`推送消息通知用户，实现了自动化与人工干预的结合。

### 6.6 动态列表序列化
`MetaDemon`配置类通过`model_validator`和`model_serializer`实现了动态长度列表（`md_strategies`）的序列化/反序列化，支持用户自定义任意数量的策略。
