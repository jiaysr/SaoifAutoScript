# 御灵副本任务 (GoryouRealm) 逐行代码详解

## 1. 文件概述

御灵副本任务用于自动刷御灵副本，获取御灵（类似坐骑/守护灵系统）相关资源。该任务支持单人模式，可选择不同的暗御灵进行挑战。

### 御灵类型

| 类型 | 说明 |
|------|------|
| 暗神龙 (Dark_Divine_Dragon) | 暗属性神龙御灵 |
| 暗白蔵主 (Dark_Hakuzousu) | 暗属性白蔵主御灵 |
| 暗黑豹 (Dark_Black_Panther) | 暗属性黑豹御灵 |
| 暗孔雀 (Dark_Peacock) | 暗属性孔雀御灵 |
| 随机 (RANDOM) | 随机选择一种御灵 |

### 文件结构

| 文件 | 说明 |
|------|------|
| `script_task.py` | 任务入口，包含主流程和挑战逻辑 |
| `config.py` | 配置定义，包含御灵类型、次数、时间限制等 |
| `assets.py` | 资源定义，包含点击、图像匹配、OCR等规则 |

## 4. 核心代码逐行解释

### 4.1 `script_task.py` - 主流程

#### ScriptTask 类定义
```python
class ScriptTask(GeneralBattle, GameUi, SwitchSoul, GoryouRealmAssets):
```
- **继承**：通用战斗、UI导航、御魂切换、资源定义

#### run() - 主入口
```python
def run(self):
    con = self.config.goryou_realm

    # 1. 初始化时间限制
    limit_time = con.goryou_config.limit_time
    self.limit_time: timedelta = timedelta(hours=limit_time.hour, 
                                            minutes=limit_time.minute,
                                            seconds=limit_time.second)

    # 2. 切换御魂
    if con.switch_soul_config.enable:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(con.switch_soul_config.switch_group_team)

    # 3. 导航到御灵界面
    self.ui_get_current_page()
    self.ui_goto(page_goryou_realm)

    # 4. 构建御灵类型到点击坐标的映射
    match_click = {
        GoryouClass.Dark_Divine_Dragon: self.C_GR_C_1,   # 暗神龙
        GoryouClass.Dark_Hakuzousu: self.C_GR_C_2,       # 暗白蔵主
        GoryouClass.Dark_Black_Panther: self.C_GR_C_3,   # 暗黑豹
        GoryouClass.Dark_Peacock: self.C_GR_C_4,         # 暗孔雀
    }

    # 5. 处理随机选择
    goryou_class = con.goryou_config.goryou_class
    if goryou_class == GoryouClass.RANDOM:
        goryou_class = choice(list(match_click.keys()))
        # 使用 random.choice 从所有御灵类型中随机选择一个

    # 6. 进入对应的御灵副本
    while 1:
        self.screenshot()
        if self.appear(self.I_GR_FIRE):
            logger.info('Enter GoryouRealm')
            break  # 成功进入，挑战按钮出现
        if self.click(match_click[goryou_class], interval=1):
            continue  # 点击对应的御灵入口

    # 7. 检查并设置锁定状态
    self.check_lock(con.general_battle_config.lock_team_enable, 
                    self.I_GR_LOCK, self.I_GR_UNLOCK)

    # 8. 挑战循环
    while 1:
        self.screenshot()
        if not self.appear(self.I_GR_FIRE):
            continue  # 等待挑战按钮出现

        # 检查次数限制
        if self.current_count >= con.goryou_config.limit_count:
            logger.info('GoryouRealm count limit out')
            break

        # 检查时间限制
        if datetime.now() - self.start_time >= self.limit_time:
            logger.info('GoryouRealm time limit out')
            break

        # 检查御灵票数量
        ticket = self.O_GR_TICKET.ocr(self.device.image)
        if ticket == 0:
            break  # 没有票了

        # 点击挑战并执行战斗
        while 1:
            self.screenshot()
            if self.appear_then_click(self.I_GR_FIRE, interval=1):
                pass  # 点击挑战按钮
            if not self.appear(self.I_GR_FIRE):
                # 挑战按钮消失，说明进入战斗
                self.run_general_battle(config=con.general_battle_config)
                break  # 战斗结束

    # 9. 返回探索界面
    self.ui_click(self.I_UI_BACK_YELLOW, self.I_CHECK_EXPLORATION)
    logger.info('Back to exploration')

    # 10. 设置下次运行时间
    self.set_next_run(task='GoryouRealm', success=True, finish=True)
    raise TaskEnd
```

### 4.2 代码详解 - 关键逻辑

#### 随机选择机制
```python
if goryou_class == GoryouClass.RANDOM:
    goryou_class = choice(list(match_click.keys()))
```
- **实现**：使用 Python 标准库 `random.choice`
- **原理**：将 `match_click` 字典的键（所有御灵类型）转换为列表，随机选择一个
- **效果**：每次运行时随机选择一种御灵进行挑战

#### 御灵票检测
```python
ticket = self.O_GR_TICKET.ocr(self.device.image)
if ticket == 0:
    break
```
- **实现**：使用 OCR 识别御灵票数量
- **模式**：`mode="Digit"` 只识别数字
- **位置**：屏幕右上角 (938, 4, 100, 41)
- **逻辑**：票数为0时退出循环

#### 战斗发起流程
```python
while 1:
    self.screenshot()
    if self.appear_then_click(self.I_GR_FIRE, interval=1):
        pass  # 点击挑战按钮
    if not self.appear(self.I_GR_FIRE):
        # 挑战按钮消失，说明进入战斗
        self.run_general_battle(config=con.general_battle_config)
        break
```
- **逻辑**：
  1. 持续点击挑战按钮
  2. 当挑战按钮消失时，认为已进入战斗
  3. 执行通用战斗流程
  4. 战斗结束后跳出内层循环

#### check_lock() 方法（继承自父类）
```python
self.check_lock(con.general_battle_config.lock_team_enable, 
                self.I_GR_LOCK, self.I_GR_UNLOCK)
```
- **参数**：
  - `lock`：是否锁定阵容
  - `lock_image`：锁定状态图像
  - `unlock_image`：未锁定状态图像
- **逻辑**：
  - 如果要锁定：点击直到出现锁定图标
  - 如果要解锁：点击直到出现解锁图标

## 6. 设计模式总结

### 6.1 策略模式
- `GoryouClass` 枚举定义不同的御灵类型
- `match_click` 字典将类型映射到具体操作
- `RANDOM` 类型通过 `choice()` 动态选择策略

### 6.2 组合模式
- 多重继承组合功能：
  - `GeneralBattle` - 通用战斗逻辑
  - `GameUi` - UI导航
  - `SwitchSoul` - 御魂切换
  - `GoryouRealmAssets` - 资源定义

### 6.3 资源驱动模式
- `RuleClick` 定义点击区域
- `RuleImage` 定义图像匹配规则
- `RuleOcr` 定义文字识别规则
- 代码通过资源引用操作UI

### 6.4 配置驱动模式
- 所有参数通过 `config.py` 定义
- 使用 Pydantic 进行数据验证
- 支持运行时动态调整

### 6.5 循环控制模式
```python
while 1:
    # 检查退出条件
    if 次数满: break
    if 时间到: break
    if 没票: break
    
    # 执行操作
    点击挑战
    执行战斗
```
- **特点**：多重退出条件，优先级明确
- **优势**：逻辑清晰，易于维护

### 6.6 容错机制
- **超时检测**：防止无限循环
- **票数检测**：防止无票时继续挑战
- **状态等待**：等待挑战按钮出现后再操作
- **UI回退**：退出时确保回到正确的界面

### 6.7 简洁设计
- 文件数量少（仅3个核心文件）
- 逻辑相对简单（单人模式，无组队）
- 代码行数少（~90行主逻辑）
- 易于理解和维护

## 7. 与其他任务的对比

| 特性 | GoryouRealm | Exploration | BondlingFairyland | EvoZone |
|------|-------------|-------------|-------------------|---------|
| 组队支持 | 否 | 是 | 是 | 是 |

### 设计特点

1. **极简设计**：GoryouRealm 是最简单的任务之一，只支持单人模式
2. **随机选择**：支持 RANDOM 模式，增加游戏趣味性
3. **票数检测**：使用 OCR 识别御灵票数量，智能退出
4. **继承复用**：大量使用父类方法，减少重复代码
