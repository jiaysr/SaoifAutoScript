# 花车巡游（FloatParade）详解

## 1. 文件概述

花车巡游是阴阳师中的限时收集奖励活动，玩家通过完成任务提升花车等级，领取各等级奖励。该任务自动完成：进入花车活动页面、一键收取所有奖励、根据配置选择花车等级奖励（蛇皮/青吉鬼、金币/勾玉、体力/樱饼）等功能。

**涉及文件：**
- `script_task.py` — 任务主逻辑，包含奖励收取、等级奖励选择等
- `config.py` — 配置定义，包含调度器、等级奖励选择
- `assets.py` — 资源定义，包含图片匹配区域

---

## 2. 配置参数说明

### 2.1 `Scheduler`（调度器配置）

花车巡游使用自定义调度器，默认成功/失败间隔为3天（花车活动通常持续较长时间）。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `success_interval` | TimeDelta | 3天 | 成功后下次执行间隔 |
| `failure_interval` | TimeDelta | 3天 | 失败后下次执行间隔 |

### 2.2 `LevelReward`（等级奖励枚举）

| 枚举值 | 说明 |
|--------|------|
| `ONE` | 蛇皮/青吉鬼 |
| `TWO` | 金币/勾玉 |
| `THREE` | 体力/樱饼 |

### 2.3 `FloatParadeConfig`（花车配置）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `level_reward1` | LevelReward | THREE | 第一种等级奖励选择（体力/樱饼） |
| `level_reward2` | LevelReward | ONE | 第二种等级奖励选择（蛇皮/青吉鬼） |

### 2.4 `FloatParade`（主配置）

| 参数 | 类型 | 说明 |
|------|------|------|
| `scheduler` | Scheduler | 调度器配置（3天间隔） |
| `float_parade` | FloatParadeConfig | 花车功能配置 |

### 4.2 `get_all`方法 — 一键收取所有奖励

```python
    def get_all(self):
        while 1:
            self.screenshot()
            if self.appear(self.I_FP_UPGRADE):
                break                                    # 检测到升级标识，已进入花车
            if self.appear_then_click(self.I_FP_ACCESS, interval=0.8):
                continue                                 # 从庭院点击进入花车
            if self.appear_then_click(self.I_FP_RED_CLOSE, interval=1.5):
                continue                                 # 关闭红色弹窗
            if self.appear_then_click(self.I_FP_GIFT_CLOSE, interval=3):
                continue                                 # 关闭礼包弹窗
            if self.appear_then_click(self.I_FP_TASKS, interval=1.8):
                continue                                 # 点击任务按钮
            if self.appear_then_click(self.I_TOGGLE_BUTTON, interval=3):
                continue                                 # 点击切换按钮
```
从庭院导航到花车活动内部，处理各种弹窗。

```python
        logger.info('Enter float parade')
        logger.info('Click get all reward')
        if not self.appear(self.I_FP_GETALL1):
            logger.info('No appear get all button')
            return                                       # 没有可收取的奖励
        self.ui_get_reward(self.I_FP_GETALL1)            # 点击一键收取
        logger.info('Got all reward')
```
检测并点击一键收取按钮。`ui_get_reward`会处理奖励弹窗。

## 6. 设计模式总结

### 6.1 枚举策略模式
`LevelReward`枚举定义了三种奖励类型，通过`match_level`字典映射到对应的图片资源，实现了奖励选择的配置化。

### 6.2 多层弹窗处理
花车活动有多种弹窗（红色关闭、礼包关闭、溢出确认等），代码通过循环+`appear_then_click`模式逐一处理，确保流程顺畅。

### 6.3 超时退出机制
`check_timer`实现了2秒无操作自动退出的机制，避免在奖励领取完毕后陷入死循环。

### 6.4 资源复用
等级奖励的图片资源（`I_TP_LEVEL_*`）来自`TalisismanPassAssets`（花合战），实现了跨任务的资源共享。

### 6.5 自定义调度间隔
花车活动持续时间较长，自定义`Scheduler`将成功/失败间隔设为3天，避免频繁执行。
