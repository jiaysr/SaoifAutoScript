# AreaBoss 地域Boss 任务详解

## 1. 文件概述

**任务功能**: 自动挑战地域鬼王，包括：
- 切换御魂配置
- 挑战普通/极地鬼王
- 选择热门/收藏/悬赏鬼王
- 调整难度等级和层数
- 处理战斗结果

**入口文件**: `tasks/AreaBoss/script_task.py`

---

## 2. 配置参数说明

**配置文件**: `tasks/AreaBoss/config.py`

### AreaBoss 配置结构

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `scheduler` | Scheduler | 调度器配置 |
| `boss` | Boss | 鬼王相关配置 |
| `general_battle` | GeneralBattleConfig | 通用战斗配置 |
| `switch_soul` | SwitchSoulConfig | 御魂切换配置 |

### Boss 配置 (config_boss.py)

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `boss_number` | int | 挑战鬼王数量 |
| `boss_reward` | bool | 是否挑战悬赏鬼王 |
| `use_collect` | bool | 使用收藏列表 |
| `reward_floor` | AreaBossFloor | 悬赏层数 |
| `Attack_60` | bool | 是否切换到60级 |

### AreaBossFloor 枚举

| 值 | 说明 |
|----|------|
| `ONE` | 一层 |
| `TEN` | 十层 |
| `DEFAULT` | 默认不切换 |

## 4. 核心代码逐行解释

### ScriptTask.run() - 主入口

```python
def run(self) -> bool:
    # 直接手动关闭锁定阵容
    self.config.area_boss.general_battle.lock_team_enable = False
    con = self.config.area_boss.boss

    # 切换御魂
    if self.config.area_boss.switch_soul.enable:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(self.config.area_boss.switch_soul.switch_group_team)

    if self.config.area_boss.switch_soul.enable_switch_by_name:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul_by_name(...)

    # 导航到地域鬼王页面
    self.ui_get_current_page()
    self.ui_goto(page_area_boss)

    # 挑战悬赏鬼王
    boss_fought = 0
    if con.boss_reward:
        if self.fight_reward_boss():
            boss_fought += 1

    # 打开筛选并切换列表
    self.open_filter()
    if con.use_collect:
        self.switch_to_collect()
    else:
        self.switch_to_famous()

    # 挑战剩余鬼王
    if con.boss_number - boss_fought == 3:
        self.boss_fight(self.I_BATTLE_1)
        self.boss_fight(self.I_BATTLE_2)
        self.boss_fight(self.I_BATTLE_3)
    elif con.boss_number - boss_fought == 2:
        self.boss_fight(self.I_BATTLE_1)
        self.boss_fight(self.I_BATTLE_2)
    elif con.boss_number - boss_fought == 1:
        self.boss_fight(self.I_BATTLE_1)

    # 退出
    self.go_back()
    self.set_next_run(task='AreaBoss', success=True, finish=False)
    raise TaskEnd
```

### boss_fight() - 挑战单个鬼王

```python
def boss_fight(self, battle: RuleImage, ultra: bool = False, fileter_open: bool = True) -> bool:
    reward_floor = self.config.area_boss.boss.reward_floor

    # 打开筛选界面
    if fileter_open and not self.appear(self.I_AB_FILTER_OPENED):
        self.open_filter()

    # 打开鬼王详情
    if not self.open_boss_detail(battle, 3):
        return False

    # 检查是否已挑战过
    if self.is_group_ranked():
        self.ui_click_until_disappear(self.I_AB_CLOSE_RED)
        return True

    if ultra:
        if not self.get_difficulty():
            # 判断是否能切换到极地鬼
            if not self.appear(self.I_AB_DIFFICULTY_NORMAL) and self.config.area_boss.boss.Attack_60:
                self.switch_to_level_60()  # 切换到60级
                if not self.start_fight():
                    return False
            else:
                return False
        # 切换到极地鬼
        self.switch_difficulty(True)
        # 调整悬赏层数
        match reward_floor:
            case AreaBossFloor.ONE: self.switch_to_floor_1()
            case AreaBossFloor.TEN: self.switch_to_floor_10()

    # 开始战斗
    result = True
    if not self.start_fight():
        result = False

    self.wait_until_appear(self.I_AB_CLOSE_RED)
    self.ui_click_until_disappear(self.I_AB_CLOSE_RED)
    return result
```

### fight_reward_boss() - 挑战悬赏鬼王

```python
def fight_reward_boss(self):
    BOSS_REWARD_PHOTO1 = [self.C_AB_BOSS_REWARD_PHOTO_1, ...]
    BOSS_REWARD_PHOTO2 = [self.C_AB_BOSS_REWARD_PHOTO_MINUS_2, ...]

    # 获取挑战人数最多的Boss
    need_open_filter, boss_name, photo = self.get_hot_in_reward()
    if photo is None or boss_name == '声望不够':
        return False

    # 不需要打开筛选界面，直接挑战
    if not need_open_filter:
        return self.boss_fight(photo, True, fileter_open=False)

    # 滑动到最顶层
    for i in range(random.randint(1, 3)):
        self.swipe(self.S_AB_FILTER_DOWN)

    # 遍历所有boss找到名称一致的
    for PHOTO in BOSS_REWARD_PHOTO1:
        self.open_filter()
        name = self.get_bossName(PHOTO)
        if self.check_common_chars(str(name), boss_name):
            return self.boss_fight(PHOTO, True, fileter_open=False)
        self.ui_click_until_disappear(self.I_AB_CLOSE_RED)
    # ... 继续检查其他位置
```

## 6. 设计模式总结

### 1. 策略模式
- `use_collect` 决定使用收藏还是热门列表
- `boss_reward` 决定是否挑战悬赏鬼王
- `reward_floor` 决定挑战层数

### 2. 模板方法模式
- `boss_fight()` 定义标准挑战流程
- 通过参数控制是否切换难度

### 3. 状态检测模式
- `is_group_ranked()` 检查是否已挑战
- `get_difficulty()` 检查当前难度
- `open_boss_detail()` 检查界面状态

### 4. 重试机制
- `open_boss_detail(battle, 3)` 限制重试次数
- `try_num` 参数控制重试策略

### 5. OCR识别集成
- 使用 `O_AB_NUM_OF_CHALLENGE` 识别挑战人数
- 使用 `O_AB_BOSS_NAME` 识别鬼王名称
- 结合图像匹配和OCR进行智能选择
