# Pets 小猫咪 任务详解

## 1. 文件概述

**任务功能**: 自动完成宠物小屋任务，包括：
- 进入宠物小屋
- 快速喂养宠物
- （可选）与宠物玩耍

**入口文件**: `tasks/Pets/script_task.py`

---

## 2. 配置参数说明

**配置文件**: `tasks/Pets/config.py`

### PetsConfig 参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `pets_feast` | bool | True | 是否快速喂养 |

**注意**: `pets_happy`（其乐融融/玩耍）参数已被注释，暂不支持。

## 4. 核心代码逐行解释

### ScriptTask.run() - 主入口

```python
def run(self):
    self.ui_get_current_page()
    self.ui_goto(page_main)  # 确保在主页面

    con: PetsConfig = self.config.pets.pets_config

    # 进入宠物小屋
    while 1:
        self.screenshot()
        if self.appear(self.I_PET_FEAST):
            break  # 已进入
        if self.appear_then_click(self.I_PET_HOUSE, interval=1):
            continue  # 点击宠物小屋
        if self.appear_then_click(self.I_PET_CLAW, interval=1):
            continue  # 点击爪印

    logger.info('Enter Pets')

    # 喂养
    if con.pets_feast:
        self._feed()

    # 退出
    self.ui_click(self.I_PET_EXIT, self.I_CHECK_MAIN)

    self.set_next_run(task='Pets', success=True, finish=True)
    raise TaskEnd('Pets')
```

### _feed() - 喂养

```python
def _feed(self):
    logger.hr('Feed', 3)

    # 点击快速喂养
    self.ui_click(self.I_PET_FEAST, self.I_PET_FEED)

    # 检查体力是否足够
    number = self.O_PET_FEED_AP.ocr(self.device.image)
    if number == 0:
        logger.warning('Already feed')  # 已喂过或体力不足
        return

    # 点击喂食
    self.ui_click(self.I_PET_FEED, self.I_PET_SKIP)

    # 等待动画结束
    self.wait_until_disappear(self.I_PET_SKIP)
```

### _play() - 玩耍（未启用）

```python
def _play(self):
    logger.hr('Play', 3)

    # 点击其乐融融
    self.ui_click(self.I_PET_HAPPY, self.I_PET_PLAY)

    # 检查金币是否足够
    number = self.O_PET_PLAY_GOLD.ocr(self.device.image)
    if number == 0:
        logger.warning('Gold not enough')
        return

    # 点击玩耍三次
    play_count = 0
    while 1:
        self.screenshot()
        if self.appear(self.I_PET_SKIP):
            break  # 动画开始
        if play_count >= 3:
            logger.warning('Play count > 3')
            break
        if self.appear_then_click(self.I_PET_PLAY, interval=1):
            play_count += 1
            logger.info(f'Play {play_count}')
            continue

    # 等待动画结束
    self.wait_until_disappear(self.I_PET_SKIP)
```

## 6. 设计模式总结

### 1. 简单任务模式
- 单一职责：喂养宠物
- 线性执行流程
- 快速完成

### 2. 状态检测
- `I_PET_FEAST` 检测是否进入小屋
- `O_PET_FEED_AP` 检测体力是否足够
- `I_PET_SKIP` 检测动画状态

### 3. 超时控制
- `wait_until_disappear()` 等待动画结束
- `play_count >= 3` 限制玩耍次数

### 4. 资源消耗检测
- OCR识别体力/金币消耗
- 资源不足时跳过操作

### 5. 可扩展设计
- `_play()` 方法已实现但未启用
- 配置参数预留扩展空间
