# 搜刮商店（RichMan）任务详解

## 1. 文件概述

搜刮商店任务是《阴阳师》手游中各类商店自动购买的聚合脚本模块。它统一管理多个商店的自动购买逻辑，包括：千物宝箱、神龛、功勋商店、以及杂货铺（友情点/勋章/荣誉/魅力/特殊/寄售/密卷/契灵）等子模块。

**核心功能：**
- **千物宝箱**：自动购买蓝票（2000）、黑蛋碎片（350）、体力（600）
- **神龛**：自动购买黑蛋（1500）、五星白蛋（1200）、四星白蛋（400）
- **功勋商店**：自动购买蓝票（240功勋）、黑碎（200功勋）、皮肤券（50功勋）
- **杂货铺**：自动导航到各子商店（特殊/荣誉/友情点/勋章/魅力）购买对应物品
- **密卷屋**：蛇皮兑换御魂、首领御魂、永生之海
- **契灵商店**：购买随机御魂、契灵石、高级/中级盘
- **寄售屋**：购买寄售券

**文件组成：**
| 文件 | 作用 |
|------|------|
| `script_task.py` | 任务入口，串联四个子模块 |
| `config.py` | 所有商店的配置模型定义 |
| `assets.py` | 所有图像/点击/OCR/滑动资源定义 |
| `guild.py` | 功勋商店子模块 |
| `shrine.py` | 神龛子模块 |
| `thousand_things.py` | 千物宝箱子模块 |
| `mall/` | 杂货铺子模块目录（含多个子商店） |

## 4. 核心代码逐行解释

### 4.1 script_task.py - 任务入口

```python
class ScriptTask(Mall, Guild, ThousandThings, Shrine):

    def run(self):
        con: RichMan = self.config.rich_man
        self.execute_tt(con.thousand_things)
        self.execute_shrine(con.shrine)
        self.execute_guild(con.guild_store)
        self.execute_mall()
        self.set_next_run(task='RichMan', success=True, finish=False)
        raise TaskEnd('RichMan')
```
- 通过多重继承组合四个子模块
- 按固定顺序执行：千物宝箱 → 神龛 → 功勋商店 → 杂货铺
- `set_next_run(finish=False)` 表示任务完成后不标记为结束（等待下次调度）

```python
                ...
                break
            if self.ui_reward_appear_click():
                sleep(0.5)
                while 1:
                    if not self.appear(self.I_UI_REWARD, threshold=0.6):
                        break
                    if self.ui_reward_appear_click():
                        continue
                break
            if self.appear_then_click(image_button, interval=2):
                click_count += 1
                continue
```
- 多层循环确保奖励领取完成
- 外层超时 6 次防止死循环
- 内层等待动画结束

## 6. 设计模式总结

### 6.1 组合模式（Composite Pattern）
- `ScriptTask` 通过多重继承组合 4 个独立子模块
- 每个子模块（`Mall`/`Guild`/`Shrine`/`ThousandThings`）独立实现
- 主入口只需按顺序调用 `execute_*()` 方法

### 6.2 动态列表 + 滑动扫描模式
- 功勋商店使用动态构建的 `items` 列表
- 滑动过程中匹配到商品就购买并移除
- 最后一个商品购买完毕则退出
- `ButtonException` 处理 OCR 识别失败时的优雅降级

### 6.3 动态 ROI 模式
- `check_remain()` 根据商品图像位置动态计算 OCR 区域
- 适应不同商品在商店中的不同位置
- 使用正则表达式提取数字

### 6.4 购买流程模板
- 所有子模块遵循统一的购买流程模板：
  1. 检查 enable 标志
  2. 导航到目标页面
  3. 检查余额是否足够
  4. 检查商品是否存在
  5. 点击商品 → 确认购买 → 领取奖励
  6. 返回上级页面

### 6.5 防御性编程
- `click_count >= N` 限制最大点击次数
- `ButtonException` 异常捕获
- `threshold` 参数调整匹配精度
- `wait_until_stable()` 等待界面稳定后再操作

### 6.6 配置驱动
- 所有购买行为通过配置文件控制
- `enable` 标志控制子模块是否执行
- 商品级别的开关独立控制
- 数量参数支持精确控制购买数量
