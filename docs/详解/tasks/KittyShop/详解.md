# 小猫咪商店（KittyShop）详解

## 1. 文件概述

小猫咪商店是阴阳师中的限时经营玩法，玩家派遣猫咪进行经营，收集奖励。该任务自动完成：进入经营页面、选择猫咪（支持滑动翻页）、开始经营、在经营过程中点击礼物和加号收集资源、处理猫咪忙碌状态、经营完成后领取奖励等功能。

**涉及文件：**
- `script_task.py` — 任务主逻辑，包含猫咪选择、经营流程、奖励收集等
- `config.py` — 配置定义，包含经营次数、完成退出选项
- `assets.py` — 资源定义，包含图片匹配、点击区域、滑动区域

### 4.4 `_select_kitty`方法 — 选择猫咪

```python
    def _select_kitty(self):
        self.ui_click(self.I_START_FARMING, stop=self.I_START_ENSURE)  # 点击开始经营

        index_timer = Timer(1.2).start()                 # 1.2秒切换计时器
        index_cnt = 0                                    # 当前选择位置索引
```
进入猫咪选择界面。

```python
        while 1:
            self.screenshot()
            if index_timer.reached():
                index_cnt += 1                           # 每1.2秒切换一个位置
                index_timer.reset()

            if not self.appear(self.I_UNSELECTED):
                break                                    # 所有位置都已选择完毕

            match index_cnt:
                case 0:
                    self.click(self.C_SELECT_1, interval=1.2)  # 选择位置1
                case 1:
                    self.click(self.C_SELECT_2, interval=1.2)  # 选择位置2
                case 2:
                    self.click(self.C_SELECT_3, interval=1.2)  # 选择位置3
                case 3 | 7 | 11:
                    self.click(self.C_SELECT_4, interval=1.2)  # 选择位置4（可翻页）
                case 5 | 10:
                    self.swipe(self.S_SELECTION, interval=1.5)  # 滑动翻页
                case 12:
                    raise SelectFailed('Select failed')  # 12次尝试后仍失败
```
使用`match-case`实现猫咪选择的自动轮转：
- 位置1-3：直接点击
- 位置4：点击（可能触发翻页）
- 位置5、10：滑动翻页
- 位置12：放弃，抛出异常

```python
        logger.info('Select all kitties done')
```
所有猫咪选择完毕。

### 4.5 `_main_select_kitty`方法 — 经营中选择猫咪

```python
    def _main_select_kitty(self):
        for busy in self.MAIN_BUSY:
            if self.appear(busy):
                continue                                 # 这个位置正在营业，跳过
            self.click(busy, interval=1.3)               # 这个位置空闲，点击选择
            break
```
遍历5个位置，找到第一个空闲位置并点击选择猫咪。通过检测"营业中"标识判断哪些位置正在忙碌。

## 6. 设计模式总结

### 6.1 状态轮转模式
`_select_kitty`使用`index_cnt`计时器实现位置轮转：每1.2秒切换一个选择位置，位置4可触发翻页，位置5/10执行滑动。这是一种基于时间的状态轮转模式。

### 6.2 Match-Case模式
使用Python 3.10的`match-case`语法替代传统的`if-elif`链，使位置选择逻辑更加清晰。`case 3 | 7 | 11`使用了OR模式匹配多个值。

### 6.3 忙碌检测模式
`MAIN_BUSY`列表存储5个位置的"营业中"图片，`_main_select_kitty`遍历列表找到第一个非忙碌位置。这是一种典型的资源池管理模式。

### 6.4 重试机制
猫咪选择最多重试3次（`for trial in range(3)`），每次失败后返回经营主页面重新进入。选择过程本身最多尝试12次（`index_cnt`达到12时抛出异常）。

### 6.5 资源继承复用
继承`ActivityShikigamiAssets`以复用通用UI资源（如`I_SHI`活动入口、`I_UI_BACK_YELLOW`返回按钮等），避免重复定义。

### 6.6 可配置退出策略
`kitty_quit_when_finished`配置项允许用户选择是否在经营完成时自动点击完成按钮退出，提供了灵活的退出策略。
