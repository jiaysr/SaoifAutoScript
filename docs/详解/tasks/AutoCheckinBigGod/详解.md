# 大神签到任务详解

## 1. 文件概述

大神签到（AutoCheckinBigGod）是自动领取网易大神APP礼包的任务。网易大神是网易游戏的社区APP，玩家可以在其中领取每日礼包。该自动化脚本实现了以下功能：

- 通过ADB连接模拟器并启动大神APP
- 通过Frida从APP内存中提取认证Token
- 支持自动登录（读取auth数据库 + HTTP API）
- 通过大神API获取可领取的礼包列表
- 自动领取所有可领取的礼包
- Token过期时自动重新登录

### 文件清单

| 文件 | 说明 |
|------|------|
| `script_task.py` | 任务主逻辑，包含ADB操作、Frida脚本执行、HTTP API调用 |
| `config.py` | 配置定义，包含使用说明 |
| `assets.py` | 资源定义（当前为空） |

### 依赖

- `oas-checkin-biggod`：外部Python包，提供Frida Server二进制文件和ADB路径
- `frida`：动态插桩框架，用于从APP内存提取Token
- ADB：Android调试桥，用于与模拟器通信

### ADB操作方法

#### `_adb_cmd()` — 执行ADB命令

```python
def _adb_cmd(self, args, timeout=10):
    cmd = [ADB_PATH]
    if hasattr(self, '_adb_serial') and self._adb_serial and args[0] not in ['connect', 'devices']:
        cmd.extend(['-s', self._adb_serial])
    cmd.extend(args)
    result = subprocess.run(cmd, capture_output=True, text=True, timeout=timeout,
                            creationflags=_NO_WINDOW)
    return result.stdout.strip()
```

封装ADB命令执行，自动添加设备序列号参数。

#### `_check_adb_connection()` — 检查ADB连接

```python
def _check_adb_connection(self):
    serial = str(self.config.script.device.serial)
    if serial and serial != 'auto':
        result = self._adb_cmd(['connect', serial], timeout=10)
        self._adb_serial = serial
    else:
        self._adb_serial = None
    output = self._adb_cmd(['devices'])
    lines = [l for l in output.strip().split('\n')[1:] if l.strip() and '\tdevice' in l]
    if len(lines) == 0:
        return False
    if not self._adb_serial and len(lines) == 1:
        self._adb_serial = lines[0].split('\t')[0]
    return True
```

**连接逻辑**：
1. 如果配置了设备序列号，尝试 `adb connect`
2. 检查 `adb devices` 输出
3. 如果只有一个设备且未指定序列号，自动使用该设备

#### `_launch_app()` — 启动大神APP

```python
def _launch_app(self):
    pid = self._get_app_pid()
    if pid:
        return pid
    # 优先后台启动（ContentProvider）
    try:
        subprocess.run([ADB_PATH, 'shell', 'su', '0', 'content', 'query', '--uri',
                        f'content://{GL_PACKAGE}.utilcode.provider/'], ...)
    except:
        pass
    # 等待进程启动
    for _ in range(10):
        time.sleep(2)
        pid = self._get_app_pid()
        if pid:
            return pid
    # 回退：monkey前台启动后按HOME切后台
    self._adb_shell(['monkey', '-p', GL_PACKAGE, '-c', 'android.intent.category.LAUNCHER', '1'])
```

**启动策略**：
1. 已在运行 → 直接返回PID
2. 后台启动（需要su权限）→ 等待
3. 前台启动后立即按HOME切回后台

### Frida操作方法

#### `_ensure_frida_server_running()` — 确保Frida Server运行

```python
def _ensure_frida_server_running(self):
    if self._is_frida_server_running():
        return True
    if not self._is_frida_server_installed():
        if not self._push_frida_server():
            return False
    return self._start_frida_server()
```

**检查链**：运行中？→ 已安装？→ 推送安装 → 启动

#### `_ensure_frida_repl()` — 建立常驻Frida REPL

```python
def _ensure_frida_repl(self, pid):
    if self._frida_session is not None:
        if self._frida_session.poll() is None:
            if self._frida_attached_pid == pid:
                return self._frida_session
    frida_exe = self._get_frida_exe()
    cmd = [frida_exe, '-D', self._adb_serial, '-p', str(pid)]
    proc = subprocess.Popen(cmd, stdin=subprocess.PIPE, stdout=subprocess.PIPE, ...)
    self._frida_session = proc
    # 等待REPL就绪
    for wait_sec in (3, 3, 4):
        time.sleep(wait_sec)
        if self._ping_frida_repl(proc):
            return proc
```

**REPL管理**：
- 首次调用：启动 `frida.exe` 进程并attach到目标APP
- 后续调用：复用已有进程（毫秒级响应）
- PID变化时：关闭旧进程并重新attach

#### `_run_frida_script()` — 执行Frida脚本

```python
def _run_frida_script(self, pid, script_content, timeout=10):
    if self._frida_session is None or self._frida_session.poll() is not None:
        if not self._ensure_frida_repl(pid):
            return self._run_frida_script_oneshot(pid, script_content, timeout)
    proc = self._frida_session
    line = script_content.replace('\n', ' ').replace('\r', '') + '\n'
    proc.stdin.write(line.encode('utf-8'))
    proc.stdin.flush()
    # 读取输出直到 __DONE__ 标记
    # ...
```

**脚本执行**：
1. 确保REPL进程存活
2. 将多行JS压成单行写入stdin
3. 从stdout读取输出直到 `__DONE__` 标记
4. REPL失败时回退到单次执行模式

#### `_extract_token()` — 内存提取Token

def _extract_token(self, pid):
    script = """
Java.perform(function() {
    var YXFDeviceInfo = Java.use('com.netease.gl.glbase.build.YXFDeviceInfo');
    console.log('GL_DEVICEID:' + YXFDeviceInfo.getDeviceId());
    Java.choose('com.netease.gl.serviceaccount.proto.auth.GLAuth$Authed', {
        onMatch: function(instance) {

            console.log('GL_TOKEN:' + instance.getToken());

def _frida_sign(self, url, body, headers=None):

### 自动登录流程

#### `_auto_login()` — 自动登录

```python
def _auto_login(self, pid):
    # 第1步：从auth数据库读取URS凭据
    urs_creds = self._get_urs_credentials(pid)
    if not urs_creds:
        return pid, None
    # 第2步：调用login-by-urs-token API
    token_data = self._login_by_urs_token(pid, urs_creds)
    return self._get_app_pid(), token_data
```

## 6. 设计模式总结

### 6.1 管道模式（Pipeline）

整个流程分为5个阶段，每个阶段有明确的输入/输出和错误处理。任何阶段失败都会设置下次运行时间并退出。

### 6.2 双重认证获取

Token获取支持两种方式：
1. **自动登录**（快速）：读取数据库 + HTTP API
2. **内存提取**（回退）：Frida从堆上搜索

优先使用快速方式，失败时回退到内存提取。

### 6.3 常驻进程复用

Frida REPL进程采用常驻模式：
- 首次调用启动进程（3-5秒）
- 后续调用复用进程（毫秒级）
- PID变化时自动重建

这比每次启动新进程（`_run_frida_script_oneshot`）快数十倍。

### 6.4 Token过期自动重登

所有API调用都检测Token过期状态（code 802/805 或关键词匹配），过期时自动调用 `_relogin()` 重新登录并重试。

### 6.5 签名安全机制

大神API的请求需要通过APP内部的 `Tools.getPostMethodSignatures` 函数签名。脚本通过Frida调用该函数生成签名URL，确保请求合法性。

### 6.6 资源清理保证

`_cleanup()` 方法确保：
- 关闭Frida REPL进程
- 强制停止大神APP
- 杀死Frida Server
- 恢复阴阳师前台

即使任务异常退出，也会在 `run()` 的最后调用清理。
