# 斗技（Duel）任务详解

## 1. 文件概述

斗技任务是《阴阳师》手游中"斗技"（PVP 对战）功能的自动化脚本模块。斗技每天 12:00-23:00 开放，玩家通过匹配对手进行式神对战，胜利可获得分数和荣誉。

**核心功能：**
- 自动匹配对手并进行斗技战斗
- 支持普通斗技和名仕（Ban/Pick）模式
- 自动切换御魂和阴阳师
- 一键切换斗技御魂
- 绿标功能（标记优先攻击目标）
- 分数追踪和目标分数判断
- 荣誉满时自动退出
- 超时保护和战斗超时检测
- 名仕模式下自动检测式神被 Ban 并退出

**文件组成：**
| 文件 | 作用 |
|------|------|
| `script_task.py` | 任务主逻辑，含匹配、准备、战斗、结算全流程 |
| `config.py` | 配置模型定义（调度器、斗技配置、名仕配置、御魂切换） |
| `assets.py` | 图像/点击/OCR 资源定义（自动生成） |

## 2. 配置参数说明

### 2.1 DuelConfig（斗技配置）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `switch_enabled` | `bool` | `True` | 是否切换阴阳师 |
| `switch_onmyoji` | `Onmyoji` | `YORIMITSU` | 切换到哪个阴阳师（默认缘结神） |
| `switch_all_soul` | `bool` | `False` | 是否一键切换斗技御魂 |
| `limit_time` | `Time` | `00:30:00` | 斗技最大运行时间 |
| `target_score` | `int` | `2000` | 目标分数（达到后停止） |
| `honor_full_exit` | `bool` | `False` | 荣誉满时是否退出 |
| `green_enable` | `bool` | `False` | 是否开启绿标 |
| `green_mark` | `GreenMarkType` | `GREEN_LEFT1` | 绿标位置 |

### 2.2 DuelCelebConfig（名仕配置）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `celeb_battle` | `bool` | `False` | 是否开启名仕战斗 |
| `ban_name` | `str` | `''` | 第五手式神名称（被 Ban 时退出） |
| `initial_score` | `int` | `3800` | 初始斗技分数（名仕模式，赢+100/输-100） |

### 2.3 SwitchSoulConfig（御魂切换配置）

继承自通用御魂切换组件，支持按组队和按名称两种切换方式。

### 2.4 Scheduler（调度器）

继承默认调度器，无额外参数。

### 4.3 `prepare_duel()` 准备工作

```python
def prepare_duel(self):
    self.ui_goto_page(page_main)
    self.switch_soul()
    if self.conf.duel_config.switch_enabled:
        self.ui_goto_page(page_onmyodo)
        self.switch_onmyoji(self.conf.duel_config.switch_onmyoji)
    self.ui_goto_page(page_duel)
    self.switch_all_soul()
    self.current_score = self.conf.duel_celeb_config.initial_score
```
- 切换御魂 → 切换阴阳师 → 导航到斗技页面 → 一键切换斗技御魂 → 初始化分数

### 4.4 `can_start_duel()` 退出条件判断

```python
def can_start_duel(self) -> bool:
    if datetime.now() - self.start_time >= self.limit_time:
        return False
    if self.get_and_update_cur_score() >= self.conf.duel_config.target_score:
        return False
    if not self.conf.duel_celeb_config.celeb_battle and self.is_celeb:
        return False
    if self.appear(self.I_BATTLE_WITH_TRAIN) or self.appear(self.I_BATTLE_WITH_TRAIN2):
        return False
    if self.conf.duel_config.honor_full_exit and self.check_honor():
        return False
    return True
```
- 5 个退出条件：
  1. 超过限制时间
  2. 达到目标分数
  3. 到达名仕且不开启名仕战斗
  4. 进入练习模式
  5. 荣誉满了

### 4.5 `start_duel()` 单次斗技

```python
def start_duel(self):
    self.current_count += 1
    self.enter_battle()
    self.battle_prepare()
    battle_ret = self.wait_battle()
    if battle_ret:
        self.battle_win_count += 1
    else:
        self.battle_lose_count += 1
    logger.info(f'battle count:{self.current_count} | win:{self.battle_win_count} failure:{self.battle_lose_count}')
    self.ui_goto_page(page_duel)
```
- 进入战斗 → 准备 → 等待结果 → 更新计数 → 返回斗技主界面

### 4.9 `get_and_update_cur_score()` 分数更新

```python
def get_and_update_cur_score(self, skip_screenshot: bool = True) -> int:
    self.maybe_screenshot(skip_screenshot)
    score = self.current_score
    self.is_celeb = False
    if self.appear(self.I_D_CELEB_STAR) or self.appear(self.I_D_CELEB_HONOR):
        self.is_celeb = True
        if self.battle_win_count - self.pre_battle_win_cnt == 1:
            self.pre_battle_win_cnt = self.battle_win_count
            score += 100
        elif self.battle_lose_count - self.pre_battle_lose_cnt == 1:
            self.pre_battle_lose_cnt = self.battle_lose_count
            score -= 100
    else:
        score, remain, total = self.O_D_SCORE.ocr(self.device.image)
        if score > 10000:
            score = int(str(score)[1:])
    self.current_score = score
    return self.current_score
```
- 名仕模式：通过胜负计数推算分数变化（+100/-100）
- 普通模式：OCR 直接读取分数
- 分数超过 10000 时去掉最高位（OCR 识别错误修正）

### 4.10 `check_honor()` 荣誉检查

```python
def check_honor(self) -> bool:
    if not self.appear(self.I_DUEL_HONOR):
        return False
    roi_x = self.I_DUEL_HONOR.roi_front[0] + self.I_DUEL_HONOR.roi_front[2]
    roi_y = self.I_DUEL_HONOR.roi_front[1]
    roi_w = 110
    roi_h = self.I_DUEL_HONOR.roi_front[3]
    self.O_D_HONOR.roi = [roi_x, roi_y, roi_w, roi_h]
    current, remain, total = self.O_D_HONOR.ocr(self.device.image)
    return current == total and remain == 0
```
- 动态计算荣誉 OCR 区域（基于荣誉图标的右侧）
- `DigitCounter` 模式返回 `current/remain/total`
- 当 `current == total` 且 `remain == 0` 时荣誉已满

### 4.11 `switch_all_soul()` 一键切换御魂

```python
def switch_all_soul(self):
    if not self.conf.duel_config.switch_all_soul:
        return
    click_count = 0
    while 1:
        self.screenshot()
        if click_count >= 3:
            break
        if self.appear_then_click(self.I_D_TEAM, interval=1):
            continue
        if self.appear_then_click(self.I_UI_CONFIRM, interval=0.6):
            continue
        if self.appear_then_click(self.I_D_TEAM_SWTICH, interval=1):
            click_count += 1
            continue
    self.ui_click(self.I_UI_BACK_YELLOW, self.I_D_TEAM)
```
- 点击阵容 → 一键切换 → 确认，重复 3 次确保所有式神御魂切换完成

### 4.12 `duel_exit_battle()` 退出战斗

```python
def duel_exit_battle(self):
    while 1:
        self.screenshot()
        if self.appear(self.I_D_FAIL) or self.appear(self.I_FALSE):
            return
        if self.appear_then_click(self.I_EXIT_ENSURE):
            continue
        if self.appear_then_click(self.I_DUEL_EXIT, interval=1) or \
                self.appear_then_click(self.I_EXIT, interval=1):
            continue
```

- 点击退出 → 确认 → 等待失败界面出现

## 6. 设计模式总结

### 6.1 状态机模式
- 整个斗技流程由多个状态组成：
  - **主界面** → **匹配中** → **准备界面** → **战斗中** → **结算** → **主界面**
- 每个状态通过图像匹配判断
- `is_in_battle_prepare()` / `is_battle_win()` / `is_battle_lose()` / `is_battle_end()` 封装状态判断

### 6.2 多重退出条件模式
- `can_start_duel()` 方法封装了 5 个退出条件
- 任何条件满足即停止斗技
- 条件检查在每次循环开始时执行

### 6.3 超时保护机制
- **任务级超时**：`limit_time` 限制总运行时间
- **战斗级超时**：`Timer(270)` 单场战斗 270 秒
- **重试计数**：`battle_timeout_cnt >= 3` 超时 3 次强制退出
- **准备界面重试**：`not_in_prepare_cnt >= 3` 识别失败 3 次退出

### 6.4 动态 ROI 调整
- `check_honor()` 根据荣誉图标位置动态计算 OCR 区域
- 适应不同分辨率和界面布局

### 6.5 分数推算与修正
- 名仕模式：通过胜负计数推算分数（±100）
- 普通模式：OCR 直接读取
- 修正逻辑：分数 > 10000 时去掉最高位

### 6.6 Ban/Pick 检测模式
