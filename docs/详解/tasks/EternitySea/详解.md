# EternitySea 永生之海 任务详解

## 1. 文件概述

**任务功能**: 自动挑战永生之海御魂副本，支持队长/队员/单人三种模式。永生之海需要两套御魂配置（双队伍），支持独立的御魂切换设置。

- **队长模式 (LEADER)**: 创建队伍、邀请队友、循环挑战
- **队员模式 (MEMBER)**: 接受邀请、等待队长开始战斗
- **单人模式 (ALONE)**: 独自挑战（仅支持锁定阵容模式）

**文件结构**:
- `script_task.py` - 任务主逻辑入口
- `config.py` - 配置参数定义
- `assets.py` - 图像/点击/OCR等资源定义

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `user_status` | UserStatus | LEADER | 用户身份 |

### Layer 枚举（层数）

| 值 | 说明 |
|----|------|
| `ONE` | 壹层 |
| `TWO` | 贰层 |
| `THREE` | 叁层 |

### UserStatus 枚举

复用自 `tasks/Orochi/config.py` 中的 `UserStatus` 定义（LEADER/MEMBER/ALONE/WILD）。

### _two_teams_switch_sous() - 双队伍御魂切换

```python
def _two_teams_switch_sous(self, config):
    if config.enable:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(config.switch_group_team)

    if config.enable_switch_by_name:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul_by_name(config.group_name, config.team_name)
```

封装御魂切换逻辑为独立方法，因为永生之海需要切换两套御魂。

### run() - 主入口方法

```python
def run(self) -> None:
    # 切换两套御魂配置
    self._two_teams_switch_sous(self._task_config.switch_soul_config_1)
    self._two_teams_switch_sous(self._task_config.switch_soul_config_2)

    # 根据身份选择执行模式
    match self._task_config.eternity_sea_config.user_status:
        case UserStatus.LEADER: success = self.run_leader()
        case UserStatus.MEMBER: success = self.run_member()
        case UserStatus.ALONE:  success = self.run_alone()

    # 设置下次运行时间
    if success:
        self.set_next_run(self.task_name, finish=True, success=True)
    else:
        self.set_next_run(self.task_name, finish=False, success=False)

    raise TaskEnd(self.task_name)
```

### run_leader() - 队长模式

```python
def run_leader(self):
    # 1. 导航到永生之海
    self._navigate_to_soul_zones()
    self._enter_eternity_sea()

    # 2. 选层、锁阵容
    layer = self._task_config.eternity_sea_config.layer
    self.check_layer(layer)
    self.check_lock(self._task_config.general_battle_config.lock_team_enable)

    # 3. 创建队伍和房间
    while 1:
        self.screenshot()
        if self.appear(self.I_CHECK_TEAM): break
        if self.appear_then_click(self.I_FORM_TEAM, interval=1): continue
    self.create_room()
    self.ensure_private()
    self.create_ensure()

    # 4. 主循环
    success = True
    is_first = True
    while 1:
        self.screenshot()
        if self.check_and_invite(self._task_config.invite_config.default_invite):
            continue
        # 检查限制
        if self.current_count >= self._task_config.eternity_sea_config.limit_count: break
        if datetime.now() - self.start_time >= self._limit_time: break
        # 检查房间存活
        if not self.is_in_room():
            if self.is_room_dead(): success = False; break
            continue
        # 邀请并战斗
        if not is_first:
            if self.run_invite(config=self._task_config.invite_config):
                self.run_general_battle(config=self._task_config.general_battle_config)
            else: success = False; break
        if is_first:
            if not self.run_invite(config=self._task_config.invite_config, is_first=True):
                success = False; break
            else:
                is_first = False
                self.run_general_battle(config=self._task_config.general_battle_config)

    # 5. 退出清理
    self.exit_room()
    self.exit_team()
    self.ui_get_current_page()
    self.ui_goto(page_main)
    return success
```

### run_member() - 队员模式

```python
def run_member(self):
    self.ui_get_current_page()
    self.device.stuck_record_add('BATTLE_STATUS_S')
    while 1:
        self.screenshot()
        # 检查限制
        if self.current_count >= self._task_config.eternity_sea_config.limit_count: break
        if datetime.now() - self.start_time >= self._limit_time: break
        # 接受邀请
        if self.check_then_accept(): continue
        # 等待战斗
        if self.is_in_room():
            self.device.stuck_record_clear()
            if self.wait_battle(wait_time=self._task_config.invite_config.wait_time):
                self.run_general_battle(config=self._task_config.general_battle_config)
            else: break
        elif self.check_take_over_battle(False, config=self._task_config.general_battle_config):
            continue
    # 退出清理
    while 1:
        if self.appear(self.I_GI_HOME) or self.appear(self.I_GI_EXPLORE): break
        if self.exit_room(): pass
        if self.exit_battle(): pass
    self.ui_get_current_page()
    self.ui_goto(page_main)
    return True
```

### run_alone() - 单人模式

```python
def run_alone(self) -> bool:
    self._navigate_to_soul_zones()
    self._enter_eternity_sea()

    # 永生之海单人模式仅支持锁定阵容
    if self._task_config.general_battle_config.lock_team_enable == False:
        logger.critical(f"Only supports lock team mode")
        raise RequestHumanTakeover   # 抛出异常请求人工介入

    while 1:
        self.screenshot()
        if not self._is_in_eternity_sea(): continue
        # 检查限制
        if self.current_count >= self._task_config.eternity_sea_config.limit_count: break
        if datetime.now() - self.start_time >= self._limit_time: break
        # 点击挑战
        while 1:
            self.screenshot()
            if self.appear_then_click(self.I_ETERNITY_SEA_FIRE, interval=1): pass
            if not self.appear(self.I_ETERNITY_SEA_FIRE):
                self.run_general_battle(config=self._task_config.general_battle_config)
                break
    return True
```

注意：单人模式强制要求锁定阵容，否则抛出 `RequestHumanTakeover` 异常。

### is_room_dead() - 房间失效检测

```python
def is_room_dead(self) -> bool:
    sleep(0.5)
    if self.appear(self.I_MATCHING) or self.appear(self.I_CHECK_EXPLORATION):
        sleep(0.5)
        if self.appear(self.I_MATCHING) or self.appear(self.I_CHECK_EXPLORATION):
            return True
    return False
```

双重确认机制：首次检测到异常后等待0.5秒再次确认，避免误判。

### check_layer() / check_lock()

```python
def check_layer(self, layer: str) -> bool:
    pos = self.list_find(self.L_LAYER_LIST, layer)
    if pos:
        self.device.click(x=pos[0], y=pos[1])
        return True

def check_lock(self, lock: bool = True) -> bool:
    if lock:
        while 1:
            self.screenshot()
            if self.appear(self.I_NEWETERNITYSEA_LOCK): return True
            if self.appear_then_click(self.I_ETERNITYSEA_UNLOCK, interval=1): continue
    else:
        while 1:
            self.screenshot()
            if self.appear(self.I_ETERNITYSEA_UNLOCK): return True
            if self.appear_then_click(self.I_NEWETERNITYSEA_LOCK, interval=1): continue
```

与其他副本相同的选层和锁阵容逻辑，使用永生之海专用的锁定/解锁图像资源。

## 6. 设计模式总结

### 1. 策略模式 (Strategy Pattern)
- `UserStatus` 枚举决定执行模式
- `Layer` 枚举决定挑战层数
- 复用 `Orochi.config` 中的 `UserStatus`，体现模块间共享

### 2. 模板方法模式 (Template Method Pattern)
- `run()` 定义任务模板：双御魂切换 → 身份分发 → 清理
- `run_leader()`, `run_member()`, `run_alone()` 实现具体流程

### 3. 属性方法封装
- 使用 `@property` 封装配置访问（`_task_config`, `_limit_time`, `task_name`）
- 提供类型提示和统一访问入口
- 相比直接访问 `self.config.xxx` 更清晰

### 4. 双队伍御魂切换
- `switch_soul_config_1` 和 `switch_soul_config_2` 支持两套独立的御魂配置
- `_two_teams_switch_sous()` 方法封装复用切换逻辑
- 这是永生之海独有的特性（需要两支队伍）

### 5. 安全约束
- 单人模式强制锁定阵容，否则抛出 `RequestHumanTakeover`
- 使用 `logger.critical()` 记录严重错误
- 确保不会因配置错误导致任务失败

### 6. 导航辅助方法
- `_navigate_to_soul_zones()`, `_enter_eternity_sea()`, `_is_in_eternity_sea()` 等私有方法
- 提高代码可读性和复用性
- `_enter_eternity_sea()` 处理了误触录像按钮的边界情况
