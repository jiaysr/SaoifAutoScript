# 真蛇（TrueOrochi）任务详解

## 1. 文件概述

真蛇任务是《阴阳师》手游中"真·八岐大蛇"副本的自动化脚本模块。该副本每周最多可成功挑战 2 次，需要消耗 60 体力创建房间，支持单人或组队模式。

**核心功能：**
- 自动检测真蛇是否出现，若未出现则通过反复挑战十层八岐大蛇来触发真蛇出现（最多 10 次）
- 支持两种御魂切换方式（按组队/按名称）
- 自动创建房间、设置私人房间、准备战斗
- 战斗过程中自动处理贪吃鬼弹窗、头像框确认等交互
- 基于 ISO 周数的次数管理，跨周自动重置挑战次数
- 胜利后 3 天再次调度，失败后 1 天再次调度

**文件组成：**
| 文件 | 作用 |
|------|------|
| `script_task.py` | 任务主逻辑，继承自八岐大蛇任务 |
| `config.py` | 配置模型定义（调度器、挑战配置、御魂切换） |
| `assets.py` | 图像/点击/OCR 资源定义（自动生成） |

## 2. 配置参数说明

### 2.1 TrueOrochiScheduler（调度器）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `priority` | `int` | `10` | 任务优先级 |
| `success_interval` | `TimeDelta` | `3天` | 挑战成功后的下次调度间隔 |
| `failure_interval` | `TimeDelta` | `1天` | 挑战失败后的下次调度间隔 |

### 2.2 TrueOrochiConfig（挑战配置）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `find_true_orochi` | `bool` | `True` | 是否在真蛇未出现时自动刷十层触发真蛇 |
| `current_success` | `int` | `0` | 本周已成功挑战次数（上限 2） |

### 2.3 GreenMarkType（绿标类型枚举）

| 值 | 说明 |
|------|------|
| `LEFT_1` ~ `LEFT_6` | 左侧 1~6 号位式神 |
| `MAIN` | 主力式神 |

### 2.4 SwitchSoulConfig（御魂切换配置）

继承自通用御魂切换组件，支持按组队和按名称两种切换方式。

| `I_ST_FIRE_PREPARE` | 十个式神的准备按钮 | 0.8 |

## 4. 核心代码逐行解释

### 4.1 类定义与继承

```python
class ScriptTask(OrochiScriptTask, TrueOrochiAssets):
```

- 继承自 `OrochiScriptTask`（八岐大蛇任务），复用其 `orochi_enter()`、`check_layer()`、`check_lock()`、`run_general_battle()` 等方法
- 继承自 `TrueOrochiAssets`，获得所有图像/点击/OCR 资源定义

### 4.2 `run()` 主方法

```python
def run(self):
    conf = self.config.true_orochi.true_orochi_config
```

**第一阶段：次数检查**
```python
    if conf.current_success >= 2:
        logger.warning('This week is full')
        self.check_times(True)
        raise TaskEnd('TrueOrochi')
```
- 检查本周已成功次数，若 >= 2 则本周已完成，设置下次运行时间后抛出 `TaskEnd` 结束任务

**第二阶段：御魂切换**
```python
    if self.config.true_orochi.switch_soul.enable:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(self.config.true_orochi.switch_soul.switch_group_team)
    if self.config.true_orochi.switch_soul.enable_switch_by_name:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul_by_name(...)
```
- 支持两种御魂切换方式，可同时配置（先按组队切，再按名称切）

**第三阶段：进入御魂界面并检测真蛇**
```python
    self.ui_get_current_page()
    self.ui_goto(page_soul_zones)
    self.orochi_enter()
    sleep(0.5)
    battle = self.check_true_orochi(True)
```
- 导航到御魂副本页面，进入八岐大蛇界面
- `check_true_orochi()` 通过图像匹配 `I_FIND_TS` 检测真蛇是否出现

**第四阶段：未出现真蛇时的触发逻辑**
```python
    if not battle:
        if not conf.find_true_orochi:
            self.check_times(False)
            raise TaskEnd('TrueOrochi')
        self.check_layer(Layer.TEN)
        self.check_lock(False)
        count_orochi_ten = 0
        while 1:
            self.screenshot()
            if self.appear_then_click(self.I_PET_PRESENT, action=self.C_WIN_3, interval=1):
                continue
            if not self.appear(self.I_OROCHI_FIRE):
                continue
            if self.check_true_orochi(False):
                battle = True
                break
            if count_orochi_ten >= 10:
                battle = False
                break
            if self.appear(self.I_OROCHI_FIRE):
                self.ui_click_until_disappear(self.I_OROCHI_FIRE)
                self.run_general_battle()
                count_orochi_ten += 1
```
- 选择十层，关闭锁定阵容
- 循环挑战十层最多 10 次，每次挑战后检测真蛇是否出现
- 自动处理猫咪奖励弹窗

**第五阶段：真蛇战斗流程**
```python
    conf.current_success += 1
    while 1:
        self.screenshot()
        if self.appear(self.I_ST_CREATE_ROOM):
            break
        if self.appear_then_click(self.I_ST_FIRE, interval=4):
            current, current_success, total = self.O_TIMES.ocr(self.device.image)
            if current_success < 0 or current_success > 2:
                continue
            conf.current_success = current_success
            self.config.save()
```
- 点击挑战按钮，通过 OCR 修正本周成功次数
- 等待创建房间界面出现

```python
    self.ensure_private()
```
- 确保设置为私人房间

```python
    while 1:
        if self.appear(self.I_ST_FIRE_PREPARE):
            break
        if self.appear_then_click(self.I_FIRE, interval=3, threshold=0.7):
            continue
        if self.appear_then_click(self.I_UI_CONFIRM, interval=1):
            continue
        if self.appear_then_click(self.I_ST_CREATE_ROOM, interval=1):
            continue
```
- 创建房间后，等待准备界面出现

**第六阶段：战斗准备与执行**
```python
    self.ui_click(self.I_ST_FIRE_PREPARE, self.I_BUFF)
    while 1:
        if not self.appear(self.I_BUFF):
            break
        if self.appear_then_click(self.I_ST_AUTO_FALSE, interval=1.8):
            continue
```
- 点击准备按钮，开启自动战斗，等待 BUFF 界面消失

**第七阶段：战斗等待与结束处理**
```python
    check_timer = Timer(280)
    check_timer.start()
    check_count = 0
    while 1:
        self.screenshot()
        if self.appear(self.I_GREED_GHOST):
            # 处理贪吃鬼弹窗
            ...
            break
        if self.appear_then_click(self.I_ST_FRAME, interval=1):
            continue
        if check_timer.reached():
            if check_count > 3:
                raise GameStuckError
            check_count += 1
            check_timer.reset()
```
- 设置 280 秒超时计时器
- 等待战斗结束（头像框出现）
- 处理贪吃鬼弹窗（左上角出现的灵魂碎片收集）
- 超时 3 次后抛出 `GameStuckError`

### 4.3 `check_true_orochi()` 方法

```python
def check_true_orochi(self, screenshot=False) -> bool:
    if screenshot:
        self.screenshot()
    return self.appear(self.I_FIND_TS)
```
- 简单的图像匹配，判断真蛇标识图是否出现在当前截图中

### 4.4 `check_times()` 次数管理方法

```python
def check_times(self, battle: bool):
    now = datetime.now()
    now_year, now_week_number, now_weekday = now.isocalendar()
    if battle:
        next_run = now + self.config.true_orochi.scheduler.success_interval
    else:
        next_run = now + self.config.true_orochi.scheduler.failure_interval
    next_run_year, next_run_week_number, next_run_weekday = next_run.isocalendar()
    if now_week_number != next_run_week_number:
        self.config.true_orochi.true_orochi_config.current_success = 0
    else:
        self.config.true_orochi.true_orochi_config.current_success += 1
        self.config.true_orochi.true_orochi_config.current_success = min(2, ...)
    self.config.save()
    self.set_next_run(task='TrueOrochi', target=next_run)
```
- 使用 ISO 日历周数判断是否跨周
- 跨周则重置成功次数为 0
- 同周则累加（上限 2）
- 根据成功/失败设置不同的下次运行间隔

## 6. 设计模式总结

### 6.1 模板方法模式
- `ScriptTask` 继承自 `OrochiScriptTask`，复用父类的 `orochi_enter()`、`check_layer()`、`run_general_battle()` 等模板方法
- 子类只需实现 `run()` 主流程和真蛇特有的逻辑

### 6.2 状态机模式
- 整个任务流程由多个 `while` 循环构成隐式状态机
- 每个状态通过图像匹配（`appear`/`appear_then_click`）进行状态转移
- 状态包括：次数检查 → 御魂切换 → 进入副本 → 检测真蛇 → 触发真蛇 → 战斗 → 结束

### 6.3 资源分离模式
- 所有 UI 交互资源（图像模板、点击区域、OCR 配置）集中在 `assets.py` 中定义
- 资源通过继承注入到任务类中，与业务逻辑解耦
- 资源文件由 `dev_tools/assets_extract.py` 自动生成

### 6.4 调度器模式
- 使用 `Scheduler` 基类管理任务调度
- 根据成功/失败设置不同的重试间隔
- 基于 ISO 周数的周期性重置机制

### 6.5 容错与超时机制
- `Timer` 类实现超时检测（280 秒战斗超时）
- `GameStuckError` 异常处理死循环情况
- `check_count` 计数器防止无限重试
- 贪吃鬼弹窗的双重确认（出现 → 等待 → 再次确认消失）
