# DailyTrifles 每日杂事 任务详解

## 1. 文件概述

**任务功能**: 自动完成阴阳师每日杂事任务，包括：
- 每日召唤（普通召唤/今忆召唤）
- 友情点收取
- 吉闻祝福
- 商店签到
- 购买体力（寿司）

**入口文件**: `tasks/DailyTrifles/script_task.py`

---

## 2. 配置参数说明

**配置文件**: `tasks/DailyTrifles/config.py`

### DailyTriflesConfig 参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `one_summon` | bool | False | 是否执行每日召唤 |
| `summon_type` | SummonType | default | 召唤类型：普通召唤/今忆召唤 |
| `draw_mystery_pattern` | bool | False | 是否绘制神秘图案（跨月自动重置） |
| `guild_wish` | bool | False | 是否执行寮祈愿（未实现） |
| `friend_love` | bool | False | 是否收取友情点 |
| `luck_msg` | bool | False | 是否处理吉闻 |
| `store_sign` | bool | False | 是否商店签到 |
| `buy_sushi_count` | int | -1 | 每天购买体力数量（-1表示不购买） |

### SummonType 枚举

| 值 | 说明 |
|----|------|
| `default` | 普通召唤 |
| `recall` | 今忆召唤 |

## 4. 核心代码逐行解释

### ScriptTask.run() - 主入口

```python
def run(self):
    con = self.config.daily_trifles.trifles_config
    # 每日召唤
    if con.one_summon:
        self.run_one_summon()
    if con.guild_wish:
        pass  # 寮祈愿暂未实现
    # 友情点
    if con.friend_love:
        self.run_friend_love()
    # 吉闻
    if con.luck_msg:
        self.run_luck_msg()
    # 商店签到 or 购买寿司
    if con.store_sign or con.buy_sushi_count > 0:
        self.run_store()
    self.set_next_run('DailyTrifles', success=True, finish=False)
    raise TaskEnd('DailyTrifles')
```

**逻辑说明**:
1. 读取配置
2. 根据配置依次执行各子任务
3. 设置下次运行时间
4. 抛出TaskEnd异常结束任务

### run_one_summon() - 每日召唤

```python
def run_one_summon(self):
    self.ui_get_current_page()
    self.ui_goto(page_summon)  # 导航到召唤页面
    config = self.config.daily_trifles.trifles_config
    if config.summon_type == SummonType.default:
        self.summon_one(draw_mystery_pattern=config.draw_mystery_pattern)
        self.check_time()  # 检查是否跨月重置神秘图案
    elif config.summon_type == SummonType.recall:
        self.summon_recall()  # 今忆召唤
    self.back_summon_main()
```

### check_time() - 跨月检查

```python
def check_time(self):
    config = self.config.daily_trifles.trifles_config
    now = datetime.now()
    next_run = now + self.config.daily_trifles.scheduler.success_interval
    if next_run.month != now.month:
        # 跨月重置神秘图案
        config.draw_mystery_pattern = True
    else:
        # 同月不需要绘制
        config.draw_mystery_pattern = False
    self.config.save()
```

### run_friend_love() - 友情点收取

```python
def run_friend_love(self):
    self.ui_get_current_page()
    self.ui_goto(page_friends)  # 导航到好友页面
    while 1:
        self.screenshot()
        if self.appear(self.I_L_LOVE):
            break  # 找到友情点标签
        if self.appear_then_click(self.I_FRIENDSHIP_UP, interval=1):
            continue  # 关闭羁绊提升弹窗
        if self.appear_then_click(self.I_L_FRIENDS, interval=1):
            continue  # 点击好友标签
    # 点击收取
    while 1:
        if self.appear_then_click(self.I_L_COLLECT, interval=1):
            continue
        if self.ui_reward_appear_click():
            break  # 收取成功
```

### run_luck_msg() - 吉闻处理

```python
def run_luck_msg(self):
    self.ui_get_current_page()
    self.ui_goto(page_friends)
    # 找到吉闻页面
    while 1:
        if self.appear(self.I_LUCK_TITLE):
            break
        if self.appear_then_click(self.I_FRIENDSHIP_UP, interval=1):
            continue
        if self.ocr_appear_click(self.O_LUCK_MSG, interval=1):
            continue
    # 执行祝福
    while 1:
        if self.appear_then_click(self.I_CLICK_BLESS, interval=1):
            continue
        if self.appear_then_click(self.I_ONE_CLICK_BLESS, interval=1):
            continue
        if self.ui_reward_appear_click():
            break  # 领取奖励成功
```

## 6. 设计模式总结

### 1. 状态机模式
- 使用 `while` 循环 + `screenshot()` + `appear()` 实现状态检测
- 通过 `appear_then_click()` 实现状态转换

### 2. 策略模式
- `SummonType` 枚举区分不同召唤方式
- 根据配置选择不同的执行路径

### 3. 模板方法模式
- `GameUi` 基类提供 UI 导航框架
- 子类实现具体业务逻辑

### 4. 资源分离模式
- 图像/OCR 资源定义在 `assets.py`
- 配置参数定义在 `config.py`
- 业务逻辑在 `script_task.py`

### 5. 定时任务模式
- `set_next_run()` 设置下次执行时间
- `raise TaskEnd` 优雅结束任务
