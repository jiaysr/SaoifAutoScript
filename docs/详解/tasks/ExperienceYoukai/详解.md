# ExperienceYoukai 经验妖怪 任务详解

## 1. 文件概述

**任务功能**: 自动组队挑战经验妖怪副本，包括：
- 切换御魂配置
- 开启经验加成buff
- 创建房间并等待队友
- 执行战斗
- 关闭buff并退出

**入口文件**: `tasks/ExperienceYoukai/script_task.py`

---

## 4. 核心代码逐行解释

### ScriptTask.run() - 主入口

```python
def run(self):
    # 切换御魂
    if self.config.experience_youkai.switch_soul.enable:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul(...)

    if self.config.experience_youkai.switch_soul.enable_switch_by_name:
        self.ui_get_current_page()
        self.ui_goto(page_shikigami_records)
        self.run_switch_soul_by_name(...)

    # 开启加成
    con = self.config.experience_youkai.experience_youkai
    if con.buff_exp_50_click or con.buff_exp_100_click:
        self.ui_get_current_page()
        self.ui_goto(page_main)
        self.open_buff()
        if con.buff_exp_50_click:
            self.exp_50()  # 开启50%经验加成
        if con.buff_exp_100_click:
            self.exp_100()  # 开启100%经验加成
        self.close_buff()

    # 执行两次战斗
    count = 0
    while count < 2:
        self.ui_get_current_page()
        self.ui_goto(page_team)
        self.check_zones('经验妖怪')  # 选择经验妖怪副本

        # 创建房间
        if not self.create_room():
            self.experience_exit(con)
        self.ensure_public()
        self.create_ensure()

        # 等待队友
        wait_timer = Timer(50)
        wait_timer.start()
        while 1:
            self.screenshot()
            if not self.is_in_room():
                continue
            if wait_timer.reached():
                logger.warning('Wait for too long')
                self.click_fire()
                count += 1
                self.run_general_battle()
                break
            if not self.appear(self.I_ADD_5_1):
                logger.info('There is someone in the room')
                self.click_fire()
                count += 1
                self.run_general_battle()
                break

    # 退出
    self.experience_exit(con)
```

### battle_wait() - 战斗等待（重写）

```python
def battle_wait(self, random_click_swipt_enable: bool) -> bool:
    self.device.stuck_record_add('BATTLE_STATUS_S')
    self.device.click_record_clear()

    logger.info("Start battle process")
    while 1:
        self.screenshot()
        if self.appear_then_click(self.I_PREPARE_HIGHLIGHT, interval=1):
            logger.info('click prepare')
        # 经验妖怪专用胜利标识
        if self.appear(self.I_DE_WIN):
            logger.info('Win battle')
            self.ui_click_until_disappear(self.I_DE_WIN)
            return True
        if self.appear(self.I_EXP_WIN):
            logger.info('Win battle')
            self.ui_click_until_disappear(self.I_EXP_WIN)
            return True
        if self.appear(self.I_FALSE):
            logger.warning('False battle')
            self.ui_click_until_disappear(self.I_FALSE)
            return False
```

### experience_exit() - 退出清理

```python
def experience_exit(self, con):
    self.ui_get_current_page()
    self.ui_goto(page_main)

    # 关闭buff
    if con.buff_exp_50_click or con.buff_exp_100_click:
        self.open_buff()
        if con.buff_exp_50_click:
            self.exp_50(False)  # 关闭50%加成
        if con.buff_exp_100_click:
            self.exp_100(False)  # 关闭100%加成
        self.close_buff()

    self.set_next_run(task='ExperienceYoukai', success=True, finish=False)
    raise TaskEnd('ExperienceYoukai')
```

## 6. 设计模式总结

### 1. 代码复用模式
- 与 `GoldYoukai` 结构几乎相同
- 仅副本名称和胜利标识不同
- 体现了良好的代码复用设计

### 2. 组件组合模式
- 继承：`GameUi`, `GeneralBattle`, `GeneralRoom`, `GeneralInvite`, `SwitchSoul`
- 各组件职责单一，组合使用

### 3. 配置驱动模式
- 通过配置控制是否开启buff
- 通过配置控制御魂切换

### 4. 超时处理
- `Timer(50)` 控制等待时间
- 超时后自动开始挑战，避免卡死

### 5. 状态检测
- `is_in_room()` 检测房间状态
- `I_ADD_5_1` 检测空位
- `I_EXP_WIN` 检测胜利
