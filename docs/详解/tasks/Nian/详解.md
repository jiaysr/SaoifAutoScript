# 年兽任务详解

## 1. 文件概述

年兽（Nian）是《阴阳师》游戏中的组队副本玩法。玩家需要与其他玩家组队匹配，共同击败年兽BOSS以获取奖励。该自动化脚本实现了以下功能：

- 自动导航至组队页面并选择"年兽"副本
- 检测冷却时间（CD），若在CD中则自动计算下次可挑战时间并退出
- 发起自动匹配，等待其他玩家加入
- 匹配成功后自动进入战斗，支持开启金币加成Buff（50%/100%）
- 战斗结束后自动关闭Buff并设置下次运行时间

### 文件清单

| 文件 | 说明 |
|------|------|
| `script_task.py` | 任务主逻辑入口，包含匹配、战斗、CD检测等核心流程 |
| `config.py` | 配置定义，包含调度器配置和年兽专属Buff开关 |
| `assets.py` | 资源定义，包含图片匹配模板、OCR规则、点击区域等 |

## 4. 核心代码逐行解释

### `ScriptTask` 类

```python
class ScriptTask(GameUi, GeneralBattle, GeneralRoom, GeneralInvite, NianAssets):
```

**多重继承设计**：继承了5个基类：
- `GameUi`：提供UI页面导航能力（`ui_get_current_page`, `ui_goto`）
- `GeneralBattle`：提供通用战斗能力（`run_general_battle`, `check_take_over_battle`）
- `GeneralRoom`：提供房间管理能力（`create_room`, `is_in_room`, `wait_battle`）
- `GeneralInvite`：提供邀请能力
- `NianAssets`：提供年兽任务的图片/OCR/点击资源

### `run()` 方法 — 主入口

```python
def run(self) -> None:
```

#### 4.1 内部辅助函数 `cd_exit`

```python
def cd_exit(cd: timedelta=False):
    logger.warning(f'Nian in CD {cd}')
    if cd is False:
        self.set_next_run(task='Nian', success=False, finish=True)
        raise TaskEnd('Nian')
    next_run = datetime.now() + cd
    self.set_next_run(task='Nian', success=False, finish=False, target=next_run)
    raise TaskEnd('Nian')
```

- 当 `cd=False`（布尔False）时，表示无法确定CD时间，标记任务为完成状态退出
- 当 `cd` 为 `timedelta` 对象时，计算下次可挑战时间（当前时间 + CD剩余时间），设置为下次运行时间后退出

#### 4.2 导航到组队页面

```python
self.ui_get_current_page()
self.ui_goto(page_team)
con = self.config.nian.nian_config
```

- `ui_get_current_page()`：截图并识别当前所在页面
- `ui_goto(page_team)`：自动导航到组队页面
- 读取年兽配置

#### 4.3 检查副本区域和冷却

```python
self.check_zones('年兽')
cd = self.check_cd()
if cd:
    cd_exit(cd)
```

- `check_zones('年兽')`：在组队页面中找到并选择"年兽"副本
- `check_cd()`：检查是否在冷却中，如果在CD中则调用 `cd_exit` 退出

#### 4.4 点击自动匹配按钮

```python
cd_count = 0
while 1:
    self.screenshot()
    if self.appear(self.I_N_WAITING):
        break
    if cd_count >= 4:
        cd_exit()
    if self.appear_then_click(self.I_GR_AUTO_MATCH, interval=1.5):
        cd_count += 1
        continue
```

- 循环截图检测：如果出现等待界面（`I_N_WAITING`）则匹配已发起
- 如果连续点击4次自动匹配按钮（每次间隔1.5秒）仍未进入等待界面，判定为CD中并退出
- `appear_then_click`：先检测图片是否出现，出现则点击

#### 4.5 等待匹配完成

```python
logger.info('Waiting for match')
click_timer = Timer(240)
check_timer = Timer(480)
click_timer.start()
check_timer.start()
```

设置两个计时器：
- `click_timer`（240秒）：第一次超时，尝试点击安全区域刷新
- `check_timer`（480秒）：第二次超时，放弃匹配

#### 4.6 匹配主循环

```python
while 1:
    self.screenshot()
    # 被秒开进入战斗
    if self.check_take_over_battle(False, config=self.battle_config):
        logger.info('Nian take over battle')
        break
    # 进入房间
    elif self.is_in_room():
        self.device.stuck_record_clear()
        if self.wait_battle(wait_time=time(minute=1)):
            # 开启Buff
            buff = []
            if con.buff_gold_50_click:
                buff.append(BuffClass.GOLD_50)
            if con.buff_gold_100_click:
                buff.append(BuffClass.GOLD_100)
            if buff is []:
                buff = None
            self.run_general_battle(config=self.battle_config, buff=buff)
            # 关闭Buff
            self.open_buff()
            if con.buff_gold_50_click:
                self.gold_50(False)
            if con.buff_gold_100_click:
                self.gold_100(False)
            self.close_buff()
            break
        else:
            break
```

**三种匹配结果处理**：
1. **被秒开**：匹配后直接进入战斗（来不及进入房间），不开启Buff
2. **进入房间**：等待房主开始战斗（最多1分钟），然后开启Buff并执行战斗
3. **超时未开始**：退出

#### 4.7 超时处理

```python
if click_timer and click_timer.reached():
    logger.warning('It has waited for 240s...')
    self.click(self.C_CLIC_SAFE)
    click_timer = None
    # ...
if check_timer.reached():
    logger.warning('Nian match timeout')
    # 退出匹配
```

- 240秒超时：点击安全区域尝试刷新匹配状态
- 480秒超时：彻底放弃匹配，关闭等待界面

### `check_cd()` 方法 — CD检测

```python
def check_cd(self) -> False or timedelta:
    self.screenshot()
    if not self.appear(self.I_N_CHECK):
        return False
    if not self.ocr_appear(self.O_N_BATTLE_AGAIN):
        return False
    result = self.O_N_CD.ocr(self.device.image)
    if not isinstance(result, str):
        logger.error(f'OCR error {result}')
        return False
    try:
        result = re.search(r'(\d+)时(\d+)分后可', result)
        time_delta = timedelta(hours=int(result.group(1)), minutes=int(result.group(2)))
    except Exception as e:
        logger.error(f'{e} {result}')
        time_delta = timedelta(hours=4)
    return time_delta
```

**检测逻辑**：
1. 先判断是否在年兽界面（`I_N_CHECK`图片匹配）
2. 再判断是否出现"再次挑战"文字（`O_N_BATTLE_AGAIN`OCR识别）
3. 两个条件都满足说明在CD中，通过OCR读取剩余时间
4. 使用正则表达式解析"X时Y分后可"格式的时间文本
5. OCR失败时默认CD为4小时

### `battle_config` 属性

```python
@cached_property
def battle_config(self) -> GeneralBattleConfig:
    conf = GeneralBattleConfig()
    return conf
```

使用 `cached_property` 缓存战斗配置，只在首次访问时创建。

## 6. 设计模式总结

### 6.1 组合模式（Mixin）

`ScriptTask` 通过多重继承组合了5个功能基类，每个基类负责一个独立的功能域：
- `GameUi`：页面导航
- `GeneralBattle`：战斗执行
- `GeneralRoom`：房间管理
- `GeneralInvite`：邀请系统
- `NianAssets`：资源定义

这是典型的 **Mixin 模式**，通过组合而非继承实现功能复用。

### 6.2 资源与逻辑分离

所有UI交互资源（图片模板、OCR规则、点击坐标）都定义在 `assets.py` 中，任务逻辑在 `script_task.py` 中通过资源ID引用。这种分离使得：
- 资源可以由工具自动生成（`dev_tools/assets_extract.py`）
- UI变更时只需更新资源文件，不影响逻辑代码

### 6.3 调度器模式

任务通过 `Scheduler` 配置实现定时调度，通过 `set_next_run` 方法设置下次运行时间，通过 `raise TaskEnd` 结束当前执行。

### 6.4 状态机模式

匹配过程采用隐式状态机：
- **初始状态**：导航并选择副本
- **匹配状态**：点击自动匹配并等待
- **战斗状态**：执行战斗逻辑
- **结束状态**：设置下次运行并退出

### 6.5 容错与超时机制

- 多级超时（240秒刷新 + 480秒放弃）
- CD检测使用正则解析+默认值兜底
- OCR失败时使用默认4小时CD
- `stuck_record` 机制防止脚本卡死
