# 鬼兵演武 (HeroTest) 任务详解

## 1. 文件概述

鬼兵演武是《阴阳师》中的英杰试炼玩法，包含多种副本模式。本任务实现了**全自动鬼兵演武刷副本**功能，核心特点：

- **多副本支持**：支持鬼兵演武（经验本）、兵藏秘境（技能本）、传承试炼、梦虚秘境四种模式
- **双英杰切换**：自动切换源赖光/藤原道长，根据副本选择对应英杰
- **智能技能选择**：兵藏秘境/梦虚秘境自动选择最优技能升级路线
- **阵容管理**：支持锁定/解锁阵容
- **经验加成管理**：自动开关50%/100%经验加成
- **御魂切换**：支持切换御魂配置

### 文件清单

| 文件 | 用途 |
|------|------|
| `script_task.py` | 任务主入口，包含战斗循环和各种模式的处理 |
| `config.py` | 配置参数定义 |
| `assets.py` | UI资源定义（图片、点击、OCR规则） |

### 4.2 `run()` 主流程 (第27-60行)

```python
def run(self) -> None:
    self.conf = self.config.hero_test                              # 获取配置
    self.limit_time: timedelta = self.conf.herotest.limit_time     # 时间限制
    # 处理 time → timedelta 类型转换
    if isinstance(self.limit_time, time):
        self.limit_time = timedelta(hours=..., minutes=..., seconds=...)
    self.limit_count = self.conf.herotest.limit_count              # 次数限制

    self.check_and_switch_soul()                                   # 检查并切换御魂
    self.open_exp_buff()                                           # 开启经验加成
    self.switch_hero(self.conf.herotest.layer)                     # 切换对应英杰
    self.init_pages()                                              # 初始化页面链接
    self.ui_goto_page(self.page_hero_mode)                         # 导航到目标副本页面
    self.check_and_lock_team()                                     # 检查并锁定阵容

    while True:
        # 时间检查
        if self.limit_time is not None and self.limit_time + self.start_time < datetime.now():
            break
        # 次数检查
        if self.current_count >= self.limit_count:
            break
        self.ui_goto_page(self.page_hero_mode)                     # 确保在正确页面
        if not self.can_run(self.conf.herotest.layer):             # 检查是否还能运行
            break
        entered = self.enter_battle()                              # 尝试进入战斗
        if not entered:
            break
        if self.run_general_battle(config=self.conf.general_battle):  # 执行自动战斗
            logger.info("General battle success")

    self.close_exp_buff()                                          # 关闭经验加成
    self.set_next_run(task="HeroTest", success=self.success)       # 设置下次运行
    raise TaskEnd
```

### 4.3 `enter_battle()` 进入战斗 (第62-87行)

```python
def enter_battle(self) -> bool:
    click_cnt, max_click = 0, random.randint(3, 4)  # 最多点击3~4次
    while True:
        self.screenshot()
        if self.is_in_battle(False):                 # 已进入战斗
            return True
        if click_cnt >= max_click:                   # 超过最大点击次数
            break
        # 处理各种按钮
        if self.appear_then_click(self.I_START_CHALLENGE, interval=1):  # 兵藏秘境确认挑战
            continue
        if self.appear_then_click(self.I_BCMJ_RESET_CONFIRM, interval=1):  # 确认重置
            continue
        if self.appear(self.I_REAL_MONEY, interval=1):  # 门票不足
            logger.warning('Ticket is not enough')
            return False                                 # 返回False但success仍为True（正常结束）
        if self.appear_then_click(self.O_FIRE, interval=1.2):  # 点击挑战
            self.device.stuck_record_clear()
            click_cnt += 1
            continue

    logger.error('Battle cannot enter, maybe recognize failed')
    self.success = False  # 异常情况，标记失败
    return False
```

### 4.4 `battle_wait()` 战斗等待 (第89-120行)

```python
def battle_wait(self, random_click_swipt_enable: bool) -> bool:
    self.device.stuck_record_add("BATTLE_STATUS_S")
    win = None
    # 不同模式的特殊等待处理
    mode_wait_dict: dict[Layer, Callable] = {
        Layer.MIJING: self.hero1_skill_wait,      # 兵藏秘境：源赖光技能选择
        Layer.MENGXU: self.hero2_skill_wait,       # 梦虚秘境：藤原道长技能选择
    }
    while True:
        self.screenshot()
        if win is not None and self.appear(self.O_FIRE, interval=1.5):
            break                                    # 战斗结束，回到挑战界面
        # 模式特殊处理
        if mode_wait_dict.get(self.conf.herotest.layer, None) is not None:
            if mode_wait_dict[self.conf.herotest.layer]():
                win = True
                continue
        # 通用胜利检测
        if self.appear(self.I_WIN, interval=1.2) or \
                self.appear(self.I_DE_WIN, interval=1.2) or \
                self.appear(self.I_REWARD, interval=1.2):
            win = True
            self.click(pages.random_click(ltrb=(False, True, True, False)))  # 随机点击跳过
            continue
        # 失败检测
        if self.appear(self.I_FALSE, interval=1.5):
            win = False
            self.click(pages.random_click(ltrb=(False, True, True, False)))
            continue
        # 等待中随机点击/滑动（防止卡死）
        if win is None and random_click_swipt_enable:
            self.random_click_swipt()
    return win
```

### 4.5 `hero1_skill_wait()` 源赖光技能选择 (第122-142行)

```python
def hero1_skill_wait(self):
    if self.wait_until_appear(self.I_BCMJ_SKILL_ADD_CONFIRM, wait_time=2):
        while 1:
            self.screenshot()
            # 按优先级选择技能：八华斩 > 无畏 > 祝福 > 暴击伤害 > 默认属性
            if self.appear_then_click(self.I_BCMJ_SKILL_ADD1, interval=1):     # 八华斩
                break
            if self.appear_then_click(self.I_BCMJ_SKILL_ADD2, interval=1):     # 无畏
                break
            if self.appear_then_click(self.I_BCMJ_BLESS, interval=1):          # 默认祝福
                break
            if self.appear_then_click(self.I_BCMJ_PROPERTY_ADD_CRITICAL, interval=1):  # 暴击伤害
                break
            if self.appear_then_click(self.I_BCMJ__DEFALUT_ATTRIBUTE, interval=1):     # 默认属性
                break
        if self.appear_then_click(self.I_BCMJ_SKILL_ADD_CONFIRM, interval=1):  # 确认
            return True
    return False
```

**优先级顺序**：八华斩 → 无畏 → 暴击伤害 → 默认祝福 → 默认属性

### 4.7 `switch_hero()` 英杰切换 (第170-189行)

```python
def switch_hero(self, layer: Layer):
    self.ui_goto_page(pages.page_hero_test)
    # 副本→英杰映射
    switch_hero_dict: dict = {
        Layer.YANWU: (self.I_CHECK_HERO1, self.I_SWITCH_HERO1),       # 鬼兵演武→源赖光
        Layer.MIJING: (self.I_CHECK_HERO1, self.I_SWITCH_HERO1),      # 兵藏秘境→源赖光
        Layer.CHUANCHENG: (self.I_CHECK_HERO2, self.I_SWITCH_HERO2),  # 传承试炼→藤原道长
        Layer.MENGXU: (self.I_CHECK_HERO2, self.I_SWITCH_HERO2),      # 梦虚秘境→藤原道长
    }
    check_hero_img, switch_hero_img = switch_hero_dict[layer]
    while True:
        self.screenshot()
        if self.appear_then_click(switch_hero_img, interval=1):  # 点击切换
            continue
        appeared = self.appear(check_hero_img, interval=1)       # 检查是否已在目标英杰
        if not appeared and self.appear(self.I_CHECK_HERO_TEST):
            self.click(self.C_SWITCH_HERO_BTN, interval=1.5)     # 点击切换按钮
            continue
        if appeared:
            break                                                 # 已切换成功
```

### 4.9 `check_art_war_card()` 门票检查 (第204-217行)

```python
def check_art_war_card(self) -> bool:
    self.screenshot()
    cu = self.O_ART_WAR_CARD.ocr(image=self.device.image)  # OCR识别兵道帖数量
    if cu[0] >= 1:                                          # 有兵道帖
        return True
    cu = self.O_ART_WAR_CARD_PLUS.ocr(image=self.device.image)  # 检查机密兵道帖
    cu = 0 if cu == '' else int(cu)
    if cu >= 1:                                             # 有机密兵道帖
        return True
    return False                                            # 都没有
```

```
│  I_WIN/I_DE_WIN/I_REWARD?     │──→ win=True
│  I_FALSE?                      │──→ win=False
│  random_click_swipt() 防卡死   │
└──────────────┬─────────────────┘
               ▼
       return win
```

## 6. 设计模式总结

### 6.1 动态页面图构建

通过 `Page.link()` 方法在运行时动态构建页面导航图，`ui_goto_page()` 自动计算路径。这是一种**图遍历模式**，将页面视为节点，按钮视为边。

### 6.2 策略分发模式 (Match-Case Dispatch)

大量使用 Python 3.10+ 的 `match-case` 语句进行策略分发：
- `init_pages()`：根据副本类型初始化不同页面
- `switch_hero()`：根据副本切换不同英杰
- `check_and_lock_team()`：根据副本使用不同锁定图标
- `can_run()`：根据副本执行不同检查
- `battle_wait()`：根据副本选择不同等待策略

### 6.3 模板方法模式 (Template Method)

`run()` 定义了固定的执行骨架（初始化 → 循环战斗 → 清理），具体步骤由不同层的配置和方法实现。`battle_wait()` 中的 `mode_wait_dict` 允许不同模式注入不同的等待逻辑。

### 6.4 OCR + 图片匹配双重验证

门票检查 (`check_art_war_card`) 先用 OCR 识别数量，再检查特殊门票，形成双重验证机制。

### 6.5 防御性编程

- `enter_battle()` 设置最大点击次数防止死循环
- `battle_wait()` 使用 `random_click_swipt()` 防止战斗中卡死
- `success` 标志区分正常结束和异常结束
