# 记忆绘卷 (MemoryScrolls) 任务详解

## 1. 文件概述

记忆绘卷（追忆绘卷）是《阴阳师》中的限时活动玩法，玩家通过捐献碎片推进绘卷进度，达到100%可获得式神奖励。本任务实现了**全自动绘卷捐献**功能，核心特点：

- **自动捐献碎片**：自动滑动小/中/大碎片拉满并捐献
- **多绘卷支持**：支持选择卷一到卷六中的任意一卷
- **双绘卷支持**：周年庆等时期支持双绘卷活动选择
- **进度监控**：95%进度时发送通知提醒玩家空降
- **探索联动**：小绘卷满50后可自动结束当日探索任务
- **完成检测**：绘卷100%完成后可自动关闭探索任务

### 文件清单

| 文件 | 用途 |
|------|------|
| `script_task.py` | 任务主入口，包含绘卷导航和捐献逻辑 |
| `config.py` | 配置参数定义 |
| `assets.py` | UI资源定义（图片、点击、滑动规则） |

```python
class ScrollNumber(str, Enum):
    ONE = "卷一"
    TWO = "卷二"
    THREE = "卷三"
    FOUR = "卷四"
    FIVE = "卷五"
    SIX = "卷六"
```

### 2.3 MemoryScrollsConfig — 核心配置

```python
class MemoryScrollsConfig(ConfigBase):
    auto_contribute_memoryscrolls: bool = Field(default=True)     # 自动捐献碎片
    double_scrolls: DoubleScrolls = Field(default=DoubleScrolls.ONE)  # 双绘卷选择
    scroll_number: ScrollNumber = Field(default=ScrollNumber.ONE)    # 目标分卷编号
    auto_close_exploration: bool = Field(default=False)              # 绘卷完成后自动关闭探索
    notification_95: bool = Field(default=False)                     # 95%进度时发送通知
```

### 2.4 MemoryScrollsFinish — 探索完成配置

```python
class MemoryScrollsFinish(ConfigBase):
    auto_finish_exploration: bool = Field(default=False)              # 小绘卷满50后自动结束探索
    next_exploration_time: Time = Field(default=Time(hour=7, minute=0))  # 下次探索时间
```

### 2.5 顶层配置组合

```python
class MemoryScrolls(ConfigBase):
    scheduler: Scheduler                            # 调度器配置
    memory_scrolls_config: MemoryScrollsConfig      # 核心配置
```

## 4. 核心代码逐行解释

### 4.1 `run()` 主流程 (第19-25行)

```python
def run(self):
    self.ui_get_current_page()         # 检测当前所在页面
    self.ui_goto(page_summon)          # 导航到召唤页面
    con = self.config.memory_scrolls.memory_scrolls_config  # 获取配置
    self.goto_memoryscrolls_main(con)  # 进入绘卷主界面并执行捐献
    raise TaskEnd                      # 任务结束
```

### 4.2 `goto_memoryscrolls_main()` 进入绘卷主界面 (第27-73行)

```python
def goto_memoryscrolls_main(self, con):
    # 等待绘卷入口出现（最多30秒）
    if self.wait_until_appear(self.I_MS_ENTER, wait_time=30):
        while 1:
            self.screenshot()
            # 已进入主界面
            if self.appear(self.I_MS_FRAGMENT_S):
                logger.info('Entered Memory Scrolls main page')
                break
            # 双绘卷活动处理
            if self.appear(self.I_MS_DOUBLE_SCROLLS_ENTER):
                logger.info('Using Double Memory Scrolls')
                if con.double_scrolls == con.double_scrolls.ONE:
                    logger.info('Choose Double Memory Scrolls One')
                    # 默认选择第一个，不需要额外点击
                else:
                    logger.info('Choose Double Memory Scrolls Two')
                    self.click(self.C_MS_DOUBLE_SCROLLS_2, interval=1)  # 点击第二个
                if self.appear_then_click(self.I_MS_DOUBLE_SCROLLS_ENTER, interval=1):
                    continue  # 点击进入按钮
            # 点击右上角铃铛进入
            if self.appear_then_click(self.I_MS_ENTER, interval=1):
                continue
    else:
        logger.error('Failed to enter Memory Scrolls main page')
        self.set_next_run(task='MemoryScrolls', success=False)
        raise TaskEnd

    # 小绘卷数量检查（可选功能）
    if self.config.memory_scrolls.memory_scrolls_finish.auto_finish_exploration:
        while 1:
            self.screenshot()
            if self.appear(self.I_MS_FRAGMENT_S_VERIFICATION):  # 等待页面加载
                break
            if self.appear_then_click(self.I_MS_FRAGMENT_S, interval=1.5):  # 点击小碎片入口
                continue
        # 检查小绘卷是否满50
        if self.appear(self.I_MS_FRAGMENT_S_50):
            logger.info('Small Memory Scrolls fragments reached 50')
            # 安排下次探索时间
            self.custom_next_run(task='Exploration',
                                custom_time=self.config.memory_scrolls.memory_scrolls_finish.next_exploration_time,
                                time_delta=1)
        else:
            logger.warning('Small Memory Scrolls fragments not reached 50')
            self.set_next_run(task='MemoryScrolls', success=False)
            raise TaskEnd
        # 关闭小碎片页面
        self.ui_click_until_smt_disappear(self.I_MS_FRAGMENT_S,
                                          stop=self.I_MS_FRAGMENT_S_VERIFICATION, interval=1.5)

    # 进入指定分卷
    self.goto_scroll(con)
    # 返回召唤界面
    self.ui_click_until_disappear(self.I_MS_BACK, interval=1)
    logger.info('Return to Summon page')
```

### 4.3 `goto_scroll()` 进入指定分卷 (第75-130行)

```python
def goto_scroll(self, con):
    # 点击指定分卷直到捐献界面出现
    while 1:
        self.screenshot()
        if self.appear(self.I_MS_CLOSE):              # 捐献界面的关闭按钮出现
            logger.info('Entered Memory Scrolls contribution page')
            break
        # 根据配置点击对应分卷
        match con.scroll_number:
            case ScrollNumber.ONE:   self.click(self.C_MS_SCROLL_1, interval=1)
            case ScrollNumber.TWO:   self.click(self.C_MS_SCROLL_2, interval=1)
            case ScrollNumber.THREE: self.click(self.C_MS_SCROLL_3, interval=1)
            case ScrollNumber.FOUR:  self.click(self.C_MS_SCROLL_4, interval=1)
            case ScrollNumber.FIVE:  self.click(self.C_MS_SCROLL_5, interval=1)
            case ScrollNumber.SIX:   self.click(self.C_MS_SCROLL_6, interval=1)
            case _:
                logger.error(f'Unknown scroll number: {con.scroll_number.name}')
                self.set_next_run(task='MemoryScrolls', success=False)
                raise TaskEnd

    # 95%进度通知
    if con.notification_95 and not self.appear(self.I_MS_COMPLETE_95):
        logger.info('Memory Scrolls progress reached 95%')
        self.config.notifier.push(title='追忆绘卷进度95%', content='绘卷进度已达95%，请立即空降')

    # 判断是否需要捐献
    if self.appear(self.I_MS_CONTRIBUTE) or not self.appear(self.I_MS_COMPLETE):
        logger.info(f'Contributing Memory Scrolls for scroll {con.scroll_number.name}')
        if con.auto_contribute_memoryscrolls:
            self.contribute_memoryscrolls()           # 执行捐献
        self.set_next_run(task='MemoryScrolls', success=True)
    else:
        logger.info(f'Scroll {con.scroll_number.name} is already completed')
        self.set_next_run(task='MemoryScrolls', success=False)
        if con.auto_close_exploration:                # 绘卷完成，关闭探索
            logger.info('Auto close exploration task')
            self.config.exploration.scheduler.enable = False
            self.config.save()

    # 关闭捐献界面
    self.ui_click_until_disappear(self.I_MS_CLOSE, interval=1)
```

### 4.4 `contribute_memoryscrolls()` 捐献碎片 (第132-153行)

```python
def contribute_memoryscrolls(self):
    while 1:
        self.screenshot()
        # 检查三种碎片是否都为0（没有可捐献的了）
        if self.appear(self.I_MS_ZERO_S) and self.appear(self.I_MS_ZERO_M) and self.appear(self.I_MS_ZERO_L):
            logger.info('Memory Scrolls contribution is already completed')
            return

        # 滑动三种碎片拉满
        self.swipe(self.S_MS_SWIPE_S, interval=1)    # 小碎片拉满
        self.swipe(self.S_MS_SWIPE_M, interval=1)    # 中碎片拉满
        self.swipe(self.S_MS_SWIPE_L, interval=1)    # 大碎片拉满

        # 点击贡献按钮
        if self.appear_then_click(self.I_MS_CONTRIBUTE, interval=3):
            logger.info('Contributed Memory Scrolls')
            # 等待捐献动画结束
            while 1:
                self.screenshot()
                if self.wait_until_appear(self.I_MS_CONTRIBUTED, wait_time=5):
                    self.click(self.C_MS_CONTRIBUTED, interval=1)  # 点击跳过结算
                else:
                    break  # 动画结束
```

**捐献流程**：滑动拉满 → 点击贡献 → 等待动画 → 点击跳过 → 循环直到碎片耗尽。

## 6. 设计模式总结

### 6.1 页面状态机

通过图片匹配 (`appear`) 检测当前页面状态：
- `I_MS_ENTER`：在召唤页面（等待进入）
- `I_MS_FRAGMENT_S`：在绘卷主界面
- `I_MS_CLOSE`：在捐献界面
- `I_MS_CONTRIBUTE`：可以捐献

这是一种**隐式状态机**，状态由屏幕内容决定，而非显式变量。

### 6.2 Match-Case 分发

`goto_scroll()` 使用 `match-case` 根据配置的分卷编号点击对应按钮，清晰且易于扩展。

### 6.3 滑动操作模式

捐献碎片使用滑动 (`swipe`) 而非点击，模拟用户将滑块拖到最右端的操作。三个滑动操作分别对应小/中/大三种碎片。

### 6.4 探索联动机制

通过配置 `auto_finish_exploration` 和 `auto_close_exploration`，将绘卷任务与探索任务联动：
- 小绘卷满50 → 自动安排下次探索时间
- 绘卷100%完成 → 自动关闭探索任务

这是一种**跨任务协调**模式，通过配置系统实现任务间的依赖关系。

### 6.5 通知机制

95%进度时通过 `self.config.notifier.push()` 发送通知，提醒玩家手动"空降"（立即参与捐献抢排名）。这是**人机协作**的设计——自动化处理常规操作，关键时刻提醒人工介入。

### 6.6 防御性终止

每个异常路径都设置 `set_next_run(success=False)` 并抛出 `TaskEnd`，确保：
- 不会无限重试
- 调度器知道任务失败，可以安排重试
- 资源被正确释放
